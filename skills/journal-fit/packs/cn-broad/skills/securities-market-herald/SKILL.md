# 《证券市场导报》投稿（securities-market-herald）

## 期刊定位

证券市场和资本市场监管实务特色刊，适合上市公司、证券监管和市场运行研究。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方投稿须知。正式投稿前必须重新核对官网、采编系统或编辑部发布的最新模板。

## 触发时机

- 用户明确说目标期刊是《证券市场导报》或 Securities Market Herald
- 稿件主题接近本刊，但不确定问题意识、方法强度和读者对象是否匹配
- 需要把一篇通用中文经管稿改写成《证券市场导报》更容易接受的叙事
- 投稿前需要列出本刊高频拒稿风险和改投方向

## 选题偏好

- 证券市场监管、注册制和投资者保护
- 上市公司治理、信息披露和并购重组
- 资产定价、市场微观结构和投资者行为

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 引言明确证券市场制度或投资者行为问题
- 机制落到信息、流动性、定价效率、监管约束或公司治理
- 政策含义面向资本市场监管、上市公司和投资者保护

## 路由防误投

- 本刊快速定位属于“财政金融”通道；只有当稿件的核心贡献满足“金融机构、资本市场、监管、公司金融或国际金融机制必须是主线”时，才把 《证券市场导报》 作为首选。
- 相近 profile 先比较：`journal-of-financial-research`（《金融研究》） / `chinese-review-of-financial-studies`（《金融评论》） / `studies-of-financial-economics`（《金融经济学研究》） / `financial-regulation-research`（《金融监管研究》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：若金融只是机制之一，优先比较产业、财政、区域或综合经济刊。 正式建议前仍需进入官方核验清单。

## 高频拒稿雷区

- 只做股价相关性，无定价或监管机制
- 事件窗口和公告时点处理粗糙
- 把证券题写成一般公司金融

## 改投判断

金融学术顶刊转 journal-of-financial-research；会计披露转 accounting-research。
