# 《数量经济技术经济研究》投稿（journal-of-quantitative-technological-economics）

## 期刊定位

中国社会科学院数量经济与技术经济研究所主办。两条主线：**数量经济学**（计量方法及其应用、宏观计量、经济预测、投入产出、CGE）与**技术经济学**（技术进步、生产率、效率评价、创新与数字经济的测度与评估）。相较《经济研究》《CEQ》偏理论/因果，本刊更看重**测度与方法的应用价值**——把"怎么量、量得准、预测得好"做扎实。

## 触发时机

- 贡献点在**测度/方法**：全要素生产率、效率（DEA/SFA）、技术进步分解、投入产出/CGE、指数构建
- 题目是宏观计量、经济预测、政策模拟、新经济（数字经济/AI）测度
- 文章方法应用扎实但"因果故事"不强，担心被纯因果刊嫌识别弱
- 想判断该投本刊还是《经济研究》/《中国工业经济》

## 选题偏好

1. **生产率与效率测度**：TFP、Malmquist、DEA/SFA、技术进步分解
2. **宏观计量与预测**：时间序列、混频/大数据计量、景气与预测、政策模拟
3. **投入产出与一般均衡**：IO 表分析、CGE、结构分解（SDA）
4. **技术经济评价**：技术/项目经济评价、创新与数字经济的量化
5. **计量方法的应用与改进**：把前沿方法用到中国数据并讲清适用条件

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 引言：现实/政策需求 → 现有测度或方法的不足 → 本文方法贡献
- 方法节是重头：把模型/算法/指标讲透，假设与适用条件显式
- 结果要给**量化解读 + 敏感性**，技术经济类要落到评价结论
- 政策/实务含义面向规划、预测、产业与技术决策

## 路由防误投

- 本刊快速定位属于“经济学理论与宏观”通道；只有当稿件的核心贡献满足“经济学问题意识、机制解释和可外推的理论/政策贡献必须成立”时，才把 《数量经济技术经济研究》 作为首选。
- 相近 profile 先比较：`economic-research`（《经济研究》） / `china-economic-quarterly`（《经济学（季刊）》） / `economic-perspectives`（《经济学动态》） / `economic-science`（《经济科学》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：若只是行业背景或地方案例，比较更窄的产业、财政、金融或区域刊。 正式建议前仍需进入官方核验清单。

## 投稿前自检

- [ ] 已按适用项报告核心合同 ID/版本、哈希绑定诊断与 observed inference ceiling，且未由期刊层改写。
- [ ] 指标/模型构造透明、可复现

- [ ] 方法适用条件与局限有交代
- [ ] 结论给出量化解读，不止显著性

## 高频拒稿雷区

- 用现成软件跑 DEA/SFA/CGE 却不交代设定与参数来源
- 隐瞒、覆盖或以期刊层措辞补救核心诊断失败及 observed inference ceiling，而未如实报告登记处置。
- 指数/测度构造不透明，无法复现
- 方法堆砌，缺对中国数据/政策的实际意义

## 决策口诀

- "贡献在测度/预测/方法应用" → 本刊对口
- "贡献在干净因果 + 理论" → 《经济研究》/《CEQ》
- "贡献在产业政策评估 + 厚稳健性" → 《中国工业经济》
- "贡献在数理模型/算法本身" → 《管理科学学报》
