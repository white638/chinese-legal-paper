# 《史学月刊》投稿（journal-of-historical-science）

## 期刊定位

《史学月刊》由**河南大学主管，河南大学与河南省历史学会主办**，1951 年 1 月创刊（原名《新史学通讯》，1957 年改现名），是新中国最早的史学专业期刊之一，**月刊**。官方"敬告作者和读者"写明它"发表高水平的史学研究新成果，尤其欢迎史学理论、史学评论、社会史、城市史、乡村史、文化史、海洋史、台港澳研究等方面的优秀稿件"。与中国社会科学院系统的断代专刊相比，《史学月刊》的学术品格是**不限断代、专题取向、篇幅偏长、对史学理论与史学评论格外友好**：中国古代史、近代史、现代史、世界史、史学理论与史学史都设专门编辑与投稿邮箱，专题论文一般不少于 15000 字，并硬性要求研究性论文必须有学术史内容——"完全没有此类文字的稿件，本刊不予受理"。对历史政治学研究者，它是社会史、制度史长文与史学方法讨论的重要出口。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方投稿指南与注释规则。正式投稿前必须重新核对官网"投稿指南"的最新要求。

## 触发时机

- 用户明确说目标期刊是《史学月刊》或 Journal of Historical Science
- 稿件是社会史、城市史、乡村史、文化史、海洋史或史学理论与评论的长文，不限断代
- 需要把一篇断代专题或理论文章改写成有学术史回顾、页下注体例、1.5 万字以上的《史学月刊》式论文
- 投稿前需要列出本刊高频拒稿风险和改投方向

## 选题偏好

- 史学理论与史学评论、史学史：方法论反思、学术史梳理、对重要论著的评论
- 社会史、城市史、乡村史、文化史：不限断代的专题长文
- 海洋史、台港澳研究、环境史与新资料研究
- 各断代政治制度史与世界史专题（按学科邮箱投递）

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 正文骨架用 `cnki-paper` 的 `humanities-argument` 稿件 profile：问题—学术史—史料与考证—解释—结论；学术史一节是本刊的受理门槛，必须有评析
- 史料著录、版本选择、转引限制、引文忠实度与史料批判规则见 `cnki-paper/references/primary-source-citation.md`；页下注体例见 `cnki-paper/references/cn-journal-conventions.md`，并以本刊《中外文文献注释规范说明》为最终准绳（只按指向执行，不在本 skill 复制细则）
- 专题论文写足 15000 字以上，章节骨架清楚；史学理论与评论稿要有明确的论点与对话对象，而非综述
- 社会史、城市史等专题要在史料重建之外提炼可与他时他地比较的机制或类型
- 题名、关键词、摘要、作者简介、页下注按 2018 年以来栏目格式；按学科选择投稿邮箱，邮件主题栏写文章标题，并同时寄送打印稿

## 路由防误投

- 本刊快速定位属于“历史学”通道；只有当稿件的核心贡献满足“不限断代的史学专题长文或史学理论与评论、且具备学术史评析必须是主线”时，才把 《史学月刊》 作为首选。
- 相近 profile 先比较：`historical-research-cn`（《历史研究》） / `journal-of-chinese-historical-studies`（《中国史研究》） / `qing-history-journal`（《清史研究》） / `modern-chinese-history-studies`（《近代史研究》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：断代精深考证且篇幅较短者更适合对应断代专刊或其札记栏目；以社会科学理论检验为主、史料为辅的稿件更适合 open-times。 正式建议前仍需进入官方核验清单。

## 官方核验清单

- 正式给出投稿格式/流程建议前，先读取 `../../resources/source-basis.md` 和 `../../resources/official-source-map.md`，从其中的官方来源锚点或同一主办/出版体系入口开始核验，并在回答中说明核验日期。
- 检索"《史学月刊》 敬告作者和读者 / 中外文文献注释规则说明"，以官网 sxyk.henu.edu.cn"投稿指南"最新页面为准；不要沿用二手代投网站格式，也不要向非 henu.edu.cn 邮箱投稿。
- 核对：专题论文不少于 15000 字、学术史内容、页下注体例、题名/关键词/摘要/作者简介格式、学科邮箱与打印稿寄送要求、两个月时限、匿名与费用规定（官方未列，需询问编辑部）。
- 再次确认各学科邮箱与是否已启用在线投稿系统（上面信息发布于 2018 年，可能已更新）。
- 若本 skill 与最新官方要求冲突，以官方要求为准。

## 投稿前自检

- [ ] 一句话说明本文属于本刊欢迎的哪类专题（史学理论/评论、社会史、城市史、乡村史、文化史、海洋史、台港澳）或哪一断代
- [ ] 学术史一节对前人成果与研究现状有评析，而非罗列
- [ ] 专题论文不少于 15000 字；页下注已按本刊注释规范说明处理
- [ ] 核心史料已按 `primary-source-citation.md` 完成版本锁定、出处著录与引文忠实度核对
- [ ] 已选定对应学科邮箱、邮件主题为文章标题，并准备打印稿寄送

## 高频拒稿雷区

- 没有学术史内容，直接不予受理
- 篇幅不足或史料单薄，专题论文写成札记
- 史学评论写成综述，没有论点
- 注释不按本刊中外文文献注释规范说明处理
- 投错学科邮箱、未寄打印稿，或一稿多投（十年不受理）

## 改投判断

具有整体史学意义的重大问题可冲 historical-research-cn（《历史研究》）；1840 年前断代精深考证转 journal-of-chinese-historical-studies（《中国史研究》）；1840—1949 年专题转 modern-chinese-history-studies（《近代史研究》）；清代专题转 qing-history-journal（《清史研究》）；以社会科学理论对话为主的历史政治学长文转 open-times（《开放时代》）或 academic-monthly（《学术月刊》）历史学板块。
