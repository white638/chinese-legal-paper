# 《经济研究》投稿（economic-research）

## 期刊定位

中国经济学综合旗舰期刊，完整生命周期支持已在 `Economic-Research-Journal-Skills` 中实现。这里提供目标 pack 内的快速触发和改投判断。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方投稿须知。正式投稿前必须重新核对官网、采编系统或编辑部发布的最新模板。

## 触发时机

- 用户明确说目标期刊是《经济研究》或 Economic Research Journal
- 稿件主题接近本刊，但不确定问题意识、方法强度和读者对象是否匹配
- 需要把一篇通用中文经管稿改写成《经济研究》更容易接受的叙事
- 投稿前需要列出本刊高频拒稿风险和改投方向

## 选题偏好

- 理论贡献明确的中国经济问题
- 能与本刊近年文章对话的准实验或理论实证
- 宏观、产业、财政金融、制度经济等具有一般化含义的议题

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 把理论贡献放在引言和文献综述前部，不把政策含义写成部门建议
- 贡献要拆成理论、识别、机制、政策含义几条互不重叠的句子
- 摘要和正文需体现经济学问题而非单纯政策评估

## 路由防误投

- 本刊快速定位属于“经济学理论与宏观”通道；只有当稿件的核心贡献满足“经济学问题意识、机制解释和可外推的理论/政策贡献必须成立”时，才把 《经济研究》 作为首选。
- 相近 profile 先比较：`china-economic-quarterly`（《经济学（季刊）》） / `economic-perspectives`（《经济学动态》） / `economic-science`（《经济科学》） / `journal-of-finance-and-economics`（《财经研究》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：若只是行业背景或地方案例，比较更窄的产业、财政、金融或区域刊。 正式建议前仍需进入官方核验清单。

## 官方核验清单

- 正式给出投稿格式/流程建议前，先读取 `../../resources/source-basis.md` 和 `../../resources/official-source-map.md`，从其中的官方来源锚点或同一主办/出版体系入口开始核验，并在回答中说明核验日期。
- 深度包未随本套件收录；全流程走 `cnki-paper` 主工作流，本 profile 只做选刊与定位
- 核对最新投稿须知、匿名要求、摘要/JEL、参考文献与附件
- 检索“《经济研究》 投稿须知 / 征稿简则 / 作者指南”，以最新页面为准；不要沿用二手代投网站格式
- 核对是否要求匿名正文、作者信息页、基金信息单列、数据/程序/补充材料、版权协议或不收费声明
- 若本 skill 与最新官方要求冲突，以官方要求为准

## 投稿前自检

- [ ] 一句话说明为什么这篇稿件属于《经济研究》的核心读者范围
- [ ] 引言前 3 段已经出现本刊关心的问题层级、理论/机制和主要证据
- [ ] 文献综述至少对话 2-3 篇本刊或同层级中文期刊近年同主题文章

- [ ] 政策/管理启示从本文证据推出，而不是泛泛口号

## 高频拒稿雷区

- 只有政策评估或现象描述，缺少理论贡献
- 文献综述没有与中文经典和本刊近年文章对话
- 机制与异质性薄弱，却把显著性当作贡献

## 改投判断

深度包未随本套件收录；需要逐步写作/投稿检查时走 `cnki-paper` 主工作流，本 profile 只做选刊与定位；若实践政策更强，转 management-world。
