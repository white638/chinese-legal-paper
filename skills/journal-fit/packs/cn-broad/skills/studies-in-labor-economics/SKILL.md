# 《劳动经济研究》投稿（studies-in-labor-economics）

## 期刊定位

劳动经济学专业刊，适合就业、工资、技能、人口、社会保障和劳动关系研究。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方投稿须知。正式投稿前必须重新核对官网、采编系统或编辑部发布的最新模板。

## 触发时机

- 用户明确说目标期刊是《劳动经济研究》或 Studies in Labor Economics
- 稿件主题接近本刊，但不确定问题意识、方法强度和读者对象是否匹配
- 需要把一篇通用中文经管稿改写成《劳动经济研究》更容易接受的叙事
- 投稿前需要列出本刊高频拒稿风险和改投方向

## 选题偏好

- 就业、工资、劳动力流动和技能形成
- 人口老龄化、家庭决策和社保制度
- 企业用工、平台劳动和劳动权益

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 机制落到劳动市场摩擦、技能形成、企业用工、家庭决策或制度保障
- 异质性要按性别、年龄、教育、户籍、行业和地区解释
- 政策含义面向就业、社保、培训和收入分配制度

## 路由防误投

- 本刊快速定位属于“经济学理论与宏观”通道；只有当稿件的核心贡献满足“劳动就业、工资、人力资本、社保或劳动市场制度必须是核心贡献”时，才把 《劳动经济研究》 作为首选。
- 相近 profile 先比较：`economic-research`（《经济研究》） / `china-economic-quarterly`（《经济学（季刊）》） / `economic-perspectives`（《经济学动态》） / `economic-science`（《经济科学》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：若只是企业绩效或宏观政策，比较管理或综合经济刊。 正式建议前仍需进入官方核验清单。

## 高频拒稿雷区

- 把劳动力变量当普通控制变量，没有劳动经济学机制
- 忽略样本选择和迁移选择
- 只报告平均效应，不讨论群体差异

## 改投判断

社会保障制度专业稿转 social-security-studies；社会学机制转 sociological-studies。
