# 《中国工业经济》投稿（china-industrial-economics）

## 期刊定位

国内**产业经济 / 企业与创新实证**顶刊。其读者重视可审计的经验依据、机制含义与可落地政策解释。期刊层只要求核心合同的诊断处置和推断上限被准确呈现，不另行指定识别、稳健性或机制检验方案。

## 触发时机

- 题目涉及产业组织、企业行为、创新研发、数字经济、区域经济、环境规制
- 用中国政策做准实验（试点、补贴、环保督察、宽带中国、低碳城市、自创区……）
- 需要把核心合同的诊断处置、机制证据与推断上限清楚呈现
- 不确定既有核心结论能否转化为本刊读者关心的产业与政策含义

## 选题偏好

1. **政策评估类准实验**：某项产业/区域/环境政策对企业或地区结果的因果效应
2. **企业行为与绩效**：创新、出口、全要素生产率、数字化转型、ESG
3. **产业组织与竞争**：市场结构、进入退出、要素配置效率
4. **数字经济与新动能**：平台、数据要素、人工智能对生产率的影响

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 引言：现实问题 + 政策背景 + 边际贡献 3–5 条
- 制度背景段要把政策细节讲准（文件、时点、试点名单）
- 主表后必有经济含义解读（量级、占均值比重），不只报显著性
- 政策含义**可操作**：谁、在哪个环节、做什么——这是本刊与《经济研究》的关键差异
- 篇幅充实，表多图精

## 路由防误投

- 本刊快速定位属于“产业区域与农业经济”通道；只有当稿件的核心贡献满足“产业组织、企业行为、创新、数字经济或区域产业政策必须是主线”时，才把 《中国工业经济》 作为首选。
- 相近 profile 先比较：`industrial-economics-research`（《产业经济研究》） / `research-on-economics-and-management`（《经济与管理研究》） / `east-china-economic-management`（《华东经济管理》） / `journal-of-business-economics`（《商业经济与管理》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：若理论贡献高于产业场景，比较综合经济旗舰。 正式建议前仍需进入官方核验清单。

## 投稿前自检

- [ ] 已按适用项报告核心合同 ID/版本、哈希绑定诊断与 observed inference ceiling，且未由期刊层改写。
- [ ] 机制走"分渠道/调节"而非单纯三步中介
- [ ] 异质性多维且有经济解释
- [ ] 制度背景与政策时点准确
- [ ] 政策建议具体到主体与环节

## 高频拒稿雷区

- 隐瞒、覆盖或以期刊层措辞补救核心诊断失败及 observed inference ceiling，而未如实报告登记处置。
- 机制只有三步中介且无理论渠道
- 异质性只切"东中西"一刀
- 政策建议是"加强、完善、推进"四件套

## 决策口诀

- "核心合同通过 + 诊断透明 + 政策含义落地" → 本刊正中
- "理论贡献厚于实证" → 转《经济研究》
- "偏管理理论/案例/问卷" → 转《管理世界》或《南开管理评论》
- "落点在金融机理" → 转《金融研究》
