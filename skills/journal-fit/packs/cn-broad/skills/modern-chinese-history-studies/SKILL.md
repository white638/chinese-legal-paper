# 《近代史研究》投稿（modern-chinese-history-studies）

## 期刊定位

《近代史研究》由**中国社会科学院主管、近代史研究所主办**，1979 年创刊，初为季刊，1984 年改为**双月刊**（单月 25 日出刊）。官方稿约限定它"登载 1840—1949 年中国近代史领域的高水平原创性研究成果和学术信息，包括专题论文、学术评论、问题讨论、读史札记、学术综述等"，刊发范围涵盖近代政治、经济、思想、文化、社会等领域及港澳台地区历史，主要栏目有专题研究、中国共产党历史研究、近代中国的人与自然、学术评论、马克思主义与近代中国、青年论坛、读史札记、学术动态等。它的学术品格是**断代专刊中的旗舰**：档案（外交、党政、企业、地方）、日记、报刊、函电等一手材料的发掘与精读是入场券，"专题研究"要求在学术史上有明确递进，"学术评论""问题讨论"栏目则鼓励有据的争鸣；青年论坛为青年学者提供专栏。稿约明确只接受首发作品，含未在网络平台发表过。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方稿约与技术处理规定。正式投稿前必须重新核对近代史研究所官网与采编平台的最新要求。

## 触发时机

- 用户明确说目标期刊是《近代史研究》或 Modern Chinese History Studies
- 稿件研究 1840—1949 年间的中国政治、经济、思想、社会、中外关系或党史，有档案或报刊等一手材料
- 需要把一篇以理论框架为主的近代政治研究改写成史料承重、页末注体例的近代史论文
- 投稿前需要列出本刊高频拒稿风险和改投方向

## 选题偏好

- 晚清民国政治与制度：中央与地方、政党与政权、军政关系、司法与行政的过程重建
- 近代经济与社会：财政金融、企业与市场、乡村与城市、灾荒与人口
- 思想文化与知识分子：概念史、学术史、报刊与舆论
- 中外关系史、中共党史与革命史，以及近代中国的人与自然（环境史）

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 正文骨架用 `cnki-paper` 的 `humanities-argument` 稿件 profile：问题—学术史—史料与考证—解释—结论
- 档案、日记、报刊、函电的著录（全宗与卷号、日期、版次）、转引限制、引文忠实度与史料批判规则见 `cnki-paper/references/primary-source-citation.md`；页末注体例见 `cnki-paper/references/cn-journal-conventions.md`，并以采编平台公布的本刊技术规范为最终准绳（只按指向执行，不在本 skill 复制细则）
- 学术史要交代该问题的研究递进（含海外与港台成果），指出本文新材料或新解释所处的位置
- 叙事以时间与事件过程为骨，解释嵌在过程重建之中；避免用后见之明的理论标签替代对当时人行为逻辑的还原
- 正文匿名；注释置于页末、项目完备；投稿前以采编平台最新技术规范复核字数、提要与著录格式（本 skill 未收录这些数值）

## 路由防误投

- 本刊快速定位属于“历史学”通道；只有当稿件的核心贡献满足“1840—1949 年中国近代史领域、以一手材料承重的原创研究必须是主线”时，才把 《近代史研究》 作为首选。
- 相近 profile 先比较：`journal-of-chinese-historical-studies`（《中国史研究》） / `historical-research-cn`（《历史研究》） / `journal-of-historical-science`（《史学月刊》） / `qing-history-journal`（《清史研究》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：1840 年前议题转 journal-of-chinese-historical-studies；以清代制度长时段为主线的晚清研究先比较 qing-history-journal；1949 年后当代史或以社会科学理论检验为主的稿件不在本刊范围。 正式建议前仍需进入官方核验清单。

## 投稿前自检

- [ ] 一句话说明本文在 1840—1949 年哪一问题上、凭什么新材料或新解释推进了学术史
- [ ] 学术史评析覆盖海内外主要成果，并指出本文位置
- [ ] 核心档案与报刊已按 `primary-source-citation.md` 完成出处著录、版本锁定与引文忠实度核对
- [ ] 注释置于页末且项目完备；正文匿名；未在任何平台（含网络）先行发表
- [ ] 过程重建与解释分明，推断以史料能支撑的范围为限

## 高频拒稿雷区

- 二次发表或网络先行发表，违反首发要求
- 一手材料不足，以既有论著转述拼接
- 学术史不清，看不出递进；或问题不在 1840—1949 范围
- 理论标签替代过程重建，推断越界
- 注释不完备、未按技术规范处理，或正文暴露作者身份

## 改投判断

具有整体史学意义的重大近代史问题可冲 historical-research-cn（《历史研究》）；以清代制度为主线的晚清研究转 qing-history-journal（《清史研究》）；社会史、城市史、史学理论取向且篇幅 1.5 万字以上者转 journal-of-historical-science（《史学月刊》）；以近代中外关系为对象、偏国际政治史解释者可考虑 journal-of-international-studies-cn（《国际政治研究》）；以社会科学理论对话为主的历史政治学稿转 open-times（《开放时代》）。
