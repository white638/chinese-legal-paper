# 《管理科学学报》投稿（journal-of-management-sciences-china）

## 期刊定位

国家自然科学基金委管理学部认定的**数理/定量管理科学**顶刊。它与《管理世界》是两条路：《管理世界》偏经验实证与案例，本刊偏**模型、证明、算法、优化**。核心标识是**数理严谨性**——运筹优化、决策理论、数理金融、行为运作、系统建模、供应链与博弈。一篇问卷-SEM 或纯案例文，多半不对口。

## 触发时机

- 研究产出是**模型 + 定理/命题 + 算法/数值实验**
- 题目涉及运筹优化、排队、库存、定价、博弈、机制设计、数理金融、风险度量
- 行为运作（behavioral OM）：实验 + 模型刻画偏差
- 不确定该投本刊还是《管理世界》（经验型）

## 选题偏好

1. **优化与决策**：供应链、库存、定价、调度、网络优化、鲁棒/随机优化
2. **博弈与机制设计**：契约设计、竞争与合作、平台与定价博弈
3. **数理金融与风险**：投资组合、风险度量、衍生品、最优控制
4. **行为运作与实验**：用实验数据校准/检验行为模型
5. **数据驱动决策**：运筹 + 机器学习的方法贡献

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 引言：问题动机 → 文献中方法缺口 → 本文模型与方法贡献
- 模型—分析—算法/数值—管理启示，结构紧凑
- 记号统一、假设显式、定理表述严谨；证明放附录保持正文流畅
- 数值实验要回答"模型/算法在什么条件下更优"，给管理洞见
- 管理启示是"模型告诉我们什么决策规律"，不是政策口号

## 路由防误投

- 本刊快速定位属于“管理科学与工商管理”通道；只有当稿件的核心贡献满足“组织、战略、创新管理、管理科学模型、系统工程或企业管理机制必须是核心贡献”时，才把 《管理科学学报》 作为首选。
- 相近 profile 先比较：`chinese-journal-of-management-science`（《中国管理科学》） / `systems-engineering-theory-and-practice`（《系统工程理论与实践》） / `management-science-cn`（《管理科学》） / `journal-of-industrial-engineering-and-engineering-management`（《管理工程学报》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：若只是宏观政策效果，比较经济/产业/公共管理刊。 正式建议前仍需进入官方核验清单。

## 投稿前自检

- [ ] 模型设定完整（变量/约束/目标/假设显式）
- [ ] 关键结论以命题/定理给出并证明
- [ ] 算法有复杂度或收敛性分析
- [ ] 数值/仿真验证了理论性质并给出管理洞见
- [ ] 记号与表述前后一致、严谨
- [ ] 贡献定位在方法层（新模型/性质/算法），非政策

## 高频拒稿雷区

- 把问卷-SEM 或纯案例投到数理刊（学科不匹配）
- 有模型无证明，或命题表述含糊
- 算法无复杂度/收敛分析，数值实验单薄
- 假设不合理或与建模目标脱节
- 用"管理意义"套话替代方法贡献

## 决策口诀

- "产出是定理/算法" → 本刊对口
- "产出是回归系数 + 政策含义" → 《管理世界》/《中国工业经济》
- "产出是组织行为理论 + 问卷" → 《南开管理评论》
- "数理金融偏资产定价实证" → 也可考虑《金融研究》

## 输出格式

```
【匹配度】高 / 中 / 低
【产出类型】模型+定理 / 算法 / 行为实验+模型 / 仅实证（不匹配）
【核心方法合同】<ID/版本；诊断处置；Artifact ID；observed inference ceiling>
【方法贡献】<一句话：新在何处>
【建议去向】管理科学学报 / 管理世界 / 南开管理评论
```
