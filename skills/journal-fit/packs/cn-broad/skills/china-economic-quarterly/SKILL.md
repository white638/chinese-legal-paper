# 《经济学(季刊)》投稿（china-economic-quarterly）

## 期刊定位

北京大学中国经济研究中心（CCER）主办，是国内**最贴近国际主流经济学范式**的中文刊。编委与审稿人多有海外训练，看重"问题—模型/识别—证据"的逻辑闭环。可发表中文或英文。期刊层只判断这种逻辑与读者是否匹配，并要求核心合同、诊断处置和推断上限清楚呈现。

## 触发时机

- 文章方法接近国际期刊范式，想找国内最对口的中文出口
- 有干净的准实验设计或结构模型，但写作还停在"国内实证套路"
- 需要把核心合同、诊断处置与 observed inference ceiling 向技术审稿人清楚呈现
- 想判断该投 CEQ 还是《经济研究》

## 选题偏好

1. **机制清楚的因果问题**：理论上可建模、经验上可识别
2. **方法本身有规范价值**：结构估计、新识别策略、计量应用的范本
3. **国际可对话**：问题表述能让 field 同行立刻看懂贡献，不依赖本土语境包装
4. 不偏好纯描述、纯政策评估、缺识别的相关性研究

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 引言：问题 → 为何难 → 本文怎么解决（识别/模型）→ 主要发现 → 与文献的精确定位
- 贡献写作**对标 field**：与具体文献的方法/结论差异，而非"丰富了研究"
- 理论部分要么给可检验命题，要么给结构方程；不要"文献综述式理论"
- 图优于表：event-study 图、bin-scatter、模型拟合图受欢迎
- 全英文摘要质量要高（很多读者只读英文摘要 + 图）

## 路由防误投

- 本刊快速定位属于“经济学理论与宏观”通道；只有当稿件的核心贡献满足“经济学问题意识、机制解释和可外推的理论/政策贡献必须成立”时，才把 《经济学（季刊）》 作为首选。
- 相近 profile 先比较：`economic-research`（《经济研究》） / `economic-perspectives`（《经济学动态》） / `economic-science`（《经济科学》） / `journal-of-finance-and-economics`（《财经研究》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：若只是行业背景或地方案例，比较更窄的产业、财政、金融或区域刊。 正式建议前仍需进入官方核验清单。

## 投稿前自检

- [ ] 已按适用项报告核心合同 ID/版本、哈希绑定诊断与 observed inference ceiling，且未由期刊层改写。
- [ ] 贡献定位精确到具体文献，不是泛化套话
- [ ] 图能独立讲清主结果
- [ ] 英文摘要与术语规范、可被 field 同行读懂

## 高频拒稿雷区

- 隐瞒、覆盖或以期刊层措辞补救核心诊断失败及 observed inference ceiling，而未如实报告登记处置。
- 隐瞒、覆盖或以期刊层措辞补救核心诊断失败及 observed inference ceiling，而未如实报告登记处置
- 政策腔贡献（"为政府提供参考"）——CEQ 尤其反感
- 理论部分是文献堆砌，没有可检验命题或模型

## 决策口诀

- "识别干净 + 国际可对话" → CEQ 正中靶心
- "理论贡献厚但识别一般" → 可能更适合《经济研究》
- "纯政策评估、无机制" → 改投行业刊或补识别
- "核心合同诊断失败或推断上限不足" → 返回 `empirical-research`，不得在期刊层补救

## 输出格式

```
【匹配度】高 / 中 / 低
【核心方法合同】<ID/版本；诊断处置；Artifact ID；observed inference ceiling>
【贡献定位】对标到 <具体文献> | 仍是套话（需改）
【建议去向】CEQ / 经济研究 / 行业刊
```
