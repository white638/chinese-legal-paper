# 《社会保障评论》投稿（social-security-studies）

## 期刊定位

社会保障专业刊，适合养老、医保、社保基金、社会救助和共同富裕研究。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方投稿须知。正式投稿前必须重新核对官网、采编系统或编辑部发布的最新模板。

## 触发时机

- 用户明确说目标期刊是《社会保障评论》或 Social Security Studies
- 稿件主题接近本刊，但不确定问题意识、方法强度和读者对象是否匹配
- 需要把一篇通用中文经管稿改写成《社会保障评论》更容易接受的叙事
- 投稿前需要列出本刊高频拒稿风险和改投方向

## 选题偏好

- 养老保险、医保和长期护理保险
- 社保基金、缴费激励和财政可持续
- 社会救助、就业保障和收入分配

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 引言同时交代制度背景、政策问题和学术争论
- 结果解释要兼顾公平、效率和可持续
- 政策含义面向制度设计和执行层级

## 路由防误投

- 本刊快速定位属于“公共管理与社会政策”通道；只有当稿件的核心贡献满足“政府治理、公共服务、行政改革、社会保障或数字政府机制必须是主线”时，才把 《社会保障评论》 作为首选。
- 相近 profile 先比较：`journal-of-public-management`（《公共管理学报》） / `chinese-public-administration`（《中国行政管理》） / `china-public-administration-review`（《公共管理评论》） / `journal-of-public-administration-cn`（《公共行政评论》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：若只是经济政策效果，转向财政、产业或综合经济刊。 正式建议前仍需进入官方核验清单。

## 高频拒稿雷区

- 只描述政策条款，不检验证据
- 忽略财政可持续和群体异质性
- 把社会政策写成一般宏观经济题

## 改投判断

劳动经济机制转 studies-in-labor-economics；公共政策综合转 public-administration-and-policy-review。
