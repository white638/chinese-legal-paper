# 《南开管理评论》投稿（nankai-business-review）

## 期刊定位

国内**商学/组织管理**顶刊。学科底色是**管理学理论建构**：战略管理、组织行为、人力资源、市场营销、公司治理、创业。与《管理世界》相比更"学院派管理学"，与《管理科学学报》相比更"行为/理论"而非"数理优化"。核心评判：**理论贡献 + 中国情境 + 方法规范（问卷实证 / 多案例）。**

## 触发时机

- 题目是组织/战略/营销/治理的**构念间关系**（中介、调节、被调节的中介）
- 数据是**问卷/量表**（个体或企业层级），方法是 SEM / 多层线性模型 / 实验
- 或是**多案例 / 扎根理论**的质性建构
- 想判断该投《南开管理评论》《管理世界》还是《管理科学学报》

## 选题偏好

1. **组织行为与人力资源**：领导、团队、员工态度行为、HR 实践
2. **战略与创业**：战略选择、动态能力、商业模式、创业过程
3. **市场营销**：消费者行为、品牌、渠道、数字营销
4. **公司治理**：董事会、股权、高管激励（偏管理学视角而非纯财务）

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 引言立**理论缺口**：现有理论解释不了什么，本文补什么命题
- 假设推演：每条假设有理论机理支撑（而非"我觉得正相关"）
- 讨论部分要回扣理论贡献（对哪个理论的扩展/边界条件/整合）
- 中国情境是加分项：情境如何改变构念关系，提炼情境化理论

## 路由防误投

- 本刊快速定位属于“管理科学与工商管理”通道；只有当稿件的核心贡献满足“组织、战略、创新管理、管理科学模型、系统工程或企业管理机制必须是核心贡献”时，才把 《南开管理评论》 作为首选。
- 相近 profile 先比较：`business-management-journal`（《经济管理》） / `chinese-journal-of-management`（《管理学报》） / `management-review`（《管理评论》） / `foreign-economics-and-management`（《外国经济与管理》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：若只是宏观政策效果，比较经济/产业/公共管理刊。 正式建议前仍需进入官方核验清单。

## 投稿前自检

- [ ] 有清晰的理论缺口与理论贡献陈述
- [ ] 每条假设有理论机理，不是经验直觉
- [ ] 已按适用项报告核心合同 ID/版本、哈希绑定诊断与 observed inference ceiling，且未由期刊层改写。
- [ ] 中介/调节用 Bootstrap，多层数据用合适模型
- [ ] 质性研究编码过程透明、可信度论证充分
- [ ] 讨论回扣并推进了某个管理理论

## 高频拒稿雷区

- 假设全凭直觉，无理论机理（"应该正相关"）
- 量表照搬国外未做信效度/CMV 检验
- 把回归显著当理论贡献，讨论部分无理论对话
- 中国情境只是采样地，没进入理论
- 用经济学政策评估的框架投管理学刊（错位）

## 决策口诀

- "构念关系 + 问卷/案例 + 理论建构" → 本刊对口
- "宏观政策实证 + 政策含义" → 《管理世界》/《中国工业经济》
- "数理模型 + 定理/算法" → 《管理科学学报》
- "公司治理偏资本市场实证" → 可考虑《会计研究》/《金融研究》

## 输出格式

```
【匹配度】高 / 中 / 低
【方法】问卷-SEM / 实验 / 多案例-扎根 / 其他
【理论缺口】<一句话>
【核心方法合同】<ID/版本；诊断处置；Artifact ID；observed inference ceiling>
【理论贡献】扩展 / 边界条件 / 整合 <理论名>
【情境化】中国情境是否进入理论：是 / 否
```
