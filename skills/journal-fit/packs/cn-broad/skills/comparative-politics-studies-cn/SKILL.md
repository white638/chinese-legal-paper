# 《比较政治学研究》投稿（comparative-politics-studies-cn）

## 期刊定位

《比较政治学研究》是**天津师范大学政治与行政学院主办**的比较政治学专业**学术集刊**（半年刊，一年两辑），2010 年创刊，主编李路曲，是国内首个以"比较政治学"命名的辑刊，多次入选 CSSCI 收录集刊。官方自述"以比较政治学为特色和重点，以专业化和国际化的视角……在对比研究中提炼共通性的分析工具"。它的学术品格是**比较取向优先**：国别比较、政体与制度比较、比较政治理论与方法（历史制度主义、组态比较、跨国统计等）都在射程内；单一国家的描述性研究、没有比较维度的中国国内治理研究不是它的重点。作为集刊，它以 ISBN 按辑出版、没有 CN 刊号，投稿走编辑部邮箱，在职称与考核认定上与期刊有别，选投前要先确认所在单位的认定口径。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该集刊最新官方征稿要求。正式投稿前必须重新核对主办单位页面、集刊公众号或编辑部发布的最新要求。

## 触发时机

- 用户明确说目标是《比较政治学研究》或 Comparative Politics Studies（集刊）
- 稿件是国别比较、政体比较、比较政治理论或方法研究，但不确定是否够"比较"
- 需要把一篇单一国别研究改写成有明确比较框架的比较政治论文
- 投稿前需要列出本集刊高频拒稿风险和改投方向

## 选题偏好

- 国别与地区比较：政党、选举、民粹主义、族群与国家整合、威权韧性与民主转型的跨国比较
- 政体与制度比较：历史制度主义、国家建构、福利国家、央地关系的比较制度分析
- 比较政治理论与方法：概念的跨语境适用性、组态比较、跨国统计与案例比较的方法讨论
- 中国与他国的规范性比较研究（以比较框架为主线，而非单一中国经验陈述）

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 引言即写明比较的对象、比较的维度和为什么这样比较能回答理论问题；比较框架是本集刊读者最先看的东西
- 概念部分要处理"西来概念的本土适用性"——这是本集刊反复讨论的议题，稿件对此有自觉会加分
- 国别材料要有原文文献或可靠数据来源；多案例比较要交代案例信息的可比性
- 结论回到"共通性的分析工具"：本文比较提炼了什么可迁移的机制或类型
- 注释与摘要格式以最新一辑书末《投稿须知》为准（本 skill 未收录具体数值）

## 路由防误投

- 本刊快速定位属于“政治学与国际关系”通道；只有当稿件的核心贡献满足“跨国／跨政体比较框架或比较政治理论与方法必须是主线”时，才把 《比较政治学研究》 作为首选。
- 相近 profile 先比较：`political-science-research-cn`（《政治学研究》） / `world-economics-and-politics`（《世界经济与政治》） / `journal-of-international-studies-cn`（《国际政治研究》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：没有比较维度的中国国内政治或治理研究转 political-science-research-cn 或公共管理刊；国家间互动与外交研究转 IR 刊；需要期刊（而非集刊）认定的作者先确认单位口径。 正式建议前仍需进入官方核验清单。

## 高频拒稿雷区

- 名为比较、实为单一国别介绍或中国经验陈述
- 概念未经本土适用性讨论就直接套用西方分类
- 案例并列而无共同分析框架，结论无法跨案例迁移
- 材料依赖二手编译，缺少原文文献或可核对的数据来源
- 把集刊当作期刊处理，未核对单位认定与最新出版信息

## 改投判断

政治学理论与中国政治制度研究转 political-science-research-cn（《政治学研究》）；国家间互动、国际秩序与外交研究转 world-economics-and-politics（《世界经济与政治》）；区域国别政治且材料偏历史者转 journal-of-international-studies-cn（《国际政治研究》）；需要期刊认定且议题偏跨学科者可考虑 open-times（《开放时代》）。
