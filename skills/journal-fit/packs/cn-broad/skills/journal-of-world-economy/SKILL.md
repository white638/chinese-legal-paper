# 《世界经济》投稿（journal-of-world-economy）

## 期刊定位

中国社会科学院世界经济与政治研究所主办，国内**国际经济学/开放宏观**第一刊。核心标识是**国际视角**：贸易、投资、金融、汇率、全球价值链、开放与增长。一篇纯国内、与"开放/外部"无关的文章，即便做得好，也属于不对口。

## 触发时机

- 题目涉及贸易、关税、FDI、汇率、跨境资本、GVC、全球冲击
- 用中国开放政策（入世、自贸区、一带一路、外资准入）做准实验
- 文章有国际维度但写成了"国内政策评估"，定位偏了
- 想判断该投《世界经济》还是《金融研究》/《中国工业经济》

## 选题偏好

1. **开放经济中的因果问题**：外部冲击/政策如何通过贸易、投资、金融渠道传导
2. **国际比较与全球视野**：跨国数据、多国面板、全球价值链分解
3. **中国与世界的互动**：中国开放进程对内/对外的双向影响
4. **国际经济理论的中国检验或扩展**

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 引言要把"国际/开放"这一维度立在最前，让审稿人一眼看出对口
- 机制要讲清**传导渠道**（贸易渠道、金融渠道、预期渠道……）
- 与国际贸易/国际金融经典与前沿对话（不能只引国内文献）
- 政策含义偏**开放政策**层面（贸易、汇率、资本账户、产业开放）

## 路由防误投

- 本刊快速定位属于“国际经济”通道；只有当稿件的核心贡献满足“开放经济、国际贸易、GVC、汇率、FDI或国别比较必须是主贡献”时，才把 《世界经济》 作为首选。
- 相近 profile 先比较：`world-economic-papers`（《世界经济文汇》） / `world-economic-studies`（《世界经济研究》） / `international-economic-review-cn`（《国际经济评论》） / `journal-of-international-trade`（《国际贸易问题》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：若只是国内政策评估，优先回到综合经济或产业经济刊。 正式建议前仍需进入官方核验清单。

## 投稿前自检

- [ ] "国际/开放"维度在引言前段就立住，不是硬贴标签
- [ ] 传导渠道明确（经由贸易/投资/金融/预期）
- [ ] 数据匹配国际经济研究（海关/跨国面板/GVC）
- [ ] 已按适用项报告核心合同 ID/版本、哈希绑定诊断与 observed inference ceiling，且未由期刊层改写。
- [ ] 文献含国际贸易/金融的经典与前沿
- [ ] 政策含义落在开放政策层面

## 高频拒稿雷区

- 题目其实是国内问题，"国际"只是引言里一句话
- 用了 GVC 词汇但没做分解，只是叙事
- 隐瞒、覆盖或以期刊层措辞补救核心诊断失败及 observed inference ceiling，而未如实报告登记处置。
- 只引国内文献，缺国际对话
- 机制停在"促进了出口"，没说清渠道

## 决策口诀

- "外部冲击/开放政策 + 传导渠道" → 《世界经济》对口
- "落点在银行/货币政策/资本市场" → 更适合《金融研究》
- "落点在国内产业/企业行为" → 更适合《中国工业经济》
- "跨国比较的纯增长理论" → 可冲本刊，但需经验支撑

## 输出格式

```
【匹配度】高 / 中 / 低
【国际维度】贸易 / 投资 / 金融 / 汇率 / GVC | 偏弱（需上移）
【传导渠道】<明确的渠道> | 缺失
【核心方法合同】<ID/版本；诊断处置；Artifact ID；observed inference ceiling>
【数据对口度】海关/跨国/GVC | 一般国内数据
【建议去向】世界经济 / 金融研究 / 中国工业经济
```
