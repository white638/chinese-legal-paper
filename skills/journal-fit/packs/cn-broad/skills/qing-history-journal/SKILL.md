# 《清史研究》投稿（qing-history-journal）

## 期刊定位

《清史研究》由**教育部主管、中国人民大学主办**，中国人民大学清史研究所承担编辑，是清史领域的专业**双月刊**（2020 年起由季刊改为双月刊，逢单月 15 日出版）。前身为 1979 年创办的《清史研究通讯》，1991 年更名。官方以"学术性、资料性、信息性"为办刊宗旨，自述为"海内外清史研究领域最重要的两大定期刊物之一"，并明确"尤其欢迎有新材料、新观点、新方法和跨学科的研究成果"。它的学术品格是**断代精深加史料开放**：满文档案、朱批奏折、内阁题本、方志、族谱、域外文献等新材料的发掘与考订是其看家本领，同时对制度史、边疆民族史、社会经济史、思想文化史、环境史以及"新清史"等海外研究的对话保持高度活跃；官网栏目还包括清史纂修与学科自主知识体系讨论。对做清代政治制度、密折制度、督抚与中央关系的历史政治学研究者，这是最对口的专业刊。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方投稿指南与注释规范。正式投稿前必须重新核对官网在线投稿系统的最新要求。

## 触发时机

- 用户明确说目标期刊是《清史研究》或 The Qing History Journal
- 稿件是清代制度、政治、边疆、社会经济或思想文化研究，有新档案或新考订
- 需要把一篇以理论框架为主的清代政治研究改写成史料承重、符合《清史研究》注释规范的史学论文
- 投稿前需要列出本刊高频拒稿风险和改投方向

## 关键事实（核验日期 2026-09-02；以官网《投稿指南》《引文注释规范》与在线投稿系统最新要求为准）

- **主管/主办/编辑**：教育部主管；中国人民大学主办；中国人民大学清史研究所编辑（来源：国家哲学社会科学文献中心期刊页 https://www.ncpssd.cn/journal/secure/details?params=MzFCVDFPTGx6SUhrUlVLeXdxdmhjN01MTU40Z0V3dGZEUlUyK2doYnREVEVwaXdMMWtnaG9pRzJtTXJvVjFaSw ，核验日期 2026-09-02；期刊官网"期刊介绍"称"中国人民大学清史研究所主办的高水平的学术刊物" https://qsyj.ruc.edu.cn/CN/column/column1.shtml ，核验日期 2026-09-02）。
- **沿革与刊期**：前身《清史研究通讯》1979 年起刊印，1991 年更名《清史研究》；自 2020 年起由季刊变更为双月刊，逢单月 15 日出版；2025 年起正文版面由 156 页增至 204 页（来源：官网期刊介绍同上，核验日期 2026-09-02；国家哲学社会科学文献中心页记创刊时间 1991、出版周期双月刊）。
- **刊号**：ISSN 1002-8587；CN 11-2765/K；邮发代号 2-749（来源：国家哲学社会科学文献中心期刊页同上，核验日期 2026-09-02）。
- **办刊宗旨与偏好**："学术性、资料性、信息性"；"凡与清史相关的论文、评论皆在接收之列，优先选用选题新颖、观点明确、内容充实、论证严密、语言精炼的学术论文，尤其欢迎有新材料、新观点、新方法和跨学科的研究成果"（来源：官网投稿指南 http://qsyj.ruc.edu.cn/CN/column/item3.shtml ，发布日期 2021-04-15，核验日期 2026-09-02）。
- **投稿渠道**：官网网上投稿系统（http://qsyj.ruc.edu.cn/ ）是"本刊唯一投稿处理平台"，请勿将稿件转寄个人；任何冒用本刊名号收费的机构和个人均为非法（来源：投稿指南同上，核验日期 2026-09-02）。
- **评审制度**：严格遵行匿名评审和三审三校制；作者个人信息在投稿系统"作者工作桌面"填写，正文中勿出现可能显示作者信息的文字；署名及顺序以投稿系统为准；实行三审制，处理进度在系统跟踪，最终结果以电子邮件告知（来源：投稿指南同上，核验日期 2026-09-02）。
- **技术规范**：参照本刊纸质刊物相关论文或系统发布的《〈清史研究〉注释规范》处理来稿；不符合技术规范的来稿本刊有权令作者修改后重新投稿或退稿；官网另载《清史研究》引文注释规范 https://qsyj.ruc.edu.cn/CN/column/item4.shtml （来源：投稿指南同上，核验日期 2026-09-02）。
- **学术不端**：对出现学术不端行为的作者，一经发现立即公开并撤稿，五年内禁止在本刊发表（来源：投稿指南同上，核验日期 2026-09-02）。
- **字数、摘要/关键词、审稿周期、费用、编辑部邮箱**：待核（2026-09-02 官网投稿指南未列；第三方转载的"来稿须知"所称不收费用、邮箱等信息未经官方页面核实，不采信）。

## 选题偏好

- 清代政治制度与国家治理：密折与奏折制度、中央与督抚关系、八旗与官僚体制、法律与司法实践
- 边疆、民族与"大一统"：藩部治理、满蒙藏回事务、正统性建构，以及与海外"新清史"等研究的对话
- 社会经济史与环境史：赋役、市场、人口、灾荒、水利与生态
- 思想文化与学术史、清史纂修与清史学科自主知识体系；新材料（满文档案、题本、方志、域外文献）的发掘与考订

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 正文骨架用 `cnki-paper` 的 `humanities-argument` 稿件 profile：问题—学术史—史料与考证—解释—结论
- 史料著录（档案全宗、卷宗号、朱批与题本的定位符、方志版本）、转引限制、引文忠实度与史料批判规则见 `cnki-paper/references/primary-source-citation.md`；页下注体例见 `cnki-paper/references/cn-journal-conventions.md`，并以本刊《引文注释规范》为最终准绳（只按指向执行，不在本 skill 复制细则）
- 学术史部分要对海内外清史研究（含英文、日文成果）作实质评析，说明新材料或新解释的递进关系
- 制度史与政治史稿件先重建制度运作过程再谈解释；理论概念（如集权、信息机制、代理关系）用作提问工具，结论以史料能支撑的范围为限
- 正文匿名，个人信息在投稿系统填写；投稿前按官网最新规范复核注释、摘要与字数（本 skill 未收录这些数值）

## 路由防误投

- 本刊快速定位属于“历史学”通道；只有当稿件的核心贡献满足“以清代史料承重的制度、政治、社会经济或思想文化研究必须是主线”时，才把 《清史研究》 作为首选。
- 相近 profile 先比较：`historical-research-cn`（《历史研究》） / `journal-of-historical-science`（《史学月刊》） / `journal-of-chinese-historical-studies`（《中国史研究》） / `modern-chinese-history-studies`（《近代史研究》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：以社会科学理论检验为主、史料为辅的清代政治研究更适合 open-times 或 political-science-research-cn；晚清 1840 年后议题若以近代转型为主线，先比较 modern-chinese-history-studies。 正式建议前仍需进入官方核验清单。

## 官方核验清单

- 正式给出投稿格式/流程建议前，先读取 `../../resources/source-basis.md` 和 `../../resources/official-source-map.md`，从其中的官方来源锚点或同一主办/出版体系入口开始核验，并在回答中说明核验日期。
- 检索"《清史研究》 投稿指南 / 引文注释规范"，以官网 qsyj.ruc.edu.cn 最新页面与在线投稿系统为准；不要沿用二手代投网站格式，不向个人邮箱投稿。
- 核对：字数、摘要与关键词、正文匿名、系统内个人信息、《引文注释规范》（档案、古籍、外文文献著录）、三审三校流程、费用声明、版权与数据库收录条款。
- 再次确认在线投稿系统入口与规范版本（上面信息可能随官网更新而变化）。
- 若本 skill 与最新官方要求冲突，以官方要求为准。

## 投稿前自检

- [ ] 一句话说明本文的新材料、新观点或新方法，以及它在清史学术史中的递进位置
- [ ] 学术史评析覆盖海内外主要成果，而非仅列中文近作
- [ ] 核心档案与古籍已按 `primary-source-citation.md` 完成版本锁定、定位符著录与引文忠实度核对
- [ ] 注释已按本刊《引文注释规范》处理；正文匿名、个人信息在系统内填写
- [ ] 解释以史料能支撑的范围为限，"史料可证"与"推断"分明

## 高频拒稿雷区

- 缺少学术史回顾或对话，看不出研究起点
- 以二手论著或转引替代一手档案，版本与出处不明
- 理论框架先行，史料只作例证，推断越界
- 不符合本刊技术规范（注释、著录）而被令修改或退稿
- 正文暴露作者身份，或通过非官方渠道投稿

## 改投判断

具有整体史学意义的重大清史问题可冲 historical-research-cn（《历史研究》）；晚清以降以近代转型为主线者转 modern-chinese-history-studies（《近代史研究》）；明清之际或制度长时段贯通者比较 journal-of-chinese-historical-studies（《中国史研究》）；社会史、城市史、环境史取向且篇幅 1.5 万字以上者转 journal-of-historical-science（《史学月刊》）；以社会科学理论对话为主的历史政治学稿转 open-times（《开放时代》）。
