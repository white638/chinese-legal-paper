# 《开放时代》投稿（open-times）

## 期刊定位

《开放时代》由**广州市社会科学院主管、主办**，开放时代杂志社编辑出版，1982 年创刊（原名《广州研究》，1989 年改现名），**双月刊**。官方自述"坚持'以学术关怀社会'的理念"，办刊宗旨强调"以'大历史'的立场贯通理解近现代以来的中国问题"，并称"在国内社会科学期刊中率先推行双向匿名评审制度"。主要栏目有专题、人文天地、法学与政治、经济社会、传播与网络、"他者的世界"、批评、阅读。它的学术品格是**跨学科、长文、思想性**：政治学、社会学、历史学、法学、人类学在同一期并置，编辑部偏好有问题意识与理论抱负、以厚重经验或历史材料支撑一个大判断的文章，以及围绕同一议题组织的专题；每年举办的"开放时代论坛"和工作坊也是其议题来源。技术精致但问题细碎的实证短文、政策汇报体、纯综述，都不在其口味之内。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方投稿须知。正式投稿前必须重新核对官网或编辑部发布的最新要求。

## 触发时机

- 用户明确说目标期刊是《开放时代》或 Open Times
- 稿件是历史政治学、政治社会学、国家与社会关系、乡村与基层、思想史或法政交叉的长文，想找跨学科平台
- 手头有厚实的田野、档案或历史材料，需要提炼成一个有思想分量的判断并按本刊体例改写
- 投稿前需要列出本刊高频拒稿风险和改投方向

- **栏目与评审**：主要栏目为习近平新时代中国特色社会主义思想研究、专题、人文天地、法学与政治、经济社会、传播与网络、"他者的世界"、批评、阅读；官方称"在国内社会科学期刊中率先推行双向匿名评审制度"；投稿须知载明"推行匿名审稿制度"（来源：杂志简介同上；官网"投稿须知" https://www.opentimes.cn/html/About/Tips/index.html ，核验日期 2026-09-02）。

## 选题偏好

- 历史政治学与国家建构：以"大历史"视野贯通近现代中国的制度、政权与社会变迁
- 政治社会学与国家—社会关系：基层治理、乡村中国、单位与社区、社会组织的经验研究与理论提炼
- 法学与政治、经济社会：法治与政治秩序、发展模式、劳动与产业的跨学科解释
- 思想史、文化研究与"他者的世界"：非西方经验、比较文明视野下的中国问题

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 开篇立"问题的思想分量"：这个经验现象为什么关乎对中国近现代道路或社会结构的整体理解，再进入材料
- 全文围绕一个核心判断展开，材料（田野、档案、访谈、统计）要厚，但每一节都要回答"这一步如何支撑判断"
- 允许并欢迎跨学科语汇，但概念要有出处、用法要一致；避免名词堆叠替代论证
- 文风可以有作者声音，但须是学理化的判断而非时评；忌政策汇报腔与技术炫技腔
- 内容提要 350 字以内、关键词 3—5 个；注释用 Word 尾注功能编号，其余格式按官网《投稿体例》PDF；来稿附完整个人信息，邮件主题注明作者与标题

## 路由防误投

- 本刊快速定位属于“综合社科”通道；只有当稿件的核心贡献满足“跨学科的思想性判断、以厚重经验或历史材料支撑的大问题解释必须是主线”时，才把 《开放时代》 作为首选。
- 相近 profile 先比较：`social-sciences-in-china`（《中国社会科学》） / `academic-monthly`（《学术月刊》） / `exploration-and-free-views`（《探索与争鸣》） / `comparative-economic-and-social-systems`（《经济社会体制比较》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：学科内规范实证（识别为主、理论对话在学科内部）回到对应专业刊；纯政策评估或对策研究转公共管理或综合经济刊。 正式建议前仍需进入官方核验清单。

## 投稿前自检

- [ ] 一句话说明本文的核心判断及其对理解中国近现代道路或社会结构的意义
- [ ] 引言前 3 段已出现问题的思想分量、材料基础与对话对象
- [ ] 文献对话触及跨学科的理论源流，而非单一学科近年实证的罗列
- [ ] 内容提要 350 字以内、关键词 3—5 个、尾注编号、个人信息完整；若使用生成式 AI 已备书面说明
- [ ] 全文无政策汇报腔，材料厚度与判断分量相称

## 高频拒稿雷区

- 问题细碎、只有学科内部的技术贡献，没有思想性判断
- 材料单薄却下大判断，或材料堆砌而判断缺席
- 概念随意跨学科挪用，用法前后不一
- 时评化写作、政策建言体
- 不按邮件投稿规范（主题、提要、关键词、尾注、个人信息）投递，或一稿多投

## 改投判断

学科门类清楚、需要按学科板块评审的综合稿转 academic-monthly（《学术月刊》）；争鸣性强、面向公共议题且篇幅在 1.2—1.5 万字的稿转 exploration-and-free-views（《探索与争鸣》）；重大理论命题且体量更大者冲 social-sciences-in-china（《中国社会科学》）；社会学问题意识明确的经验研究转 sociological-studies（《社会学研究》）或 chinese-journal-of-sociology-shehui（《社会》）。
