# 《历史研究》投稿（historical-research-cn）

## 期刊定位

《历史研究》由**中国社会科学院主管、主办**，是中国历史研究院院刊，1954 年创刊，现为**月刊**。官方自述它是"党中央决定创办的全国性史学刊物"，"百家争鸣"是创刊时确定的办刊方针，"是史学界的一面旗帜"。作为中国史学的旗舰刊，它覆盖史学理论与史学史、中国史各断代、世界史与考古学，不设断代门槛，但设"分量"门槛：要么是**重大历史问题的新解释**，要么是**新材料带来的关键考订**，要么是**贯通性的理论与方法讨论**，三者至少居其一，并且史料功夫经得起本领域最挑剔的匿名评审。断代专刊（《中国史研究》《近代史研究》《清史研究》）更接纳精细的专题考证，《历史研究》则期待专题研究之上还有对整体史学认识的推进。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方稿约。正式投稿前必须重新核对中国历史研究院官网与稿件管理系统的最新要求。

## 触发时机

- 用户明确说目标期刊是《历史研究》或 Historical Research（中国历史研究院）
- 稿件是史学论文，材料扎实，但不确定问题分量是否够旗舰刊，或该投断代专刊
- 需要把一篇断代专题考证改写成有整体史学意义的《历史研究》式论文
- 投稿前需要列出本刊高频拒稿风险和改投方向

## 选题偏好

- 重大历史问题的新解释：国家形态、大一统、央地关系、社会经济结构、中外关系的长时段或关键节点研究
- 新材料驱动的关键考订：出土文献、档案、域外史料带来的史实重建与既有定论修正
- 史学理论与史学史：唯物史观与史学方法、学科史、史学话语体系的贯通性讨论
- 世界史与考古学中具有整体史学意义的专题

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 正文骨架用 `cnki-paper` 的 `humanities-argument` 稿件 profile：问题—学术史—史料与考证—解释—结论，叙事与论证并进
- 史料著录、版本选择、转引限制、引文忠实度与史料批判规则见 `cnki-paper/references/primary-source-citation.md`；页下注体例见 `cnki-paper/references/cn-journal-conventions.md`（只按指向执行，不在本 skill 复制细则）
- 开篇必须写清"这个问题为什么是重大问题、既有解释卡在哪里"，学术史回顾要有评析而非罗列
- 考证段落让史料自己说话，逐条注明出处与版本；解释段落明确区分"史料可证"与"合理推断"，推断上限如实写出
- 结论回到对整体史学认识的推进；投稿前以稿件管理系统公布的最新体例复核注释、摘要与字数

## 路由防误投

- 本刊快速定位属于“历史学”通道；只有当稿件的核心贡献满足“重大历史问题的新解释、新材料带来的关键考订或贯通性史学理论讨论必须是主线”时，才把 《历史研究》 作为首选。
- 相近 profile 先比较：`journal-of-historical-science`（《史学月刊》） / `journal-of-chinese-historical-studies`（《中国史研究》） / `qing-history-journal`（《清史研究》） / `modern-chinese-history-studies`（《近代史研究》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：精细的断代专题考证若缺少整体史学意义，先投对应断代专刊；以社会科学理论为主、史料为辅的历史政治学稿件，考虑 open-times 或 political-science-research-cn。 正式建议前仍需进入官方核验清单。

## 官方核验清单

- 正式给出投稿格式/流程建议前，先读取 `../../resources/source-basis.md` 和 `../../resources/official-source-map.md`，从其中的官方来源锚点或同一主办/出版体系入口开始核验，并在回答中说明核验日期。

- 若本 skill 与最新官方要求冲突，以官方要求为准。

## 投稿前自检

- [ ] 一句话说明本文回答的重大历史问题以及对整体史学认识的推进
- [ ] 学术史回顾有评析，指出既有解释的具体缺口
- [ ] 核心史料已按 `primary-source-citation.md` 完成版本锁定、出处著录与引文忠实度核对
- [ ] "史料可证"与"合理推断"在文中明确区分，推断上限如实写出
- [ ] 注释、摘要、字数已按稿件管理系统最新体例复核（本 skill 未收录这些数值）

## 高频拒稿雷区

- 问题细碎，只有专题考证而无整体史学意义
- 学术史罗列而不评析，看不出本文推进了什么
- 史料转引、版本不明、引文不忠实，或以二手论著替代一手材料
- 以理论框架套史料，推断越过史料所能支撑的上限
- 体例不合本刊页下注与著录规范

## 改投判断

1840 年前中国古代史专题转 journal-of-chinese-historical-studies（《中国史研究》）；1840—1949 年专题转 modern-chinese-history-studies（《近代史研究》）；清代专题转 qing-history-journal（《清史研究》）；史学理论、社会史、城市史、世界史等专题且篇幅在 1.5 万字以上者转 journal-of-historical-science（《史学月刊》）；以社会科学理论对话为主的历史政治学稿转 open-times（《开放时代》）。
