# 《学术月刊》投稿（academic-monthly）

## 期刊定位

《学术月刊》由**上海市社会科学界联合会主管、主办**，1957 年 1 月创刊，是新中国最早的综合性哲学社会科学学术刊物之一，**月刊**。它是典型的"综合刊、学科评审"：官方投稿指南把稿件分为哲学、经济学、文学艺术学美学、历史学民族学人类学、政治学社会学、法学与综合通联七个板块，各板块由本学科专家匿名审稿。因此它既要求稿件有综合刊所需的问题重要性与学理厚度，又要求经得起本学科同行的专业挑剔——政治学、社会学稿件在这里面对的是政治学、社会学评审，而不是泛社科读者。篇幅上以 1.5—2 万字的长文为主，另设学术笔谈与专题讨论两类较短体裁。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方投稿指南。正式投稿前必须重新核对官网、采编系统或编辑部发布的最新要求。

## 触发时机

- 用户明确说目标期刊是《学术月刊》或 Academic Monthly
- 稿件学科归属清楚（政治学、社会学、历史学、哲学等），有综合刊层级的问题意识，但需要确认板块与篇幅是否匹配
- 需要把一篇专业刊格式的稿子改写成 1.5—2 万字、当页脚注体例的《学术月刊》式长文
- 投稿前需要列出本刊高频拒稿风险和改投方向

## 选题偏好

- 政治学、社会学板块：国家理论、政治哲学、制度变迁、社会结构与社会理论的学理研究
- 历史学、民族学、人类学板块：有史料或民族志厚度并能提出解释性命题的研究
- 哲学、经济学、法学板块：基础理论与学科前沿问题
- 学术笔谈与专题讨论：围绕重大理论议题的多学科对话（篇幅较短，需按体裁投稿）

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 投稿时先选对板块：政治学、社会学稿件投第（5）板块，评审是本学科专家，写法要经得起学科内挑剔
- 引言先立问题的学理重要性与学术史位置，再交代本文的命题与材料；综合刊读者需要在前两页看懂"为什么重要"
- 长文（1.5—2 万字）要有清晰的章节骨架，每节推进一个论证环节；避免把专业刊短文机械扩写
- 注释一律当页脚注、圈码编号，引文注释按官网"关于引文注释的规定"；参考文献不另列或按官方规定处理
- 中文摘要 300~400 字，英文摘要约 200 词且不必逐句对译；正文匿名，作者简介单独提供

## 路由防误投

- 本刊快速定位属于“综合社科”通道；只有当稿件的核心贡献满足“学科归属清楚且具有综合刊层级学理重要性的理论或解释性命题必须是主线”时，才把 《学术月刊》 作为首选。
- 相近 profile 先比较：`social-sciences-in-china`（《中国社会科学》） / `open-times`（《开放时代》） / `exploration-and-free-views`（《探索与争鸣》） / `comparative-economic-and-social-systems`（《经济社会体制比较》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：只是学科内的技术性实证或对策研究，回到对应专业刊；争鸣性公共议题短文更适合 exploration-and-free-views。 正式建议前仍需进入官方核验清单。

## 投稿前自检

- [ ] 已确定所投板块，并能一句话说明本文对该学科的学理贡献
- [ ] 引言前 3 段已出现问题重要性、学术史定位与本文命题
- [ ] 文献综述至少对话 2-3 篇本刊或同层级综合刊近年同主题文章
- [ ] 字数、中文摘要 300~400 字、英文摘要约 200 词、关键词 3~5、当页脚注圈码、正文匿名均已复核
- [ ] 结论回扣理论贡献；无政策汇报腔

## 高频拒稿雷区

- 板块选错或学科归属摇摆，落入"综合通联"后缺少对口评审的加分
- 问题细碎、只有技术贡献，达不到综合刊的学理重要性
- 篇幅不足或机械扩写，章节骨架松散
- 注释体例不合（未用当页脚注圈码），正文暴露作者信息
- 一稿多投或已在网络先行发表

## 改投判断

跨学科思想性长文且材料厚重者转 open-times（《开放时代》）；面向公共议题、争鸣性强、1.2—1.5 万字者转 exploration-and-free-views（《探索与争鸣》）；重大理论命题体量更大者冲 social-sciences-in-china（《中国社会科学》）；学科内部规范研究回到 sociological-studies（《社会学研究》）、political-science-research-cn（《政治学研究》）或对应史学刊。
