# 《公共行政评论》投稿（journal-of-public-administration-cn）

## 期刊定位

《公共行政评论》（JPA）由**教育部主管、中山大学主办**，教育部人文社会科学重点研究基地中山大学中国公共管理研究中心、广东省行政管理学会协办，是公共行政类专业学术**双月刊**。官方办刊宗旨四句话点明了它的品格："倡导规范严谨的研究方法，提升公共行政研究质量；回应公共行政实践，建构公共行政学本土化理论；跟踪国际公共行政理论前沿，展开建设性的学术对话；弘扬公共精神，服务我国公共行政实践。"在国内公共管理刊物中，本刊最突出的是**方法规范意识与国际文献对话**：无论是定量实证、实验、质性案例还是混合设计，编辑与匿名评审都会盯住研究设计是否交代清楚、推断是否与设计匹配、与国际公共行政文献的对话是否实质。它也接受理论综述、书评与评论，但同样以学术品质为唯一标准。

这个 skill 是**定位 / 选刊 / 改写框架**工具，不替代该刊最新官方稿件体例。正式投稿前必须重新核对官网、采编系统或编辑部发布的最新模板。

## 触发时机

- 用户明确说目标期刊是《公共行政评论》或 Journal of Public Administration（JPA）
- 稿件是公共行政／公共政策的规范实证或方法自觉的质性研究，但不确定方法透明度与国际对话是否达标
- 需要把一篇偏实务或偏政策评论的公共管理稿改写成研究设计清楚、与国际文献对话的 JPA 式论文
- 投稿前需要列出本刊高频拒稿风险和改投方向

## 选题偏好

- 政府行为与官僚组织：激励、问责、注意力分配、部门协同的机制研究
- 公共政策过程与政策工具：议程设置、执行偏差、政策扩散、政策评估
- 公民—政府互动：公共服务满意度、政府信任、公众参与、协同治理
- 公共行政理论的本土化与国际对话：中国情境如何修正或扩展既有理论

## 方法与证据的报告边界

- 明示 `empirical-research` 核心合同 ID 与版本，按适用项原样报告已登记的估计对象或理论目标、假设、诊断处置、哈希绑定 Artifact ID 和 observed inference ceiling。
- 说明这些既有记录为何与本刊读者相关；期刊层不选择估计器、聚类层级、阈值、诊断或修复方案。
- 核心记录缺失或诊断失败时，返回 `empirical-research`，并如实报告收窄或撤回后的推断；不得在期刊层补救。
- 本刊层只补充版面位置、数据/代码、披露和透明度等呈现要求。

## 结构与写作

- 引言按"理论缺口—中国情境为何能推进—本文设计与发现"展开，前两页就让评审看到与国际公共行政文献的对话点
- 研究设计单独成节：数据来源、测量、分析策略与其局限如实写清；已登记的诊断处置与推断上限按上一节边界原样呈现，不在写作层拔高结论
- 质性与案例稿同样要交代材料获取、编码或分析过程与可信度处理，避免"深描"替代论证
- 讨论部分区分理论贡献、实践启示与边界条件；启示从证据推出，不写口号
- 正文匿名；体例（摘要、关键词、注释/参考文献）按官网 2022 年 7 月修订版《稿件体例》附件执行

## 路由防误投

- 本刊快速定位属于“公共管理与社会政策”通道；只有当稿件的核心贡献满足“公共行政／公共政策的机制解释且研究设计透明、能与国际公共行政文献对话必须是主线”时，才把 《公共行政评论》 作为首选。
- 相近 profile 先比较：`journal-of-public-management`（《公共管理学报》） / `chinese-public-administration`（《中国行政管理》） / `china-public-administration-review`（《公共管理评论》） / `public-administration-and-policy-review`（《公共管理与政策评论》）。若这些刊物的读者对象更贴近，不要因为名称、地区或变量相似而强行投本刊。
- 常见误投：偏决策咨询与行政实务的稿子转 chinese-public-administration；治理实践与基层经验总结转 governance-studies；只是经济政策效果评估转财政或综合经济刊。 正式建议前仍需进入官方核验清单。

- [ ] 实践启示从本文证据推出，并标明适用层级与边界

## 高频拒稿雷区

- 研究设计交代不清，推断强度超出设计所能支撑
- 只与国内政策文件对话，缺少与国际公共行政文献的实质对话
- 案例稿停留在过程描述，没有可迁移的机制或概念
- 政策建议脱离证据，写成部门工作建议
- 未按最新稿件体例处理，或正文暴露作者身份

## 改投判断

偏决策影响与行政实务叙事转 chinese-public-administration（《中国行政管理》）；理论评论、述评与案例比较转 china-public-administration-review（《公共管理评论》）；同样重方法但更偏政策评估与管理科学取向可比较 journal-of-public-management（《公共管理学报》）；治理实践与基层治理经验转 governance-studies（《治理研究》）。
