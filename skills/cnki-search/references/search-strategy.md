# 中文主题检索策略手册

`cnki-search`、`cnki-advanced-search`、`cnki-navigate-pages`、`cnki-snowball` 四个技能回答"怎么点"；本文回答"搜什么、用哪个字段、开不开核心刊过滤、按什么排、何时滚雪球、何时可以停、怎么记日志"。检索式与结果只有登记为 `cnki-paper/references/acquisition-registry.md` 第 4 节的 query 记录才算检索证据；文献充分性的判据以 `cnki-paper/references/literature-sufficiency.md` 为准；知网之外的渠道选择与文献分量判断见 `cnki-paper/references/source-channels-cn.md`；术语谱系与自创词撞车的检索组见 `cnki-paper/references/cnki-operations.md` §2a。

## 1. 何时读取

- 首次为一个课题建检索组（`purpose=sota|collision|terminology|citation|snowball`）之前；
- 结果数异常（0、少于 10、多于 5000）需要调整检索式时；
- 准备宣布"检索已饱和"或"该主题无人研究"之前；
- `audit` 阶段复核 query 记录能否重放时。

## 2. 字段选择

| 字段 | 代码 | 匹配范围 | 适用 | 漏检／噪音风险 |
|---|---|---|---|---|
| 主题 | SU | 篇名＋关键词＋摘要，并按知网主题词表做扩展 | 默认首选：建组、估规模 | 扩展规则不透明；摘要提及即命中，噪音随规模上升；早年文献无摘要、无关键词时退化为篇名匹配 |
| 篇名 | TI | 篇名 | 精确撞车、找承重文献、控制噪音 | 标题不含该词但实质讨论的文献全部漏掉——史学、思想史标题常用典故、人名、史料名 |
| 关键词 | KY | 作者关键词（部分界面并入机标关键词） | 找学科内自称属于该主题的文献 | 作者关键词随意；早期文献与集刊常无关键词 |
| 摘要 | AB | 摘要 | 找研究对象或方法在摘要出现的文献 | 史学、法学论文摘要极短或缺失 |
| 篇关摘 | TKA | 篇名＋关键词＋摘要，不做主题扩展 | 想要 SU 的覆盖但不要它的扩展噪音 | 与 SU 的差异当次对比结果数 |
| 全文 | FT | 全文文字层 | 找引文片段、罕见术语、史料名、人名地名、档号 | 噪音极大；OCR 错字；只能配精确短语与年代限定 |
| 参考文献 | RF | 参考文献著录 | 找"引用了某书某文"的文献，是前向追踪的替代路径 | 著录不规范致漏检；字段是否可用当次核验 |
| 作者／单位／基金／来源 | AU／AF／FU／LY | 各著录字段 | 限定范围、找同行、按刊定向 | 同名作者、单位改名、刊名变更 |

取舍原则：

1. 建组先 SU 估规模，再 TI 看承重层。SU 与 TI 结果数之比是主题"泛用度"的粗测：比值很大说明该词已成泛用修辞，需要加限定概念。
2. 史学与思想史议题的核心文献标题常不含分析概念（"某某疏考""某某制度考""读某某札记"），SU 之外必须补 FT 精确短语加年代、人名或史料名限定，否则会系统漏掉以史料或人物为题的文献。
3. FT 只在三种情况下用：找引文片段（`page-evidence` 的 C 级旁证）、找极罕见术语、找史料名或档号。FT 命中数不作为规模证据。
4. 字段代码以当次页面下拉菜单为准；新版检索、旧版高级检索与专业检索的字段名有差异，日志记实际使用的界面与代码。

## 3. 主题词扩展四路

每个核心概念至少走完四路。每路建独立 Query ID，或在同一 Query 的检索式中用 OR 并列并在 `notes` 注明扩展来源。

### 3.1 同义与近义

- 同义：可完全替换的表达（密折／密奏／奏折密陈）；
- 近义：学界指同一现象的邻近概念（信息渠道／信息沟通／上情下达）；
- 上下位：更宽的类（奏折制度）与更窄的例（朱批奏折）；
- 来源：已命中文献的关键词栏、结果页左侧的主题聚类、`terminology-governance.md` 建的术语谱系。

### 3.2 学科术语变体

同一现象在政治学、历史学、法学、公共管理中命名不同：政治学说"集权—分权"，制度史说"中央与地方关系""督抚权限"，法制史说"职官""监察"。每个相关学科至少取一个惯用变体。跨学科议题不做此步会漏掉整个学科的文献，而且从结果页看不出来。

### 3.3 古今用语差异

- 清代原词与现代学术词：原词"奏折""题本""廷寄""朱批"，现代词"文书制度""信息传递机制"。史料名与制度名用原词，分析概念用现代词，两类各建检索。
- 时代错置检查：只用现代分析概念（"信息不对称""委托代理"）检索古代议题，找到的是已经理论化的研究，找不到考证类研究；只用原词则漏掉理论化研究。两边都跑。
- 繁简与异体：知网多数界面对繁简做了归一，港台文献与古籍库不一定；港台用语差异见 `source-channels-cn.md` 3.9。

### 3.4 译名变体与拼音

- 舶来概念：通行译名（路径依赖）、竞争译名（路径依存）、原文夹注形式（path dependence）、音译；
- 本土概念外译：先官方译法，再学界变体，为第 10 节的中英对照做准备；
- 人名地名：外国人名的多种汉译（孔飞力／孔复礼）、满蒙人名的音译差异、地名的古今名与拼音写法。

## 4. 布尔组合与检索式模板

### 4.1 旧版高级检索（`cnki-advanced-search`）

行内逻辑为并含／或含／不含，行间逻辑为并且／或者／不含。三个模板：

- 主题组：行 1 `SU=概念A 或含 概念A同义词`，并且，行 2 `SU=概念B 或含 概念B同义词`；
- 承重层：行 1 `TI=概念A`，并且，行 2 `KY=概念B`，来源类别按第 5 节决定；
- 排噪：行 1 `SU=概念A`，不含，行 2 `TI=噪音词`（教学、课程、案例分析等）。

### 4.2 专业检索语法

`SU='概念A' AND (TI='概念B' OR KY='概念B') NOT TI='噪音词'`。`=` 精确、`%` 模糊；同字段词间 `*` 并含、`+` 或含、`-` 不含。以当次页面的语法说明为准，日志保存原始检索式全文。

### 4.3 组合顺序

先宽后窄：SU 双概念 → 加年代 → 加来源类别 → 加 TI／KY 限定。每一步记结果数形成漏斗，审计时能看出哪一步砍掉最多。

### 4.4 年代限定

按研究问题而不是按"近五年"惯性设定：史学议题的奠基文献多在 1980—2000 年代，限近五年会把奠基链整段切掉。SOTA 检索另开近三年 query，不与全时段 query 合并。

### 4.5 文献类型

期刊、学位论文、会议、报纸、辑刊在知网是并列子库。总库检索默认全选，但来源类别过滤只作用于期刊；需要学位论文与辑刊时单独勾选或单独检索，并单独记 query。

## 5. 核心刊过滤：开关原则与系统性漏检

### 5.1 开关原则

- 开（勾 CSSCI／北大核心／AMI）：估算主流学术对话规模、找目标刊同构范文、建 SOTA 首轮候选、结果数过大先看承重层。
- 关：找奠基文献（早年刊物的核心身份与今不同）、找反方与边缘立场、史学／古典学／集刊议题、需要学位论文与会议、港台与海外中文、核对"零结果"。
- 规则：**每个检索组至少各跑一次开与关**，两次结果数都记日志。只跑开过滤的组不能用于声称覆盖或饱和。

### 5.2 系统性漏检清单

| 漏检对象 | 原因 | 补检方式 |
|---|---|---|
| 史学、古典学、语言学专刊 | 大量重要刊不在 CSSCI 来源目录或仅在扩展版 | 关过滤后按 `LY=刊名` 定向检索；港台刊走 `source-channels-cn.md` 3.9 |
| 集刊／辑刊 | 属辑刊子库，不是期刊，任何来源类别都不触及 | 单独勾选辑刊库检索 |
| 学位论文 | 独立子库，过滤只作用于期刊 | 单独检索博硕库；博士论文常是唯一系统处理某一史料群的文献 |
| 会议论文 | 同上 | 单独检索；分量见 `source-channels-cn.md` 4.2 |
| 港台文献 | 多数不在知网；在知网者不入核心目录 | 华艺、台湾期刊论文索引、香港中文期刊论文索引 |
| 核心目录版本漂移 | 目录逐版更替；知网以哪一版标注历史年份视界面而异（当次核验） | 对奠基文献按刊名核其刊发当年的目录身份，日志注明目录版本 |
| 综合性学报与专业小刊 | 过滤保留大量综合学报，专业小刊被排除 | 关过滤后按学科导航或按刊定向 |
| 网络首发 | 无卷期页，部分界面在过滤下显示不稳定 | 时间排序单独检查 |

## 6. 排序视图各自的偏差

| 视图 | 找什么 | 偏差 |
|---|---|---|
| 相关度 | 首屏看检索式是否对路 | 算法不透明，偏向篇名匹配与近期文献；不能作为"最重要文献"的依据 |
| 被引 | 奠基文献、主流承接 | 年龄偏差：老文献累积优势，近三年几乎不可见；综述与教材类虚高；自引与学科规模效应；网络首发与集刊被引近零 |
| 下载 | 教学与时事关注度 | 下载不等于分量；标题吸引、与考试或政策热点相关者虚高；老文献下载低 |
| 发表时间 | 最新对话对象、网络首发 | 对奠基链完全盲；被网络首发与低质刊近期灌水淹没 |
| 综合 | 知网加权 | 权重不公开，只作辅助 |

规则：每个检索组至少看**相关度首屏、被引首屏、时间首屏**三个视图，各记页码；被引视图按年龄归一后再判分量（`source-channels-cn.md` 4.1）。被引排序切换后要等首行被引数字变化再提取（`cnki-operations.md` §2）。

## 7. 滚雪球：何时开始、何时停

### 7.1 何时开始

- 条件：已从被引视图与相关度视图的交集中确认 ≤3 篇承重或奠基文献作种子，且已按 `critical-reading-and-synthesis.md` 至少完成摘要级判断"确实属于本问题"；
- 条件不满足就滚雪球，会把无关文献的引文网络当成本领域骨架。
- 被引数分不出"奠基"与"整合"：综述、教材被引虚高。外文种子可加 `openalex_snowball.py --cd-index` 看颠覆指数
  （(n_i−n_j)/(n_i+n_j)，靠 +1 表示后来者只引它不引其前人，靠 −1 表示它与前人一同被引），
  只作挑选种子的辅助信号，不进承重层，不写进正文。

### 7.2 方向与工具

- 后向（参考文献）：`cnki-snowball` 详情页第 1 页免验证；挖理论谱系与史料来源。
- 前向（引证文献）：详情页第 1 页免验证，翻页触发验证码。**深前向改走检索页被引排序**：在种子所属的 SU 组内按被引排序读前几页，或用 RF 字段检索种子题名；不得绕过风控。
- 共引（耦合）：只作发散线索，不入承重层。
- 同被引：升为"对话簇候选"——被同一批后续文献并引的作品往往被学界当作同一议题的对立或并列立场，
  用它给对话式综述分组；登记为 `co-cited-with` 边（见 `acquisition-registry.md` 5.3），仍不替代逐篇阅读。
- 外文种子：`intl-search` 的 OpenAlex 滚雪球。

### 7.3 何时停

- 新一轮种子的后向列表中 80% 以上已在注册表；
- 连续两轮未出现新的主要立场或新的证据类型（与第 8 节同口径）；
- 新增条目多为三手材料（教材、通论、辞典）或纯转述；
- 单轮新增超过 50 条且多数与问题无关：种子选错或问题边界太宽，回第 2—4 节收窄。

### 7.4 登记

每轮记 `purpose=snowball` 的 query，`query` 写 `snowball:<方向>@<种子 Source ID>`；发现条目 `state=discovered`、`citation_scope=candidate-only`，复用既有 Source ID。
条目登记 Source ID 后，把"种子引用了谁／谁引用了种子"写成 `edges`（后向 from=种子、前向 from=条目，`evidence=cnki-detail`），
立场留 `unknown`，读到施引段落再补 `stance` 与 `context_quote`。

## 8. 检索饱和判据

这是 `literature-sufficiency.md` 第五节饱和门在检索层的操作化：

1. 定向补检至少两轮，每轮有明确目的（补反方、补方法、补近三年、补港台、补学位论文），各自独立 Query ID，`status=complete`；
2. 最后两轮的新增来源，其作用只能记为 `verification`、`boundary`、`known-gap` 或 `none`；出现新的主要立场或决定性证据类型即未饱和；
3. 五个覆盖门（主要立场、真实反方、奠基链、近期变化、方法责任）各至少有一个可计数的学术 final Source ID；
4. 核心过滤开与关、三个排序视图、四路扩展、至少一轮滚雪球都已跑过并有日志；缺任一项不得宣布饱和；
5. 零结果或极少结果必须先过第 10 节的概念对等检验与第 11 节的失败模式排查，才能写成"研究空白"。

## 9. 检索日志字段（PRISMA-S 式）

字段与 `acquisition-registry.md` 第 4 节的 query 记录一致；本节说明每个字段在知网语境下记什么。

| 字段 | 记什么 |
|---|---|
| `query_id` | 组内唯一，命名带用途（如 `Q-SOTA-003`） |
| `channel` | `CNKI`；辑刊、博硕、报纸子库在 `filters.doc_types` 注明 |
| `purpose` | acquisition-registry 允许值之一 |
| `query` | 原始检索式全文，含逻辑词与引号，不写意译 |
| `field` | 实际字段代码（SU／TI／KY／AB／FT／TKA／RF） |
| `filters.source_types` | 来源类别；`[]` 表示关过滤；开关各一条 query |
| `filters.years` | 年代区间 |
| `filters.doc_types` | 期刊／博硕／会议／报纸／辑刊 |
| `filters.expansion` | 是否勾选同义词扩展、中英文扩展（界面提供时） |
| `filters.sort` | 相关度／被引／下载／时间／综合 |
| `filters.pages_viewed` | 实际翻看页码范围 |
| `result_count` | 页面显示总数；约数时标 `result_count_is_approximate=true` |
| `screened_count`／`included_count` | 本 query 实际筛看条数与登记条数（对应 PRISMA-S 的 identified／screened） |
| `url` | 稳定结果页 URL；结果页 URL 带会话令牌时记录检索式可重放并注明 |
| `collected_at` | ISO 日期 |
| `notes` | 界面版本（新版／旧版高级／专业检索）、异常（验证码、超时）、零结果的排查结论 |

## 10. 中英文检索不对等

### 10.1 先后顺序

- 本土概念（密折、督抚、单位制、行政发包）：先中后英。英文检索找海外中国研究与理论对话，不用来估规模。
- 舶来概念（路径依赖、政策企业家、韧性）：先英后中。中文检索看本土化与本土争鸣，英文结果数才是规模。
- 混合概念（国家能力、国家自主性）：两边平行各建组，比较两边的主要立场是否对应。

### 10.2 概念对等检验

合并中英结果前逐项检查：

1. 官方或通行译名是否存在，学界是否有竞争译名；
2. 英文词是否指同一现象（centralization 兼指财政、行政、政治多义；密折译作 secret memorial 会混入其他朝代与其他国家）；
3. 回译检验：把英文候选译回中文，是否落回同一中文词；
4. 学科对等：英文文献所在学科与中文文献是否同一学科（海外中国研究多在历史学与区域研究，中文可能在政治学）。

不通过者，两边结果分别登记为各自 query，不在覆盖门上互相抵充。

### 10.3 零结果的含义

零结果有四种解释：术语错配、数据库覆盖缺口、文献类型错位（研究在专著或学位论文而非期刊）、真实空白。排除前三者后才能记为空白。OpenAlex 对无 DOI 的中文期刊几乎不覆盖（`intl-search`），其 `--language zh` 零结果不能作为中文文献不存在的证据。

## 11. 常见失败模式

1. 只用 SU 单字段单检索式估规模并宣布"研究稀少"；
2. 全程勾核心过滤，把史学专刊、集刊、学位论文整体漏掉；
3. 只看相关度首页，把算法排序当学术分量；
4. 按被引排序不做年龄归一，把二十年前的综述当当前主流；
