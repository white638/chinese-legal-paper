# 概念、测量与推断接口

## 1. 为什么要把三者连起来

概念决定“在谈什么”，测量或识别规则决定“材料中的什么算作它”，推断决定“从这些观察最多能说到哪里”。三者任何一处断裂，都会产生看似完整但不可辩护的论证。

本文件提供判断问题，不提供固定样本量、统一显著性阈值、统一信效度门槛或方法等级。具体标准必须由研究目的、误差代价、学科惯例和设计条件论证。

## 2. 概念登记

每个承重概念应使用稳定 `concept_id`，记录：

- 规范名称、来源与中文学科谱系；
- 定义以及必要／典型属性；
- 纳入、排除和边界案例；
- 上位、下位和近邻概念；
- 维度、层级与聚合规则；
- 随时间、制度或语境变化的可能性；
- 经验指示、文本识别规则或规范适用规则；
- 与主张、问题和证据 ID 的链接。

概念质量首先是边界与分析收益问题。新名称只有在改变可观察含义、区分竞争解释或提高理论压缩力时才可能构成贡献；“命名新颖”本身不是证据。

## 3. 从概念到观察

### 3.1 定量测量

记录构念到变量的映射、题项或指标来源、编码方向、时间点、单位和变换。评估：

- 内容覆盖：指标遗漏了哪些维度；
- 构念污染：指标是否混入结果、原因或相邻概念；
- 测量等价：跨群体、时期或案例是否仍有同义；
- 误差结构：随机、系统、差异性或共同方法偏差；
- 聚合有效性：个体观察为何可以上升到组织、地区或时期；
- 数据生成：行政记录、平台行为、调查回答如何被制度过程塑造。

任何可靠性、效度或拟合统计都应解释其与当前构念和用途的关系；不因越过一个固定数值而自动 PASS。

### 3.2 案例与过程证据

操作化可以表现为事件、行动、文件、关系变化或机制节点的识别规则。记录：

- 什么观察算作节点出现，什么只是一致性线索；
- 材料的产生者、目的、受众和保存机制；
- 同一事实是否来自真正独立来源；
- 沉默、缺席和未记录能否被解释为负面证据；
- 研究者在何处作了诠释跳跃。

“有引文”不等于机制得到验证；诊断力来自证据对竞争解释的区分能力。

### 3.3 文本与内容

记录语料、分析单位、版本、预处理和编码手册。概念出现不能仅由关键词命中判断：

- 同一词可能指向不同概念；
- 同一概念可能通过不同表达实现；
- 否定、引用、讽刺和制度套话改变语义；
- OCR、分词、翻译、去重和模型版本会改变观察；
- 文本产出频率不直接等于行动者态度、行为或制度效果。

参照一致性、运行稳定性或外部准确率应与任务和证据来源相匹配，并保留逐项证据与分歧处置；固定阈值不作通用硬门。
需要试编码、独立编码、参照集、留出集、边界案例或结果—主张复核时，按
`empirical-research/references/researcher-collaboration.md` 冻结输入、隔离运行、重算指标并处置分歧。

### 3.4 规范与诠释研究

并非所有概念都需要变量化。规范概念应记录适用条件、价值前提、冲突原则、受影响主体和反例；诠释概念应记录文本语境、解释规则、替代阅读和研究者立场。其严格性来自公开论证链，而不是强行量化。

## 4. 样本、案例与语料的选择

选择过程决定可见的变异和可推断对象。至少说明：

- 目标总体或材料宇宙；
- 纳入／排除规则及其实施时间；
- 实际进入分析的样本、案例或语料；
- 缺失、不可访问和剔除项；
- 选择是否受结果、处理、可见性或成功叙事影响；
- 当前材料支持统计概括、分析性概括、机制存在性判断、类型建构还是仅个案描述。

代表性不是单一数值。概率样本、目的性案例、理论抽样和完整语料各自服务不同推断任务，不能用同一标尺排序。

## 5. 建构、探索与验证的独立性

必须声明材料在每个步骤中的角色：

| 角色 | 允许用途 | 风险 |
|---|---|---|
| 概念建构 | 发现维度、边界与类别 | 把材料特征误当普遍结构 |
| 假设／命题生成 | 提出关系与机制 | 事后模式被包装为先验预期 |
| 模型／词典训练 | 学习分类或预测规则 | 数据泄漏、过拟合 |
| 验证／检验 | 检查预先声明的期待 | 与生成材料重叠造成循环验证 |
| 说明性例证 | 帮助读者理解已支持主张 | 用生动例子冒充系统证据 |

使用同一材料承担多个角色并非绝对禁止，但必须披露，降低推断强度，并避免“独立验证”“外部验证”等不实措辞。可行时使用时间外、案例外、语料外或来源独立的材料复核。

## 6. 从观察到主张

每个 `claim_id` 应记录：

- 主张类型：描述、关联、因果、机制、预测、解释、规范或综合；
- 所需证据及其 `evidence_id`；
- 实际证据质量、直接性和独立性；
- 反证条件与替代解释；
- 允许措辞和禁止措辞；
- 适用对象、时期、场域和条件；
- 不确定性来源。

常见推断上限：

| 观察／设计 | 通常最多直接支持 | 不自动支持 |
|---|---|---|
| 横截面共变 | 条件关联 | 时间顺序、因果效应 |
| 有明确对比但识别假设未诊断 | 受条件约束的差异 | 排他性因果 |
| 案例内时序与一般一致证据 | 机制线索或过程相容性 | 机制唯一性 |
| 高诊断力过程证据与竞争预期 | 有边界的机制判断 | 无条件普遍性 |
| 文本频率／主题 | 语料内表达模式 | 行为、态度或社会效果 |
| 样本外验证的预测模型 | 指定分布下的预测表现 | 可干预因果效应 |
| 规范论证 | 在公开前提下的应然结论 | 经验上必然实现 |

表格给出校准方向，不替代具体设计判断。

## 7. 效度与不确定性

效度应写成威胁—证据—处置链，而不是填一个词：

- 构念效度：观察是否对应预期概念；
- 内部效度／解释有效性：结果是否可由替代解释产生；
- 外部效度／可迁移性：结论可到哪些对象、时期和制度；
- 统计结论有效性：估计、不确定性和模型依赖是否透明；
- 解释有效性：研究者阅读是否受语境、位置或翻译系统影响。

不确定性包括抽样、测量、模型、编码、材料缺失、版本和解释不确定性。报告应与主张相关，不要求每篇论文机械列齐所有类别。

## 8. 伦理、权限与复现

涉及个人、敏感群体、受限数据库、平台数据、访谈或非公开档案时，记录：

- 合法获取依据与允许用途；
- 知情同意、伦理审批、豁免或不适用理由；
- 去标识化、最小化、保存期限和访问控制；
- 引文或案例细节的再识别风险；
- 可公开、受控访问和不可共享部分；
- 他人在合法权限下复核所需的清单、代码、版本、随机种子、参数和决策日志。

不能公开原始材料不等于不可复现；应提供在合法边界内最大限度的可核查信息。反之，仅写“数据可得”而无材料身份、版本和处理路径也不构成复现。

## 9. 写作校准

写作必须沿概念—证据—推断链选择动词：

- 描述证据：出现、分布、变化、共现；
- 关联证据：相关、伴随、条件差异；
- 机制线索：与机制一致、支持某节点、削弱某替代解释；
- 因果识别：仅在设计支持时使用影响、导致、效应；
- 规范论证：应当、正当、可辩护，并同时公开价值前提。

“证明”“必然”“普遍适用”“解释一切”等强措辞需要相应设计和证据。checker 可以发现设计与措辞的客观冲突；概念质量、机制可信度和外推合理性由研究运行提交来源、理由、替代解释和独立复核记录。
