# 中文学术术语治理：通行谱系、规范译名与自创概念门

## 1. 目的与位置

本规则防止两种相反错误：一是为了“创新”给已有现象换名，造成概念泡沫；二是机械沿用政策口号、流行表达或外文直译，把它们误当成已经成立的学术概念。

固定位置如下：

1. research 阶段随文献实采记录候选术语、通行译名和学科谱系；
2. 用户确认研究问题后，在 design 建立 `terminology_register.md`；
3. design、execution、贡献校准、蓝图和正文只能使用登记后决定采用的核心术语；
4. audit 阶段补写正文使用审计，核对首次定义、形式一致性和未登记变体。

这里的“符合中文学界传统”不是追求古雅、四字格或中国特色措辞，而是：术语能在相应中文学科的概念史、理论争论、经典或近期核心期刊用法中定位；翻译有可追溯的通行形式；必要的新造词能说明既有概念为何不足。

## 2. 证据优先级与术语状态

术语判断按以下顺序取证：

1. 目标刊及本学科核心期刊的持续用法，优先近年用法并兼顾奠基文献；
2. 学科经典、权威工具书、国家标准或有明确出处的权威译本；
3. 法律、政策、标准和官方文件中的正式用语；
4. 外文学界原词及其中文学界已形成的通行译名。

模型记忆、搜索结果片段、用户原稿中的用词和单篇文章的偶然命名只能生成候选，不能单独证明“学界通行”。所有采用项都必须把证据登记到 `reference_materials/source_index.md`，再在术语表中引用 Source ID 或已登记 URL。

每个核心术语只能标为以下一种状态：

| Status | 含义 | 使用要求 |
|---|---|---|
| `established-cn` | 中文学界已有相对稳定的学术术语 | 沿用通行形式，说明所属学科谱系和本文边界 |
| `official-cn` | 法律、政策、标准或官方文件中的正式用语 | 可作为研究对象或制度原词；不得仅凭官方使用就宣称其为学术概念 |
| `translated-established` | 外文概念在中文学界已有通行译名 | 采用通行译名，首次出现可附原文；记录其他译名但不随意换译 |
| `author-proposed` | 作者确有必要提出的新术语或新概念 | 完成严格的新概念论证、撞车检索与用户确认 |

政策热词、宣传性表达、媒体标签和日常用语若没有稳定学术内涵，不得伪装成 `established-cn`。在不同学科中同形异义的术语，必须按本文实际对话的学科谱系界定。

## 3. 必备工件：terminology_register.md

### 3.1 Core Terms

标题、摘要、各级标题、中心命题和贡献陈述中的核心概念都须登记。表中的证据 ID 必须可回查 source index；Decision 只保留最终采用、沿用或规范化后的形式。

| Term ID | Term | Status | Established Form / Original | Evidence IDs | Chinese Disciplinary Lineage | Near-neighbor Distinction | Definition / Boundary | Manuscript Use | Decision |
|---|---|---|---|---|---|---|---|---|---|
| T01 |  | established-cn |  | S01, S02 |  |  |  | 标题/摘要/正文 | adopt |

填写规则：

- `Established Form / Original`：中文既有术语写通行形式；译介概念同时写原文；官方术语写正式全称；自创术语写“作者拟议：××”。
- `Chinese Disciplinary Lineage`：说明它在何种中文学科、理论传统或争论中使用，不写“国内已有研究”这类空话。
- `Near-neighbor Distinction`：至少指出最近的一个既有概念，以及为何不能互换。
- `Definition / Boundary`：同时写内涵和外延边界；不得只写同义反复。
- `Manuscript Use`：列出实际使用位置与功能；术语不能只为标题醒目而存在。

### 3.2 Author-Proposed Term Justification

任何决定采用的 `author-proposed` 都必须有一行对应论证：

| Term ID | Exact/Near Search IDs | Existing Terms Considered | Why Insufficient | Empirical/Theoretical Basis | Intension | Extension | Observable/Analytical Payoff | Contribution Link | User Confirmation |
|---|---|---|---|---|---|---|---|---|---|
| T03 | S21, S22 |  |  |  |  |  |  |  | 用户于本轮明确确认 |

硬判准：

- 先做精确词检索，再做近义词、构词变体和同一现象描述检索；查询式、日期、结果规模及代表文献登记进 source index；
- 既有术语不足必须是解释、区分、测量或理论定位上的不足，不能是“不够新颖”“标题不够亮”；
- 新术语必须由经验归纳、理论演绎或二者往返产生，并能降低解释成本；
- 必须说明它比近邻概念多识别了什么、排除了什么，以及读者如何观察或判断实例；
- 仅在标题中出现、删除后论证不受影响，或只是给熟悉现象换名的术语，一律不用。

默认最多采用一个核心 `author-proposed`。同一核心概念下有逻辑完备的类型标签，可作为其内部分类登记，不按多个互不相干的核心新词处理。

## 4. 写作与译名规则

- 通行术语优先于作者自造同义词；稳定使用优先于为避免重复而换词。
- 外文概念先检索中文学界既有译法。存在多种译名时，按目标学科和目标刊的主流用法选择一种，首次出现注明原文或备选译名，后文保持一致。
- 官方术语按原文保留；分析时另行说明本文是否把它当经验对象、行动者概念还是分析概念。
- 不用加“化、性、感、力、逻辑、机制、范式、赋能、耦合”等词尾制造虚假概念。这些构词不是自动禁止项，但一旦成为中心术语，必须接受近邻检索和内涵—外延审查。
- 蓝图、编码表、审计表或写作过程中为便于操作临时起的流程标签，不自动取得学术概念资格。“理念库、议题选址、设计转译、成员动员”一类标签若要进入标题、小标题、图表或中心命题，必须像其他核心术语一样登记谱系、近邻、定义与分析收益；否则在成稿时改回可直接理解的普通学术关系。
- 不把古雅、生僻或高度压缩的表达等同于中文学术传统。中文学术表达的传统性来自可识别的学科对话和概念谱系，不来自仿古语气。
- 范文只能帮助识别目标刊如何界定、翻译和安排概念，不能复制范文的独创命名，更不能把范文作者的新词改一字后据为己有。

## 5. Audit：正文使用审计

在 `terminology_register.md` 中新增：

### Manuscript Use Audit

| Term ID | First Use Location | Registered Form Used | Definition / Boundary Present | Unregistered Variants | Final Status |
|---|---|---|---|---|---|
| T01 | 引言第 2 段 | yes | yes | none | PASS |

审计要求：

- Core Terms 中每个采用项都必须出现一行，且首次出现位置真实可查；
- 正文使用登记形式；简称必须在首次出现时建立映射；
- 核心分析概念须在首次承担论证功能处给出定义或边界；
- 未登记变体为零，或已明确统一回登记形式；
- 标题、摘要、各级标题、图表、变量/编码名称和结论中的术语逐项核对；
- 同时核对规划工件中的临时标签是否泄漏到正文；未登记的流程名、压缩式构词和仅为图表整齐而造的分类名必须统一改写；
- 写作评审独立判断是否存在“换名不换解释”、政策词冒充学术概念、随意另译、同义漂移或中文学科谱系不明。

任何 adopted 行无来源、任一自创术语缺论证或用户确认、多个自创术语缺例外确认、正文存在未解决变体，均阻断 contribution/audit/output 对应门。
