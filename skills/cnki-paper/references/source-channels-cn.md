# 中文一手材料、政府文献与二次文献渠道树与文献分量判断

本文回答两个问题：某类材料去哪找（入口特征、访问条件、登记时记什么、常见坑），以及找到之后这篇东西有多重。它与三份文件分工：`primary-source-citation.md` 负责史料层级判定、版本选择、著录体例与考证；`acquisition-registry.md` 负责登记字段、状态与证据等级；`page-evidence/references/page-sources.md` 负责页码核证的 A/B/C 分级与图书类渠道操作。知网内的检索式、字段、过滤与饱和见 `cnki-search/references/search-strategy.md`。

访问条件按撰写时的一般情形描述。凡标"当次核验"者，平台权限、开放范围与界面变动频繁，使用前须在用户浏览器中实际确认，并把确认日期写入 query 记录。本文不写具体 URL 路径，只给站点名与入口特征。

## 1. 何时读取

- `acquisition` 阶段发现所需材料不是知网期刊论文（档案、古籍、方志、报刊、政策文件、统计、港台文献、专著）时；
- 研究问题属历史政治学、制度史、政策史、公共政策或涉统计口径时；
- `research` 阶段为候选文献分配 `core-reading`／`background` 与八类主张权限前判断分量时；
- 引用库出现网络首发、增刊、集刊、会议论文、疑似低质刊或撤稿信号时。

## 2. 渠道树总览

```
要找的是什么？
├─ 清代及以前的原始文书（奏折、题本、谕旨、档册）        → 3.1 明清档案
├─ 官修记录与制度文本（实录、起居注、会典、则例、政书）   → 3.2 电子古籍库
├─ 一般古籍、文集、笔记、年谱                             → 3.2 文字层检索 ＋ page-sources ④ 籍合网（页码）
├─ 某地某时的建置、职官、赋役、人物、风俗                 → 3.3 地方志
├─ 1833—1949 年的期刊与报纸                               → 3.4 近代报刊
├─ 民国政府文书                                           → 3.1 二史馆 ＋ 3.4 近代报刊
├─ 1949 年后的法律法规、国务院与部委文件、政府公报        → 3.5 当代政府文献
├─ 人口、财政、产业、社会指标                             → 3.6 统计数据
├─ 1949 年后的报纸报道、社论、政策解读                    → 3.7 当代报纸
├─ 判断某篇论文是否被同行认可、找议题的"入选"文献         → 3.8 二次文献与转载信号
├─ 港台与海外中文研究                                     → 3.9
├─ 系统处理某一史料群或案例的长篇研究                     → 3.10 学位论文
└─ 专著的著录核验、章节归属、页码影像                     → 3.11 读秀／超星／全国图书馆参考咨询联盟
```

每个渠道命中后：登记 Source ID（复用既有）→ 按 `primary-source-citation.md` 判层级与版本 → 页码走 `page-evidence`。

## 3. 渠道逐项

每项五要素：能找什么、入口特征、访问条件、登记时记什么、常见坑。

### 3.1 明清档案

**中国第一历史档案馆数字档案馆与馆藏目录**

- 能找什么：明清中央机构档案——宫中朱批奏折、军机处录副奏折、内阁题本、上谕档、起居注册等全宗的件级目录，部分全宗提供在线影像。
- 入口特征：官网的数字档案馆入口，按全宗、责任者、事由、时间检索；结果为件级条目，含档号、具奏人、日期、事由摘要。
- 访问条件：注册后可查目录；影像开放范围按全宗分批扩大，部分仅限馆内阅览（当次核验）。
- 登记时记什么：全宗名、档号（宫中朱批以 04 起、录副以 03 起）、具奏人、具奏日期与朱批日期、影像核对日期；著录见 `primary-source-citation.md` 4.5。
- 常见坑：事由摘要是馆员概括，不是原文，检索词须用当时用语；同一件在宫中档与录副中并存，不得互证；影像无法在线看时 `state` 只能到目录核验，不得写成已核原件。

**台北故宫博物院清代档案检索**

- 能找什么：宫中档奏折、军机处档折件、外纪档、史馆档等，雍正、乾隆朝宫中档最集中；另有已刊《宫中档》各朝奏折影印辑。
- 入口特征：该院清代档案检索系统，按文献编号、具奏人、时间、事由检索；条目带文献编号并标注是否有影像。
- 访问条件：目录检索公开；影像浏览与下载权限当次核验；已刊影印辑走图书馆。
- 登记时记什么：文献编号（不是档号）、具奏人、日期；引已刊辑时记辑次与页码。
- 常见坑：同一奏折在北京与台北可能各有原件或录副，`reason` 须说明所据为哪一地；繁体检索。

**中国第二历史档案馆**

- 能找什么：民国中央政府机构档案（全宗号＋案卷号体系）；大量已出版《中华民国史档案资料汇编》等汇编本。
- 入口特征：官网馆藏目录检索与数字化档案开放查询；馆内阅览为主。
- 访问条件：目录部分公开；原卷阅览须预约并持介绍信；数字化开放范围当次核验。
- 登记时记什么：全宗名、全宗号、案卷号、文件日期；汇编本另记册页并注明是否核对原卷。
- 常见坑：汇编本经选择与删节，`primary-source-citation.md` 2.1 的"整理本是二次载体"同样适用。

### 3.2 实录、起居注与政书电子库

**明清实录电子库**

- 能找什么：《明实录》《清实录》全文文字层，部分带影印页对照；起居注部分库收录。
- 入口特征：多家平台并存——中研院汉籍电子文献资料库、籍合网、爱如生等库内均有实录文本；各家底本不同（中华书局影印本、校勘本、清内府本）。
- 访问条件：汉籍电子文献部分内容免费，部分需授权；籍合网与爱如生为机构订阅（当次核验）。
- 登记时记什么：所用库、库内标注的底本、卷次、年月日干支；正文引注回中华书局影印本册页（`primary-source-citation.md` 4.4）。
- 常见坑：不同底本的卷次划分与文字有异；文字层命中后必须回影印页核对；实录是二手（`primary-source-citation.md` 2.3），不与原档互证。

**籍合网·中华经典古籍库（中华书局）**

- 能找什么：中华书局系整理本与点校本古籍，文字与原书图像逐页对照。
- 入口特征：按书名、作者、全文检索；选中文字可生成含版本页码的引用串。
- 访问条件：机构订阅为主，个人可按库付费（当次核验）。
- 登记时记什么：点校本版次与页码；这是唯一可直接产 `page-evidence` A 级的古籍库。
- 常见坑：见 `page-sources.md` ④。

**爱如生·中国基本古籍库**

- 能找什么：先秦至民国万种古籍的文字层与底本影像层，文集、笔记、政书覆盖广；方志另有中国方志库。
- 入口特征：客户端或网页版；分类导航加全文检索，命中显示卷叶，可切到影像页。
- 访问条件：机构订阅；客户端版有并发数限制（当次核验）。
- 登记时记什么：库名、条目页标注的所据底本、卷叶；影像页可截图作 A 级，但页码是底本叶码而非点校本页码。
- 常见坑：文字层 OCR 与录入错误率不低，异体字归一影响检索；底本多为某一刻本，与通行点校本文字有异，承重引文回点校本或注明所据刻本。

**书同文古籍数据库**

- 能找什么：文渊阁《四库全书》电子版、《四部丛刊》、十通等类书政书全文。
- 入口特征：全文检索带原文影像对照，按书、卷定位。
- 访问条件：机构订阅（当次核验）。
- 登记时记什么：库名、版本（四库本／丛刊本）、卷叶；四库本馆臣改字问题见 `primary-source-citation.md` 3.4。

**中国哲学书电子化计划（ctext）**

- 能找什么：先秦两汉典籍为主，后世文献部分；带扫描本对照。
- 入口特征：免费网站；按篇章号定位，可对照多个版本影像。
- 访问条件：免费；部分高级功能需注册。
- 登记时记什么：篇章定位符；不能替代点校本页码。
- 常见坑：文字层为众包校对，引用回点校本；影像所据版本需核。

**汉籍电子文献资料库（中研院）**

- 能找什么：二十五史、十三经、明清实录、大清会典、台湾方志、部分文集等。
- 入口特征：分自由使用与授权使用两类库；全文检索，命中给卷页。
- 访问条件：自由库免费；授权库需申请（当次核验）。
- 登记时记什么：库名、条目页注明的所据版本、卷页。
- 常见坑：繁体检索；页码是所据版本的页码，须核对与引用条目一致。

### 3.3 地方志

- 能找什么：某地某时的建置、职官、赋役、学校、人物、艺文、风俗。旧志（明清民国）与新编志（1980 年代以来）性质不同。
- 入口特征：国家图书馆数字方志（旧志影像）；爱如生中国方志库（旧志文字层与影像）；各综合平台的方志与年鉴专库和各省方志办的数字方志馆（新编志与地方年鉴）；影印丛书《中国地方志集成》《中国方志丛书》走图书馆与读秀。
- 访问条件：国图数字方志免费；商业库机构订阅；方志办出版物多为纸本或方志办网站 PDF（当次核验）。
- 登记时记什么：纂修年号、版本（刻本／影印本／点校本）、卷目、叶或页；著录见 `primary-source-citation.md` 4.8。
- 常见坑：同名方志多次纂修，缺年号即错代；新编志的历史部分多抄旧志与档案，对史实是三手；人物传与艺文志的褒贬有编纂动机。

### 3.4 近代报刊

**全国报刊索引（上海图书馆）**

- 能找什么：1833 年以来中文报刊篇目索引；旗下晚清期刊全文数据库、民国时期期刊全文数据库提供逐页影像。
- 入口特征：按篇名、作者、刊名、年代检索；命中给刊名、卷期、日期、页码，可看影像。
- 访问条件：索引检索部分公开；全文库机构订阅（当次核验）。
- 登记时记什么：刊名、卷期号、出版日期、影像页码，并核页角看是否与原刊页码一致；著录见 `primary-source-citation.md` 4.9。
- 常见坑：民国刊物改名、停复刊频繁，同名异刊；篇名索引不覆盖短讯与广告；影像页码与原刊页码可能两套并存。

**《申报》数据库**

- 能找什么：1872—1949 年《申报》全文影像与文字层。
- 入口特征：多家版本（上海图书馆、爱如生及其他商业平台），文字层质量不一；按日期翻版或全文检索。
- 访问条件：机构订阅（当次核验）。
- 登记时记什么：日期、版次；用影印本时记册页。
- 常见坑：早期版次编排与今不同；OCR 对竖排繁体错误多，引文看影像。

**其他**：大成老旧刊全文数据库（民国期刊影像，全文检索弱）；人民日报图文数据库见 3.7；各地图书馆的地方报纸数字化项目（当次核验）。

### 3.5 当代政府文献

**国务院政策文件库（中国政府网）**

- 能找什么：国务院、国务院办公厅文件与部门文件，含发文字号、成文日期、发布日期、主题分类。
- 入口特征：按标题、发文字号、发文机关、主题词检索。
- 访问条件：免费。
- 登记时记什么：发文字号、成文日期、发布日期、发文机关；正文引注引发文字号，URL 只作核验通道登记。
- 常见坑：库内不一定标注废止状态；通知与其附件要分清引哪一件。

**国家法律法规数据库（全国人大常委会办公厅）**

- 能找什么：宪法、法律、行政法规、监察法规、司法解释、地方性法规、自治条例与单行条例；带时效性状态。
- 入口特征：按法规名、发布机关、效力级别、时效性筛选。
- 访问条件：免费。
- 登记时记什么：法规名、通过或修正日期、施行日期、时效性状态、发布机关。
- 常见坑：多次修正的法律须写明所引版本；部门规章不在此库。

**政府公报（国务院公报与省级公报）**

- 能找什么：正式公布的法规、规章、文件的权威文本，期号与页码稳定。
- 入口特征：中国政府网的公报栏目按年份期号浏览；各省政府门户有本级公报。
- 访问条件：免费；早年公报是否上网当次核验。
- 登记时记什么：公报名、年份、期号、页码；公报是规范性文件的正式公布载体，著录优先级高于网页版。
- 常见坑：公报刊登有滞后。

**北大法宝**

- 能找什么：法律法规（含部门规章、地方规章）、司法案例、法学期刊；法规有效力级别、时效性与修订沿革，案例有案号。
- 访问条件：机构订阅（当次核验）；`workflow-playbook.md` 已列为法规与案例的首选检索通道。
- 登记时记什么：法规记标题、发文字号、发布与实施日期、时效性状态；案例记案号、审理法院、裁判日期。
- 常见坑：平台的参照级别与引用次数是平台指标，不是法律效力。

**部委官网与政府信息公开平台**

- 能找什么：部委规章、规范性文件、政策解读、统计公报；信息公开目录含索引号。
- 访问条件：免费；依申请公开另有程序。
- 登记时记什么：发布机关、文号、发布日期、索引号、采集日期；网页易迁移，存本地 PDF 打印件并在注册表记路径。
- 常见坑：解读稿不是文件本身；新闻站、律所站等转载页不作来源。

### 3.7 当代报纸

**CNKI 报纸库（中国重要报纸全文数据库）**

- 能找什么：2000 年以来（部分更早）中央与地方主要报纸的文字层，条目带日期与版次。
- 入口特征：总库勾选报纸或在报纸库内检索；结果页格式与期刊相似。
- 访问条件：知网机构权限。
- 登记时记什么：报名、日期、版次；著录用 [N]。
- 常见坑：核心过滤不作用于报纸；文字层无页面影像，页码核证走人民日报图文库或原报影像。

**人民日报图文数据库**

- 能找什么：1946 年创刊以来的版面影像与文字，可按版次浏览。
- 入口特征：按日期翻版、全文检索；影像含版次角标，可作 A 级页面证据。
- 访问条件：机构订阅（当次核验）。
- 登记时记什么：日期、版次、栏目；社论与评论员文章的署名形式。
- 常见坑：转载通稿的报道来源写首发；同日多版同题须记版次。

### 3.8 二次文献与转载信号

**人大复印报刊资料（中国人民大学书报资料中心）**

- 能找什么：按学科分册全文转载已刊论文；转载本身是同行筛选信号；另有转载索引与转载排名。
- 入口特征：复印资料全文数据库按分册、原刊、转载期检索；部分期刊与作者在简介中自报转载情况。
- 访问条件：机构订阅（当次核验）；转载目录部分公开。
- 登记时记什么：转载分册与期号记入 `metadata`；引用仍引原刊，不引复印资料页码。
- 常见坑：转载有学科与刊物偏向，未转载不等于低质；转载版本可能有删节。

**《新华文摘》《中国社会科学文摘》（及《高等学校文科学术文摘》）**

- 能找什么：全文转载或论点摘编；全文转载是较强的同行信号，论点摘编是弱信号。
- 入口特征：知网期刊库内可检到转载条目（题名相同、来源为文摘刊）；文摘刊自身目录。
- 登记时记什么：转载类型（全文／摘编）与期号记入 `metadata`；引用引原刊。
- 常见坑：知网结果中来自文摘刊的同题条目与原刊重复，去重时保留原刊 Source ID。

### 3.9 港台与海外中文

### 3.10 学位论文

- 能找什么：博士论文常是唯一系统整理某一档案群、方志群或案例的长篇研究，附录常有原始数据与文书目录；硕士论文分量差异极大。
- 入口特征：知网博硕库（博士与优秀硕士两库）、万方学位论文库（部分院校只授权其中一家）、台湾博硕士论文知识加值系统。
- 访问条件：知网与万方机构权限；涉密或作者未授权的论文不在库。
- 登记时记什么：学位授予单位、学位类型、年份、导师（用于分量判断）、页码；著录用 [D]。
- 常见坑：核心过滤下学位论文整体被漏（`search-strategy.md` 第 5 节）；博士论文改写成的期刊论文与专著须识别同源，避免重复计数；优先引已出版版本，未出版部分引学位论文。

### 3.11 图书全文与页码核证

读秀／超星与全国图书馆参考咨询联盟：中文专著的书目核验（书名、作者、出版社、年份、ISBN）、目录与章节归属、页码影像。操作与证据分级见 `page-evidence/references/page-sources.md` ②③；无机构权限时联盟是免费兜底。登记时记版次与 ISBN，同书多版本认准与引用条目一致者。

## 4. 文献分量与低质识别

分量判断服务于 `critical-reading-and-synthesis.md` 的阅读裁决与 `literature-sufficiency.md` 的 `core-reading`／`background` 分配。它是相关性与内容核验之后的第三步，不能替代前两步。

### 4.1 分量信号表

| 信号 | 怎么读 | 边界 |
|---|---|---|
| 机构与作者 | 作者是否长期在该问题上发表；所在机构是否有该领域的档案或数据资源；同一作者的系列论文识别其立场演变 | 机构声望不等于该文分量；以作者在该问题上的既有工作为准，不以头衔为准 |
| 刊物层级 | CSSCI、北大核心、AMI 是进入主流对话的门槛信号；集刊在史学、古典学、法学中常比核心刊更专业 | 目录逐版变动，按刊发年份核当年身份；核心刊上的低质文章与非核心刊上的奠基文章都存在 |
| 被引数 | 按年龄归一：被引数除以刊发年数，与同年同学科文献比较；查引证文献的性质是实质对话还是列举式引用 | 综述、教材、方法文献虚高；史学与思想史整体被引低，跨学科比较无意义；网络首发与集刊被引近零 |
| 下载数 | 只反映关注度与教学使用 | 下载不等于质量；与热点、考试、标题相关 |
| 基金 | 国家级项目说明选题经过同行评审 | 基金只证明立项，不证明该文质量；基金挂靠与成果堆砌常见；无基金的史学考证不因此减分 |
| 转载 | 人大复印全文转载、《新华文摘》《中国社会科学文摘》全文转载是较强的同行筛选信号；论点摘编是弱信号 | 学科偏向明显；未转载不减分 |
| 争鸣与商榷文 | 题名含"商榷""质疑""再论""答某某"或摘要明确针对某文；它们标出真实反方，是覆盖门"真实反方"的直接证据 | 须同时读被商榷的原文与回应文，不能只引一方；分量按其论据而非姿态判断 |
| 自引与小圈子互引 | 引证文献中同作者、同机构占比高 | 高占比时对被引数打折 |

### 4.2 特殊文献类型的分量

- 学位论文：博士论文可承担事实与材料整理类主张，理论主张看是否已期刊化并经审稿；硕士论文默认只作线索与背景。
- 会议论文：正式出版论文集且有审稿的会议可作对话对象；只有摘要或未出版的会议报告作 `candidate-only`，引用须征得作者同意或引已发表版本。
- 集刊与辑刊：按主编与编委、出版社、连续出版年限判断；重要集刊的分量等同专业核心刊。
- 综述与教材：用于建立谱系与术语，不作承重证据；综述的结论须回其引用的原始文献。
- 网络首发：与正式刊出文献同等对待，但正式刊出前不得作为页码引注来源（4.4）。
- 增刊：多数核心目录不计增刊；增刊文章按非核心处理。

### 4.3 掠夺性期刊与低质会议识别

以下特征任一命中即在注册表 `reason` 记"疑似低质"；两项以上命中不得作为 `final-source`。

1. 收费与录用挂钩：以"交费即录用""加急发表"招徕。版面费本身在中文期刊普遍存在，不是判据；判据是收费与审稿脱钩。
2. 审稿周期异常短：承诺数日内录用；正规社科刊从初审到录用通常以月计。
3. 刊名仿冒与套刊：与正规刊名相近、以上旬刊／中旬刊／下旬刊或某某版名义一号多刊、无 CN 号或冒用 CN 号。核验方式是在国家新闻出版署官网的机构与产品信息查询中核 CN 号、主管主办单位与刊名是否一致。
4. 非法出版物名单：国家新闻出版署与各地"扫黄打非"公布的非法期刊名单；国际刊参照中国科学院文献情报中心的《国际期刊预警名单》。
5. 征稿方式：群发邮件征稿、代理征稿、以"知网／万方收录"作卖点——知网收录不是质量证明。
6. 内容特征：学科大杂烩、单期文章数异常多、作者集中于非研究机构、参考文献极少或全是网页。
7. 低质会议：主办方为会务公司而非学会或高校院系、承诺 EI／CPCI 检索、高额注册费、主题跨十余学科、论文集由无学术声誉的出版方出版。
8. 一稿多投与重复发表：同一作者同题同摘要出现在多刊，按同源处理并在 `reason` 记录。

核验动作：查 CN 号与主管主办单位；查 `cnki-journal-index` 的收录标签（收录标签不等于分量，见该技能末节）；查该刊是否曾被核心目录剔除并核原因；记核验日期。

### 4.4 网络首发到正式刊出的卷期页回改规则

1. 登记：`cnki-parse-results` 与 `cnki-paper-detail` 返回 `isOnlineFirst=true` 的条目，在 `metadata` 记 `online_first=true`、首发日期与 DOI，`verification` 注明核验的是首发版。
2. 引用格式：正式刊出前按 `cn-journal-conventions.md` 第 10 节的电子期刊格式；不得写卷期页。
3. 定稿前复核：对所有 `online_first=true` 的条目回知网详情页看是否已显示卷、期、页；已刊出者回改卷期页，删除引用日期与 URL（DOI 可保留），并重核正文中引用的页码与引文文字——首发版与正式版页码几乎必然不同，文字偶有差异。
4. 页码引注：首发版页码只能作 `page-evidence` 临时定位，Status 保持【VERIFY】直到正式版页码核完。
5. 未刊出者：保留电子期刊格式，注册表记复核日期。`intl-export/references/gbt7714-cn-types.md` 的失败模式第 12 项与此同口径。

### 4.5 撤稿与更正

- 查法：中文文献看知网详情页是否有撤稿或更正标记与期刊官网声明（撤稿论文可能已下架，旧导出记录须回详情页确认仍在线）；查 Retraction Watch 数据库（收录部分中文刊）；外文看 `intl-search` 的 `is_retracted` 并回出版社页核实。
- 处理：确系撤稿——不得作为支撑来源，只能作为撤稿事件本身的研究对象并在正文明示；更正或勘误——核对更正后内容再引用，`verification.retraction_status=corrected-version-verified`；关注表达——降为 `candidate-only` 直到状态明确。
- 登记：`verification.retraction_status` 与 `retraction_checked_at` 按 `acquisition-registry.md` 5.1 填写；已入引用库的条目在每次 `sync` 前复查。

## 5. 登记与分工

- 本文之于 `primary-source-citation.md`：本文说去哪找与找到后有多重，该文说材料是几手、用哪个版本、怎么著录、怎么考证。
- 本文之于 `acquisition-registry.md`：本文说各渠道登记时要多记哪些内容，该文规定字段、状态与证据等级本身。
- 本文之于 `page-evidence/references/page-sources.md`：本文指出哪些渠道能产页面影像，该文规定 A/B/C 分级与图书类渠道的操作。
- 本文之于 `cnki-search/references/search-strategy.md`：该文管知网内检索式、字段、过滤与饱和，本文管知网之外的渠道与文献分量。

任一渠道发现的材料若拟引用，元数据须回该渠道的条目页或纸本核验后再入注册表；多渠道同一材料只建一个 Source ID，通道差异记在 `query_ids` 与 `verification.content_url`。
