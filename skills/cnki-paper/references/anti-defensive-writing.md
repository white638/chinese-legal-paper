# 中文学术写作的反防御重构协议

## 1. 目标：让边界进入论证，不让作者与假想批评者谈判

防御性写作不是谨慎本身，而是表达重心发生了偏移：作者先解释自己不主张什么、不会做什么、可能遭到何种误解，再迟迟交付研究对象、证据和判断。它常见于摘要、引言、贡献段、主题句和结论等高影响位置，也可能把一个段落拆成“免责声明—让步—自我限缩—微弱推进”的答辩链。

反防御重构的目标是让读者先获得真实主张，同时完整保留会改变以下事项的限制：

- 主张是否成立；
- 证据应如何解释；
- 结论适用于哪些对象、时间或情境；
- 研究设计和材料处理是否透明；
- 结果能否被正确使用；
- 法律、伦理、安全或作者责任是否得到履行。

因此，“更有力”不等于删掉所有限定，也不等于把有限证据改写成确定断言。好的改写把证据强度、适用范围和责任说得更准确，同时减少面向假想批评者的自我保护。

## 2. 两个诊断测试

### 2.1 信息贡献测试

暂时删除可疑句，检查是否损失主张、证据、担保、必要范围、方法透明度、反证、法律伦理责任或正确使用结果所需的信息。

- 没有任何损失：删除，或与相邻句合并；
- 信息有损失：保留信息，但不保留原来的防守姿态；
- 无法判断：先回到证据与主张身份，不用语气判断代替事实判断。

### 2.2 假想批评者测试

假定不存在正在挑错的审稿人或读者，这句话是否仍能帮助一个善意的专业读者复原“对象发生了什么—证据显示什么—作者作出什么判断—判断在何处成立”？

- 只为预防一种尚未出现的误解而存在：删除或把真正需要的信息并入正面主张；
- 对正确理解当前证据不可缺少：改写为精确范围、证据限制或概念区分；
- 回应有来源、同一问题且会改变判断的真实反方：保留学术分歧，但用来源—判别证据—校准结论呈现，不写成模拟审稿对话。

## 3. 先判功能，再决定写法

不要从替换“不是、并非、但是、可能”等词开始。先把每个可疑单元归入下列真实功能；一个单元可以包含两种功能，但每种信息都要有明确去向。

| 功能 | 判准 | 默认动作 |
|---|---|---|
| 无必要免责声明 | 删除后不损失任何承重信息，只减少对假想误解的预防 | 删除 |
| 重复澄清 | 已由主张、定义或前文边界表达 | 合并或删除 |
| 真实负面结果 | “未发现／无差异／未发生”是已登记结果本身，有分母、比较或时间范围 | 按原方向与不确定性保留，不改写成肯定结果 |
| 必要范围条件 | 改变对象、时间、案例、适用场景或外推范围 | 改写为正面范围，并放在首次需要处 |
| 真实方法限制 | 来自样本、测量、识别、材料、时间窗口或分析步骤，且改变证据解释 | 写明限制来源及其改变的主张；在方法、分析或讨论的承重位置集中说明 |
| 证据性限定 | 不确定性来自可指出的证据状态 | 指明不确定性的来源，并使用与证据相称的判断强度 |
| 有用概念对比 | X/Y 的区别本身是论证对象，有来源、定义或判别依据 | 保留对比；优先直接写两者各自是什么、如何区分 |
| 法律／伦理／安全边界 | 删除会导致错误使用、违规或伤害 | 明确保留，不为追求“自信”弱化 |
| 必要作者责任 | 作者必须交代材料选择、排除规则、编码分离、分析决定或利益冲突 | 直接说明所作选择及其后果，不隐藏在泛泛自述中 |

## 4. 六种处置动作

### 4.1 DELETE：删除无信息防守

“需要说明的是”“为避免误解”“本文无意”“这并不意味着”若只是在预演批评而没有新增承重信息，整句删除。删除后重新连接前后句，不能留下逻辑断口。

### 4.2 DIRECT-CLAIM：把主张放回句首和段首

防御式：

> 本文并非试图提出一种普遍的协同理论，而只是对现有材料中的责任变化作出有限说明。

直接式：

> 现有材料显示，事项移交权转入牵头部门后，跨部门响应由逐级请示转为直接协调。

若还需范围，随后说明材料来自哪些对象和时段；不要用“有限说明”代替实际边界。

### 4.3 POSITIVE-SCOPE：把排除声明改成正面范围

防御式：

> 本文不讨论全部政策阶段，也不主张结论适用于所有地区。

范围式：

> 本文考察政策执行初期的三个地级市场景，结论适用于相同授权结构下的组织协调。

正面范围必须来自真实设计，不得把“未覆盖全部”擅自改成“覆盖关键变异”。

### 4.4 SPECIFY-UNCERTAINTY：说明不确定性从哪里来

防御式：

> 这一结果在一定程度上可能说明平台或许改善了回应能力。

精确式：

> 平台接入与回应时间缩短相关；横截面设计未构造反事实，因此该结果不支持因果效应判断。

限定要指向样本、测量、识别、材料、时间或外推中的具体来源。多个“可能、似乎、一定程度上”叠加而不说明来源，仍是防御性写作。

### 4.5 RELOCATE-AND-CONCENTRATE：把边界放到它真正改变主张的位置

同一限制不应在摘要、引言、方法、分析和结论重复播报。选择一个承重位置完整说明其来源与后果；高影响位置只保留理解该句不可缺少的短限定。结论先直接回答研究问题，再集中交代范围，不能以局限清单开篇。

### 4.6 KEEP-WITH-MATERIAL-ANCHOR：保留真正承重的限定、对比和责任

保留不是失败。原文引语、文献题名、真实概念对比、必要方法透明度、证据能力、法律伦理边界和作者责任可以保留，但不能由作者自己写一句“有必要”就取得豁免。须同时给出已登记的 Source/Evidence/Design/Execution/Ethics/Responsibility 锚点、被改变的 Claim ID、具体 claim delta、完整说明唯一出现的位置及去重记录。若只想显得谨慎、预防想象中的误解，或不能说明删去后哪项判断会失真，返回前五种动作。

## 5. 必须重建段落，不能只改触发句

逐句换词往往保留原来的答辩结构。完成分类后，把段落按以下次序重新组织：

1. 研究对象、行动或当前关系；
2. 本段希望读者接受的直接判断；
3. 最能承重的材料或证据；
4. 证据为何支持该判断的担保／分析；
5. 只有在改变当前判断时才出现的范围、反证或含义；
6. 与下一论证任务的真实承接。

每段只承担一个主任务。若一段同时包含贡献、道歉、例外、方法局限和未来研究，先拆分功能，再决定哪些内容属于正文、方法、讨论或应删除。

## 6. 高影响位置的交付次序

| 位置 | 先交付 | 限制如何出现 |
|---|---|---|
| 标题／摘要 | 对象、问题、证据进路、核心答案 | 只保留理解答案不可缺少的对象或推断边界 |
| 引言／贡献段 | 真实张力、已有成果、剩余问题、本文的有限推进 | 不以“本文不做什么”开场；限制放在它改变贡献的句子之后 |
| 主题句 | 当前段落的判断或分析方向 | 不以让步、免责声明或作者意图占据段首 |
| 方法 | 关键材料选择、排除、编码、识别和伦理责任 | 必要作者责任可直接出现，说明选择及后果 |
| 结果／核心分析 | 发现、材料、担保 | 句内边界只在它改变该发现时出现 |
| 讨论 | 结果如何修正认识、竞争解释、适用条件 | 集中承载真实方法限制与外推边界 |
| 结论 | 对研究问题的实质回答与认识增量 | 回答之后用最短充分文字交代范围和未决问题 |

限制若对当前句的准确性不可缺少，可以留在任何位置；“集中安置”不能变成把关键边界一律推到文末。

## 7. 中文常见防御信号

以下只触发上下文复核，不是禁词表：

- 作者意图否定：“本文不把／不试图／无意／并非旨在……”；
- 预防误解式说明：“为避免误解／需要澄清的是／这并不意味着／不应据此理解为……”；
- 让步式自我削弱：“尽管样本有限／虽然存在不足……但仍具有一定价值”；
- 否定转折惯性：“不是／并非／不在于……而是／而在于”；
- 模糊限定叠加：“可能、或许、似乎、在一定程度上”同时出现；
- 审稿对话前台化：“最强质疑认为／这一质疑部分成立／本文材料所能支持的是……”；
- 贡献先道歉、结论先列局限、段首先写例外；
- 同一边界在多个章节重复，或用长 caveat 保护一个本可精确表述的简单判断。

表格另做一次正面可恢复性检查，但不统计“不”字：逐行问读者能否直接说出对象拥有什么材料、接受什么比较、允许什么核对。连续的“不作、未见、不能、失败”若只是内部操作记录，应改为正面范围、材料身份或可观察状态；若“无、零、未发生”本身就是研究结果，则保留，并在表头或表注给出分母、时间范围和比较基准。表内缺失不能自动升级为正文中的“不能／必须”结论，推断仍须另有担保。

判断单位是句子在段落中的功能，不是词频。必要的“不是……而是……”可以比强行改成绕口的正面句更清楚；一连串没有否定词的“需要说明、值得注意、必须承认”同样可能是防御性写作。

否定处置因此固定按功能分类，不做统一删除：真实负面结果保留方向；有实质判别功能的概念对比保留；范围排除优先改为正面范围；作者意图防守删除或重写；审稿、回复和流程语言硬失败。

还要检查不含触发词的结构性防御：段落是否仍按“质疑—让步—回复—再限定”推进，章节是否复刻评论到来顺序，新增定义、过渡或边界是否与前后术语、指称和推理脱节。即使完全没有“审稿人”三字，只要善意读者能反推意见序列或看到后插补丁接缝，仍须先归并功能，再整段或整节重建。

## 8. 与 CNKI-Paper 审计的接口

### Direct route

局部改稿先冻结原段的主张、证据、范围、反证和必要责任，完成两项测试与功能分类后，直接交付重建后的段落。除非用户要求审查报告，否则不先给一页问题清单，也不创建工作区工件。必要时用一句话说明保留了哪项关键边界。

### Workspace route

在 `academic_prose_audit.md` 的风险表达处置表中扩展当前行，不新增第二事实表：

- `Decision` 使用 `DELETE`、`DIRECT-CLAIM`、`POSITIVE-SCOPE`、`SPECIFY-UNCERTAINTY`、`RELOCATE-AND-CONCENTRATE` 或 `KEEP-WITH-MATERIAL-ANCHOR`；
- 只有最后一种决定填写稳定的 `Boundary ID (B-*)` 以及可核验的 `Anchor ID`、`Claim ID`、`Claim Delta`、`Placement` 与 `Dedup Record`；锚点必须来自现有事实工件，不由本表新造；唯一完整文本与位置按 `Boundary ID` 去重，同一 Anchor 可支撑不同 Claim 的不同边界；
- `Reason` 写明真实功能、受保护信息及其去向；
- `Final Text` 必须是当前正文中的实际文本，不能只写改写意图；
- 当前正文仍保留触发结构时，逐处说明为何它承担不可替代的对比、责任或边界。

如果清晰度编辑发现缺少局部担保或登记术语首次出现不可理解，只能按 `academic-prose.md` §1.2 的合同执行 `BRIDGE` 或 `DEFINE` 并写入 `avereth-clarity-edit-ledger/v1`；门禁直接比较前后稿并阻断新增数字、citation-like anchor 与引文，没有合法锚点的增长失败。

独立读者先指出各承重单元最早出现的实质判断，再判断是否有免责声明、让步或作者意图延迟了它；随后复原证据与边界。读者若只能说出作者在防什么，却说不出对象、发现和判断，正文必须重建。

## 9. 忠实性与前向评测

改写前后做一次语义零损失对照：规范命题的主体／对象、关系、方向／极性、推断强度、范围，以及事实、数字、引文、定位、来源声音、反证、负面结果、设计限制、适用范围、法律伦理边界和必要作者责任都不得丢失。比较新旧版本时，只有同时满足以下条件才算改进：

1. 读者更早、更准确地复原对象—问题—答案；
2. 证据、担保和推断强度没有被增强或削弱；
3. 必要边界仍在最能改变主张的位置；
4. 段落不再以假想批评者为隐含对话对象；
5. 防御负担下降，解释链与论证信息不减少；必要的局部 `BRIDGE` 或 `DEFINE` 即使带来小幅增长，也不应为追求形式上的“零增长”而删除。

若只是把“本文不主张 X”换成“本文聚焦 Y”，却仍未说清 Y 的实质判断、证据和范围，视为未改进。若删掉限制后主张变强，立即回滚。

# Rhetorical movement is not defensive staging

An epistemic hook delays only a registered answer for a declared comparison or evidence encounter; it never manufactures mystery or withholds an available result. A quotation or scene enters through a content-verified Context Anchor, and a closing return must deepen the original problem rather than decorate or repeat it. See [`rhetorical-architecture.md`](rhetorical-architecture.md).
