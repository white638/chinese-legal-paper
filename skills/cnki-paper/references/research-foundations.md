# 研究基础：认识论自检而非范式排名

## 作用

`research_design.json.epistemic_position` 记录研究赖以成立的知识前提。它帮助检查问题、材料、方法和主张是否相容，不给“实证主义”“诠释主义”等标签自动加分，也不把某一种方法当作社会科学的默认最高等级。

至少说明：

- `ontology`：研究对象被视为稳定实体、关系、过程、意义建构、制度实践，还是这些要素的组合；
- `epistemology`：何种观察、解释或论证能构成知识根据；
- `paradigm`：研究采用的公开立场；可写组合，但需解释兼容性；
- `research_logic`：`deductive`、`inductive`、`abductive` 或 `mixed`；
- `researcher_position`：研究者与对象的关系、进入条件、利益和可能影响；
- `compatibility_rationale`：上述前提如何与各 Design ID 的材料和推断方式共同成立。

范式字段缺失或跨工件自相矛盾可以硬检；“所选范式是否最有洞察力”进入独立解释性评审并保留论证记录。

## 科学性自检

跨方法共同要求不是统一技术，而是：

1. 问题与答案任务明确；
2. 概念和材料边界可识别；
3. 证据来源、变换和用途透明；
4. 竞争解释、反例或反证条件可见；
5. 推断不超过设计和证据；
6. 变更、负面结果和不确定性不被隐去；
7. 在合法权限下可复核研究过程。

“可复核”不等于所有原始材料必须公开。隐私、版权、档案或平台条款限制公开时，应提供元数据、代码、参数、受控访问路径或可复算替代材料，并诚实声明限制。

## 研究逻辑与适用结构

| 逻辑 | 主要运动 | 设计中应留下的记录 |
|---|---|---|
| 演绎 | 理论预期 → 观察检验 | 假设/命题、识别或区分预期、反证条件 |
| 归纳 | 材料比较 → 概念/类型/理论 | 选择边界、编码/比较过程、负面案例、理论生成轨迹 |
| 溯因 | 异常 → 竞争解释 → 最佳解释 | 异常、替代解释、区分性证据、修订记录 |
| 组合 | 多种逻辑按顺序或功能整合 | 每条路线的角色、交接、材料独立性和综合上限 |

没有假设不等于没有研究逻辑。描述、诠释、概念、规范、历史和综述路线可用命题、分析框架、论证图、竞争解读或综合逻辑。

## 外部校准

- AERA 的经验社会科学报告标准用于校准问题、方法、证据和推断的透明披露；
- SRQR 用于校准定性研究的情境、研究者位置、抽样、分析和限制；
- NASEM 的 reproducibility/replicability 报告用于校准可复核与计算透明性。

权威来源清单和教材逐节映射位于 `evals/research-methods-v31/`；报告规范只用于其声明的范围，不被偷换成方法质量等级。
