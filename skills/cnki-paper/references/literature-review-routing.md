# 文献综述路由

## 先声明综述的答案任务

| 类型 | 主要任务 | 设计字段 | 报告连接 |
|---|---|---|---|
| `embedded` | 为论文定位问题、概念、理论和方法 | 检索范围、阅读记录、综合逻辑、真实空白 | 不强制 PRISMA |
| `narrative` | 形成有边界的解释性或理论性综合 | 来源选择理由、质量判断、矛盾证据、叙事综合 | 不得冒充穷尽性系统检索 |
| `scoping` | 描绘概念、证据类型、范围和研究缺口 | 多源检索、筛选、分类/图谱、范围边界 | 采用适用的 PRISMA-ScR 报告项 |
| `systematic` | 用预先声明的方法回答明确综述问题 | 协议、检索式、筛选、提取、质量评价、综合 | 接入 `aers-prisma-slr` 与 PRISMA 2020 |

PRISMA 是报告框架，不自动证明检索全面、纳入研究优质或综合结论正确。非系统综述不因没有流程图而失败；系统综述若漏报检索、筛选或研究清单则不能通过。

四类综述共享 `critical-reading-and-synthesis.md` 的阅读—裁决—综合内核。类型差异决定检索、筛选、报告和可声称的覆盖范围，不取消全部 `final-source` 的批判性阅读，也不允许用系统综述流程图替代逐篇证据判断。

## 共同事实链

所有综述路线使用唯一来源注册表，并至少记录：

1. 数据库/来源、检索日期、检索式和时间/语言/文献类型边界；
2. 去重与筛选规则、排除理由和筛选日志；
3. 全部 final-source 对应的 `CR-*` 检视地图、独立证据判断、作者结论比对及可引用状态；
4. 按来源类型适配的质量评价、判断依据、不适用理由与利益关系；
5. `SYN-*` 综合逻辑：来源关系、可比性、评价权重、冲突解释与分析者判断；
6. 相互矛盾、负面、异常或不可比证据如何处理；
7. “空白”是否可能来自术语错配、发表时滞、检索边界、不可比性或质量排除。

系统综述的搜索数、筛选数和纳入数必须可复算。嵌入式和叙述式综述也必须披露选择边界，但不伪造穷尽性数字。

来源阅读与综合的唯一事实写入 `literature_analysis.json`；`research_design.json.knowledge_state` 只保留设计层摘要并引用相应 `CR-*`／`SYN-*`：

| 契约字段 | 内容 |
|---|---|
| `review_type` | embedded、narrative、scoping 或 systematic |
| `search_scope` | 来源、日期、检索式及时间/语言/文献类型边界 |
| `screening_rules` | 去重、纳排、排除理由和日志位置 |
| `reading_records` | 相关 `CR-*` 与 Source ID 范围，不复制逐篇裁决 |
| `quality_appraisal` | 相关 `CR-*` 类型判准、适用性与如何影响设计 |
| `synthesis_logic` | 相关 `SYN-*` 及主题、理论、计量、配置或其他综合路径 |
| `contradictory_evidence` | 相关 `SYN-*` 的矛盾、负面、异常与不可比证据处置 |

这些字段即使在 embedded/narrative 路线也不能为空；可以诚实声明非穷尽性或某种评价不适用，
但不能用“未记录”冒充完成。

## 与 CNKI 获取层的关系

`reference_materials/literature_registry.json` 是书目和内容核验的唯一事实源。综述路线引用 Source ID，不另建书目真相。CNKI 结果页命中只构成候选；详情页或全文内容核验后才能成为承重来源。需要页码的主张仍须单独通过页码证据审计。

内容核验按主张分级：摘要／详情页可记录作者公开立场和窄描述，但其 `CR-*` 必须为 `limited`，不能据此裁决方法、结果、因果／机制、稳健性、一般化或跨文献冲突。上述承重判断要求合法全文及页／节／图／表／数据／材料锚点。

## 从矩阵到综述正文

综述段落以问题、命题、机制、争议或条件组织，而非按作者逐篇排列。每个承重段落应能回溯到一个或多个 `SYN-*`，并依次交付：问题化判断、来源关系、差异／异质性解释、分析者有界综合、剩余研究责任。`cross-source-synthesis` 的身份要求至少两个来源，但不把它扩张成每段固定篇数；单一关键立场可以保留为 `single-source-position`，不得称为领域共识。

## 真实空白

`gap_test` 至少比较：

- 同义词、近义概念和相邻议题；
- 不同时间范围、单位与结果变量；
- 既有研究已经回答的关系与尚未区分的机制/条件；
- 低命中是否由访问、索引或发表时滞造成；
- 新研究是否真正改变解释、测量、比较、边界或行动判断。

比较完成后按 `research-gap-diagnosis.md` 形成一个主落点与至少一个阻断原因，并把具体未知、当前 `SYN-*`、替代解释、研究责任和撤回条件写回原有 `Gap Reality Check`。知识空白是该诊断的总体状态，不另加并列类别；概念歧义只有改变分类、测量或可比性时才成立，方法更新只有修复明确盲点或识别失败时才成立，群体缺席只有触发迁移边界、异质性或知识公平责任时才成立，实践意义只有形成主体—目标—约束—证据—评价链时才成立。

“没有完全相同标题”“文献很少”“用了新算法”“某群体未研究”与“有现实意义”都不能单独构成真实空白。
