# 中文学术文笔协议：让论证可追踪、可质疑、可记忆

## 1. 定位与边界

本协议用于各发表轨论文正文已经有真实研究问题、贡献、证据和主张边界之后的表达重建，按语言与体裁适配。它不替代研究设计、引用核验或结果验证，也不把文笔误当成句长、主动语态比例或“像不像 AI”的单项分数。

以下写作原则默认用于所有学术写作入口，包括 Direct 局部写作、clear 与 distinguished 模式；中文示例说明论证功能，其他语言按其学科、体裁和目标刊惯例实现。Direct 不因应用这些原则而新建工作区或审计表。增强模式可以提高修辞辨识度，但清楚辨析、作者判断和材料参与论证不是增强模式的专属要求。

好文笔的操作定义是：让目标读者以尽可能低的认知成本，准确复原本文的主张、证据、推理和适用边界。总原则是**修辞立其诚**：结构、语态、节奏、例子和作者声音都必须帮助读者理解真实研究，不能用“像论文”的形式感遮蔽内容空洞，也不能以“可读”为名删去证据、反证和边界。

固定位置：

1. 先通过 confirmed_contribution.md、research_design.json（及其生成视图）、terminology_register.md 和 `method_execution.json` 的规范下游资格投影；`results_validation.md` 仅作派生说明视图。
2. 按 section_blueprints.md 与 writing_rationale_matrix.md 写出完整正文。
3. 在格式润色、LaTeX/Word 组装和 AIGC 风险调整之前，先闭合问题承诺—执行证据—定稿标题回环，再执行本协议的外至内改稿序列。
4. 全部结果写入唯一工件 `academic_prose_audit.md`，运行 `scripts/academic_prose_check.py`；checker 从 `workflow_config.json` 读取 `prose_mode`（journal/conference 默认 `distinguished`，其余默认 `clear`）。
5. 未通过时回到正文或协议指定的上游阶段，不得靠填写空洞审计表绕过。

控制面与正文面必须隔离。控制器、来源／设计／执行事实、对话图和审计表保留完整后台；

语义原子（主体／对象、关系、方向／极性、推断强度、范围、数字、引文、locator/citation

边界／反方和具体读者更新；不透明 ID 列表不足以供隔离写作者成稿，完整 evidence bank、审稿意见和
回复信又不得越过防火墙。规范命题默认要求语义保真而非逐字重复；只有直接引语、法条、正式假设、

`realization_mode=semantic`；省略字段仅用于旧包的 `legacy_exact` 兼容，不能借此关闭新稿的语义保真检查。

它不是新阶段、事实表或凭证。默认正文内部链为 `ProsePacket → Writer →
deterministic protected-atom gate → Clarity Editor → Explanation/Leakage Gate →
Semantic Fidelity Gate → Clean-read Audit`。

按 `commonplace-writing.md`，`prose_conditioning=auto` 主动检索已核验范例，并按当前 Move 实际匹配结果提供语言包；仍无合格范例时记录缺口，以 ProsePacket 继续该 Move，其他 Move 不受影响。显式 `commonplace` 保留原有严格双包合同。双包写作分别检查 Writer 与 Clarity 的逐来源借用；语义写作保留既有事实、Clarity 与语义保真链，显式锁定全文保留当前权威的逐字校验。证据包独占事实和引文权限，语义评审不读取语言范例；普通 Claim 的 semantic 默认不覆盖引文、登记定义及用户锁定文本的 verbatim 保护。

`avereth_compressor` 保留兼容文件名，实际执行有证据边界的清晰度编辑；它只能 `DELETE`、`REPLACE`、`MOVE`、`BRIDGE`
或 `DEFINE`。`BRIDGE` 只显化已有 warrant／explanation path，`DEFINE` 只解释精确登记的受保护术语；两者都不得
新增事实、引用、案例或更强推断，门禁须直接比较前后稿的数字、citation-like anchor 与引文，不接受台账自我声明替代。
节级 5%、段级 15% 是默认再读软诊断，可用 `clarity_growth_soft_limits` 显式调整，不是机械拒绝线、质量分数或
完成权威。Semantic Fidelity Gate 先用 `semantic-dispatch` 固化只含 packet＋draft 的 canonical prompt 与 writer／clarity
context，再由第三个隔离 context 生成 `avereth-semantic-fidelity-review/v1`；`semantic-assure` 绑定 manifest、prompt、
raw output、限定输入域及各文件 SHA-256，`semantic-fidelity` 逐项验证 provenance、双向命题一致、主体／关系、方向／极性、
强度、范围、证据作用与边界；这些瞬时记录都不是 stage receipt。
工作流状态、失败门禁、评审角色、完整审计表和未激活异议不得穿过 prose firewall。

解释优先不是一种新文体。每个承重单元都应让读者恢复四个答案：发生了什么，为什么发生，证据如何支持这一解释，
以及这会改变什么认识。证据不只要“出现”，还要说清它在推理中用于建立模式、识别过程、区分替代解释还是校准范围。
整篇改稿若使用 `DEFINE`，还必须在 `revision_contract.expression_budget.registered_terms` 以数组登记可解释术语，`clarity_actions[].source_anchor` 与其精确匹配；审稿意见或回复信中出现过的词不因此自动成为术语锚点。

凡任务涉及防御性写作、辩解腔、过度谨慎、贡献自我削弱或 caveat 堆积，完整读取 `anti-defensive-writing.md`。该协议负责“功能分类—信息迁移—段落重建—忠实性复核”；本文件负责把结果放回整篇结构、论证链和审计工件。二者都不把触发词当自动错误。

三条不可越过的边界（distinguished 增强遍尤其适用）：

1. 不把长句、生僻词、排比或古雅词汇当作高水平文笔。
2. 不用修辞制造研究中不存在的洞见。若材料不能支持新的区分、机制、边界或含义，返回 research、design 或 execution 的事实拥有阶段。
3. 不以风格换取失真。事实、数字、引文、反证、限制和推断边界任一损失，增强即失败。

### 1.1 形式边界与叙事包装（Narrative Wrap）

期刊论文仍须遵守目标刊的体裁契约：引言、理论/文献、方法、结果、讨论以及必要图表、统计量和引文一个都不能因“讲故事”而省略。创造性发生在这些边界内部：作者把材料组织成一条读者能够跟随的理解路径，而不是发明一种脱离学术共同体预期的新形式。

论文有两层同时运行：

1. **信息层**：概念、文献、材料、数据、方法、结果、反证和边界，回答“研究知道了什么、凭什么知道”。
2. **引导层**：为什么此刻需要知道、每一节在解决什么、读者应如何理解当前证据、这一认识改变了什么。这个人为构建的理解路径称为叙事包装。

叙事包装只指认知推进，不是文学化，也不是把真实研究过程按时间顺序照搬。用五阶段检查整篇论证是否连续：

| 故事阶段 | 学术任务 | 常见位置 | 读者此刻的问题 |
|---|---|---|---|
| 背景铺陈 | 交代对象、既有认识与必要语境 | 引言、文献回顾 | 我们已经知道什么？ |
| 张力上升 | 暴露异常、理论冲突、误判或解释不足 | 问题提出、理论部分 | 为什么现有理解不够？ |
| 核心回答（高潮） | 提出解释，并让最强证据回答研究问题 | 假设、发现、核心分析 | 本文究竟发现或论证了什么？ |
| 解释与边界（张力释放） | 解释结果、处理替代解释、反证和范围条件 | 结果后段、讨论 | 为什么这样理解，而不是另一种？ |
| 认识结局 | 说明本文改变了什么、贡献在哪里、仍留下什么 | 讨论、结论 | 接受本文后，我应怎样修正原有认识？ |

五阶段可以跨越传统章节，但不能成为五个新盒子；每一阶段必须把问题交给下一阶段，传统章节也必须说明自己在整条认知路径中的任务。论文不能像小说一样隐藏结论，更不能为了故事顺滑删除负结果、竞争解释或局限。

理论、构念、研究情境和经验主体都可视为论证中的“角色”，但角色化不等于拟人化：每个角色必须承担明确功能。主角通常是核心现象、机制或问题；理论是解释工具，情境说明为何能显露该机制，行动者则让读者看见谁在何种约束下作出什么选择并承受什么结果。删去一个概念、变量或文献段落后主解释完全不变，说明它多半是无功能角色。

四种工具贯穿各阶段：

- **人的面孔**：在分析需要时写出行动主体、选择、约束和后果；研究宏观制度也不要无故抹掉所有行动者。
- **运动与节奏**：关键机制、异常和竞争解释充分展开，常识背景快速交代；篇幅按论证功能分配，不按作者开展研究的时间顺序分配。
- **展示与解释**：用数据、案例、事实、引语或图表让读者“看见”，随后明确说明证据支持什么、不能支持什么；材料堆砌和无据断言都不合格。
- **接近交流的清楚表达**：行动者重要时优先主动语态；研究动作或论证选择需要负责时，可在目标刊允许的范围内使用“我/我们”。这不是主动语态比例或第一人称配额，被动语态在过程、对象或结果需要成为焦点时仍可使用。

合作写作与审稿修改也按叙事协调处理。合作者先统一“问题是什么、核心机制是什么、最大贡献是哪一个、哪些材料属于主线”，再分段落措辞；收到审稿意见后重画叙事包装图，判断意见触及哪一阶段和哪条证据链，不能采用“评论一条、正文补一句”的补丁式修改把全文越改越散。

### 1.2 前台对象与后台控制

论文前台让读者看见研究对象、材料及作者据此作出的判断，而不是研究者正在防守什么。承重单元须使**研究对象／行动者及其变化、材料或证据、关系／机制／规范判断和改变该判断的必要边界**可恢复；这是论证责任，不是固定出场顺序。可以从事实、引文、文本细节、真实设问、概念区分或当前判断进入，按认识推进组织。分析框架、作者贡献定位和研究过程可以帮助解释，但不能长期占据句子主语和段落中心；它们一旦使对象、行动、材料和实质答案退到背景，就从工具变成了阅读障碍。

最强反方、预演审稿意见、证据审计表和贡献辨析属于**论证后台**。后台结论必须进入前台的主张力度、证据选择、替代解释处置或适用范围，却不得按“质疑—回应—让步—限定”逐项誊写。所谓反方处置“可恢复”，是指读者能够从公允的文献定位、判别性证据和校准后的结论看出反方改变了什么；并不要求正文出现四个标签或一段模拟审稿答辩。

逐段执行一次**对象检验**：暂时删除以“本文／本研究／笔者”开头、只说明研究动作或作者意图的句子，然后让读者回答三问——研究对象发生了什么，证据显示了什么，作者据此作出什么判断。任一问题无从回答，说明该段的自我说明压过了对象，应按段落功能重建这些关系。该检验不禁止作者在场：概念由谁提出、材料如何处理、哪项选择需要负责或何处必须限定时，作者自述可以保留；判准是它是否承担不可替代的责任，而不是“本文”出现次数。

例如，与其写“本文不把需求响应作为新理论，本文所做的不是另造流程，而是提出判准”，不如直接写：“在基层公共服务场景中，需求响应指需求信息经筛选和责任确认后改变项目、资源或续退决定的组织过程。流程是否齐全并非判准；决定是否随反馈变化，才区分实质回应与程序记录。”必要的证据边界随后集中说明。这里保留的“并非”承担真实判别功能；第一句的作者防守信息则已经迁移为对象定义和判断。Direct route 也执行同一对象检验与 `anti-defensive-writing.md` 的两项诊断测试，但不要求创建本协议的工作区表格。

### 1.3 同行使用检验：题名、摘要、关键词与表格

学术表达首先服务于同领域读者的检索、初步判断和复核。题名、摘要、关键词和表格不是正文完成后的装饰，而是同行进入论证的四个入口；它们应当让读者在尚未掌握作者内部流程时，仍能找到论文、判断论文解决什么问题，并理解材料与结论之间的关系。

- **题名**：用研究对象、问题或实质答案及必要范围形成可检索的压缩契约；修辞只能压缩真实张力，不能遮蔽对象或替代答案。
- **摘要**：交付具体问题、材料／分析进路、实质答案和贡献边界。只写“本文拟、旨在、构建、分为”或只列框架与章节，属于研究计划或导言，不是同行可据以判断价值与可靠性的摘要。
- **关键词**：选用能准确检索研究对象、问题和关键关系的学界通行术语，与题名、摘要和正文实际用词一致；不把临时框架名、宽泛口号或只在边缘出现的词列为关键词。
- **表格**：表题、列名、行值和表注共同说明比较谁、依据什么材料／指标、呈现何种关系。表格应能脱离作者的编码日志基本自足；“来源获取失败、核验状态、请求超时”等写作过程信息留在后台，前台改写为可观察的材料条件及其对当前主张的影响。负向表述不是禁词，但若同一列连续写“不作、未见、不能、失败”，迫使读者反向猜测每行实际具有什么信息，就应改用正面范围、材料身份或可执行核对动作；科学上承重的缺失值和否定结果仍须保留并定义比较基准。

另做一次**缺失—结论检验**：某类型未出现、频数为零或材料没有记录，只能直接说明样本中的观察分布，不能单独证明某做法“不可能”、某条件“必须”具备或某因素“足以”产生结果。若要作此类约束性或因果性判断，须写出至少三项：与什么反例或对照相比、缺失为何会产生该结论的作用机制／论证担保、哪些相邻解释已被材料区分。做不到时，把句子降回描述性发现或明确标成待检验解释，而不是用“说明、因此、由此可见”跨过缺失的前提。

### 1.4 辨清判断、贯通材料与凝结表达

**以辨为骨，以清为文。** 区分看似相近却不能替换的概念、层次和判断：出现不自动等于成立，参与不自动等于代表，影响力不自动等于说服力，接受不自动等于价值。沿现有术语、Claim、Evidence 与 warrant 说明各自指什么、在什么条件下成立、混用会改变哪项结论；这些例子不是每篇都要套用的概念对。少用“提供视角、具有启示、值得关注”等姿态句代替判断。遇到“关系、机制、路径、意义、形成、进入、呈现”等抽象表达，追问谁在什么条件下做了什么、造成何种结果；它们若是准确且承重的术语就保留，不做禁词计数。

**贯通必须增加解释。** 不同文本、理论、时代、学科或文化材料可以互相照亮，但须辨明共同问题、相通的层面、联系何以成立及在哪里分开，再说明比较改变了本文的什么判断。启发性类比不自动成为相互印证；词语相似不证明思想同构，共享原始来源不构成独立证据。研究者在既有 `SYN-*` 的综合命题、可比性、来源关系和边界中记录比较，论证担保沿已有 Claim 与 ProsePacket 的 warrant 传递；Writer 只实现已进入包中的联系，不能从语言范例另造关联。旁枝若不改变主问题的解释，应删去或移出正文。

**让材料承担关键一步。** 有力量的原始文本、事实细节、数字反差或人物语言，可以在简洁聚焦后先呈现，再让作者交代它支持、区分、修正或反驳了什么。作者不必预先替材料说尽意义，也不能将引文当作完整论证。引用之后原则上交付其认识后果，但可在同一推理链自然完成，不强制紧接“这说明……”或逐条复述。抽象判断可以凝结为一个设问、一句话、一个动作或一组已核验事实；按段落功能往返于概念、材料与更具体的判断，不把“抽象—具体—提升”写成每段固定三步。

**锋利来自推理。** 准确恢复一个观点的对象、前提与限定，再指出它解释不了的事实、遗漏的条件，或依其自身逻辑导出的矛盾。批评针对概念、论证、证据和解释力，不攻击作者本人。修辞、反讽和隐喻只能增强已有论证，不能以形容词、情绪或名家口吻代替依据。这里的“清、辨、通”是方法提示，不授权模仿朱光潜、王元化、钱锺书或鲁迅的独有表达。

开篇须让背景、问题与意义可恢复，可以让问题从真实场景、人物、事件、文本细节或异常中发生，不规定三个独立段落或一句铺垫上限。结语先回答研究问题，再说明证据支持的认识增量并落回成立条件；可以回到已核验的开篇材料，使其获得经过论证的新意义。场景、人物语言和动作只能来自已登记细节，不能用合理想象补足。悬念、场景回返、跨文化参照和修辞均按需要采用，不设数量或比例。

## 2. 外至内改稿序列：前置审查 + 五遍

顺序固定为：**标题契约与外架构 → 论证盲点 → 全文主线与章节结构 → 段落逻辑 → 句子与术语 → 主张力度 → 格式**。前置审查未通过时，不得先打磨句子、连接词、标题花样或 Word 样式；否则局部文字越精致，后续越难接受章节重排、论点收缩或整段删除。每遍先讲判准，后讲操作，结果落到 §3 工件对应表。clear 模式执行前置审查、第一至四遍和终遍；distinguished 在第四遍后加增强遍。

### 前置审查：标题契约、外架构、论证盲点与修订边界

先核对 `confirmed_motivation.md` 的工作标题、`confirmed_contribution.md` 的证据校准标题和真实稿件标题，填写 §3.0A。标题是问题—回答—证据—范围的压缩契约：执行后可按证据作实质校准，build/audit 只能作不改变问题、主张和范围的表层调整。若定稿标题新增机制、结果、概念、对象或时间范围，不把它称为“润色”，而是回到 research/design/execution 和用户确认。

再制造一次“读者距离”。时间允许时冷置草稿后再读；时间不允许时，至少暂时隐藏正文细节，只浏览标题、摘要、引言末段、各主要章节的开头与结尾、结论。先让未读正文的人仅凭标题复述问题、可预期回答和范围，再根据全部承重位置说明“问题—回答—依据—贡献”；若无法连贯复述，说明标题或外架构尚未成立，先修研究契约或结构而不是词句。

外架构审查先锁定四件事：引言在哪里结束、结论从哪里开始、中心主张由哪一句明确提出、主体各章节分别回答什么问题。填写 §3.0 外架构与章节角色表，检查标题、摘要、引言末、承重章节与结论是否交付同一项贡献；核心术语是否贯穿这些位置；每节是否有控制性命题、与前节的真实逻辑关系以及对全文的独特作用。无法说明章节作用时，先移动、合并或删除；不要靠“因此、与此相反、更重要的是”等连接词为并不存在的关系补妆。

外架构同时区分**研究对象、分析工具和作者结论**。题名及确认问题规定“论文在解释谁／什么”；概念、模型、类型和关系框架只是观察该对象的工具。摘要、引言末、主体承重节首尾和结论都须让读者识别同一研究对象及其待解释关系，不能让作者自造框架逐步取代原对象，变成全文真正的主语。若删除框架名称后已经说不清论文对原对象作出了什么判断，应回到 research/contribution 重建对象—问题—回答关系。

再核对**章节答案密度**。引言只建立必要语境与张力，公允定位已有研究，提出精确问题，交代材料／进路，并给出足以导读的一句最低限度回答；概念的完整界定、功能分解、证据展开和历史／经验比较归主体承重部分。结论以实质判断回答引言问题，说明理论或经验增量，并在合适位置集中安置范围和真正未决的问题；可以由开篇材料的回返进入答案，文字次序服从闭环功能。若引言与主体以相同顺序完整出现三项以上同一答案组件，或结论主要在播报“本文做了什么、没有做什么、未来还能做什么”，应重分章节任务，而非换同义词消除表面重复。

同时复核引言宣称的是“真空白”还是“对象稀缺”。精确题名命中少、案例出现不久或尚无同题论文，只能说明检索与发表状态，不能直接说明存在可发表贡献；要回到 research/contribution，排查发表时滞、术语错配、相邻文献覆盖和问题本身解释价值不足，并把空白改写为尚未解决的关系、机制、条件、边界或比较。若低研究度来自贡献不足，就扩大或重构问题，不能用更用力的稀缺性修辞补救。

再检查研究问题与篇章结构是否共享一个结果。采用“有些……有些……”的问题必须建立共同结果和可比单位；核心案例可以承担主要证据，对照案例负责路径差异和反事实，不因此形成第二个并列问题。若所谓张力来自把不同时间点或法律类别混在一起——例如议程场域与法律人格、资格开放与创设时实际参与——先拆开概念和阶段，不能把分类错误写成悖论。没有真实时序证据时，不用“停留—跨越—落地”制造自然发展的故事。

随后检查初稿最可能经不起挑战的地方，主动寻找挑战、复杂化或支持不同解读的证据。按核验结果填写 §3.1 强抗辩与解释角色表；存在相关抗辩时以其最强形式登记，经核验没有材料性相关抗辩或替代解释时允许 0 项。真实分歧、负面发现、反证和必要边界仍须保留并追踪来源，不因反方为 0 而省略。先判断所登记观点与主解释的关系，再决定写法：

1. 只有当两个解释针对**同一结果、同一阶段**并产生可区分的经验预期时，才称为竞争性/替代性解释，并比较判别性证据；
2. 若它们解释不同阶段、不同结果或不同层次，就标为互补解释、阶段性解释、条件解释或范围边界，放入相应机制环节，不人为排成对称竞争；
3. 若某一解释没有独特经验预期、没有可用证据，也不改变主张、机制或边界，就整合进更合适的段落或删除，不为显示周全而保留。

最后填写 §3.2 边界安置表。每项实质不确定性只选择一个承重位置完整说明：它来自材料、测量、识别、时间窗口还是外推范围，因而改变了哪项主张。其他位置只保留当前章节完成任务所需的短限定或回指。若一句“无法确认、不能确定、仅能说明”既不改变研究设计、不收窄主张，也不帮助读者理解证据，就删除；谨慎应表现为主张与证据匹配，而不是反复播报研究者尚未确认什么。

同步检查**段落的局部职能**。单独一段若只说明材料不能支持什么、本文不推断什么或贡献限于什么，却不承接前文主张、不改变当前判断，也不把问题交给下一段，通常是审计记录误入正文。把真正改变主张的边界并入方法末、讨论或对应分析段的边界／含义位置；无实质作用者删除。范围说明应在读者需要它时交代，并与所限定的判断连接；避免无关防守打断推进，不把必要条件一律移到判断之后。

承重事实与思想命题还要遵守**来源接近性**。关于某个理论家、政策文本、制度文件、档案、数据或研究结果“说了什么／显示什么”的判断，优先由最接近该命题的原典、正式文件、原始档案、原始数据或原研究承担；二手研究主要负责学术定位、解释谱系、争论与评价。原始材料无法取得时，明确转述链并降低措辞，不让二手文献冒充研究对象本身的声音。政治理论与思想史稿尤其要让权威原文或经典原典承担规范命题，二手论文不能替代可获得的原文；这是一项来源—主张匹配规则，不是机械的“原始来源越多越好”。

### 第一遍：叙事包装、一项贡献与反向提纲

一篇论文只交付一项中心贡献。先写贡献压缩句：

现有研究解释了 X，却未说明 Y；本文利用 Z 证据表明 M，因此需要修正、补充或限定 N。

标题、摘要、引言末、各承重章节和结论必须围绕同一贡献；若一句话无法写清，先修研究逻辑，不做局部润色。先填写 §3.3 叙事包装图，把背景、张力、核心回答、解释/边界和认识结局分别落到真实位置，写清每一阶段交给下一阶段的读者问题；缺少任何阶段或阶段之间只是并列，就先重排全文。

然后为每个最小论证单元只写一句“本单元使读者多知道了什么”，删除正文只读这些句子，检查：顺序是否从问题走向回答；有无逻辑跳跃、重复主张；是否在多个章节完整复刻同一组局限；是否一段承担多个任务；是否有段落回不到中心贡献。每一行都必须包含主张、所用证据或推理、与贡献的关系以及承接。再标出核心现象/机制、理论、情境和行动者各自承担的功能，删除无功能角色。先移动、合并、拆分或删除论证单元，再处理句子。

### 第二遍：承重段落与逻辑链

承重段落让“对象／行动、主张、证据、担保、必要边界/含义”的关系可恢复：主张是要读者接受的判断；证据是数据、材料、引文、案例或规范前提；担保说明证据为什么支持主张；边界写明成立条件或后续问题。可以先呈现关键材料，再凝结判断，也可以先作必要区分后让证据推进；不规定每段先下结论。让材料发声是让它承担论证中的关键一步，并在适当位置交付解释责任，不是要求引文孤立地证明全部主张。例子不能只负责好看，抽象判断也不能只靠作者告知。

逻辑加固同步完成：为承重判断补出最容易被省略的中间前提；先以最强形式复述竞争解释，再说明材料为何更支持本文解释；在涉及组织、制度和政策行为时写清“谁在何种约束下做了什么、影响了谁”，不能用“实现、形成、推进”等无主体结构抹掉关键行动；转折词只能标记真实关系，不能制造缺失的前提；段尾完成当前任务，并把读者带到下一任务，不突入未经支撑的新论点。引文堆积、数据罗列、缺失担保或跨章节整组复述相同边界，均须回炉；选择一个承重位置完整说明局限，其他位置只保留该章节自身功能所需的限定，谨慎要进入论证而不是变成“审计腔”。

最强反方、预演审稿意见和证据边界表属于**论证后台**。正文前台只呈现读者理解结论所必需的学术关系：先准确承认已有成果，再指出它留下的分析单位、关系或证据问题，最后让对象、材料和有限判断承担推进。只有确有来源支持、能产生同一结果且处于同一分析阶段、会改变当前 Claim、并有判别证据时，反方才进入 ProsePacket；没有符合者时正文反方为 0 合法。不要把“最强反对意见认为”“这一质疑部分成立”“本文材料所能支持的是”“本文把结论限定为”等内部答辩句直接排成段落。真实分歧不得因此被抹平；已激活反方须转化为有归属的文献定位、可判别问题和校准后的正面判断，其处置能够从这条链恢复即可，不在正文逐项报账。

### 第三遍：句子信息流与术语

抽查摘要、引言、各承重章节和结论：句首放承接前文的旧信息；主语与核心谓语靠近；主要动作放在动词中，不埋进“进行分析、实现提升”等名词化外壳；行动主体对解释重要时用主动语态直接写出，过程或结果需要成为焦点时允许被动语态；研究动作和论证选择需要作者负责、且目标刊允许时，可用“我/我们”，不必永远躲在“本文/本研究”后；句末放本句真正要强调的新判断；一个句子只承担一个主要论证动作。不机械禁用长句、被动句或第一人称——只检查依赖关系和责任归属是否透明。

术语稳定优先于同义词变化：逐项对照 `terminology_register.md`，核心概念确定后保持同名，不把“数字治理、数字化治理、智慧治理”当可互换装饰词；若含义不同，先界定差异。中文学界已有通行术语或规范译名时，不为显得新颖而自造近义词或另译；政策/官方用语须区分经验对象与分析概念。所谓“中文学界传统”指可追溯的学科谱系、概念史和通行用法，不是古雅、生僻、四字格或高度压缩的表面风格。

防御性写作按 `anti-defensive-writing.md` 先判功能，不能从否定词替换开始。先冻结事实、数字、证据、反证、范围、方法透明度、法律伦理边界和必要作者责任；再判断可疑单元属于无必要免责声明、重复澄清、必要范围、真实方法限制、证据性限定、有用概念对比或必要责任。只有前两类默认删除，其余信息分别改成直接主张、正面范围、精确不确定性、集中边界或承重材料锚点保留，并围绕本段主判断重建整段。

否定转折只在确有二分纠偏功能时使用。“不是／并非／不在于……而是／而在于”能够澄清易混概念，但连续使用会让论文围绕作者拒绝什么展开，形成辩解腔和口头争辩感。定义、贡献、方法与边界句优先写明分析对象、所作判断和适用范围：

- 把“这一说法不是官方命名，也不是新概念，而是对分析对象的限定”改为“该说法属于本文的分析性限定，与官方命名和新的标识性概念相区别”。
- 把“本文不把既有内容据为新发现，而是追问……”改为“本文以既有研究为起点，集中解释……”。
- 把“本文不是要写完整思想史”改为“本文聚焦与研究问题直接相关的关键文本，研究范围属于问题导向的思想史考察”。

“本文不把／不试图／无意／并非旨在……”通常是在播报作者意图；“为避免误解／需要澄清的是／这并不意味着／不应据此理解为……”通常在预演尚未出现的批评；“尽管样本有限……但仍有一定价值”则会让贡献先自我削弱。改写时先说对象发生了什么、贡献是什么、材料能支持什么；若这些句子含有必要范围或限制，把信息迁移到主张首次需要的位置。连续的“不能、无法、尚不足以、不构成”合并到一个承重位置，说明不确定性来自样本、测量、识别、材料、时间还是外推，以及它改变哪项判断。原文引语、文献题名与确有必要的反方纠偏保持原貌，在 §3.8 登记语境和保留理由。扫描以作者自写文本为重点，不为词表清零改动来源原意。

句子处理后必须重新检查段落交付关系：无论从对象、材料、引文、设问还是判断开始，读者都应能跟随证据与担保理解本段如何推进问题，只有改变当前判断的边界才留在本段。段首句按局部功能变化，不一律写总结性短句。只把“本文不主张 X”换成“本文聚焦 Y”，却仍未交付 Y 的实质判断和依据，不算完成。

凝练度使用**删减测试**而不是字数指标：逐词、逐句、逐段问“删掉后，主张、证据、担保、边界或必要节奏是否损失”。不损失就删、并或移；有损失就保留。重点压缩重复背景、同义复述、过程垫话、过密标题、逐格复述图表和在多处重复的局限；不得删掉范围、时间、对象、指标、负结果和证据力度。凝练不是统一短句，而是每个语言单位都有论证功能。

本遍必须再做一次**全文异常措辞扫描**，不能只抽查承重句。扫描范围包括标题、摘要、正文、小标题、表题、列表头、图题、资料来源与表注；脚注中的作者分析文字同样纳入，原文引语和文献题名只标记、不擅改。重点检查四类问题：

1. **空间/层级隐喻代替学术关系**：如“止步处”“最靠前的一层”“几层文献叠起来”“关键断点”“落点”“入口/出口”等。先还原它实际表示的是研究限度、时间先后、证据缺口、制度差异还是因果环节，再用该关系直接表述。
2. **分析脚手架留在成稿**：如“理念库—议题选址—设计转译—成员动员”一类为写作方便临时命名的流程标签。若不是经过术语门确认、且不承担不可替代的理论功能，就改成学界可直接理解的普通概念。
3. **审计、司法或工程语域外泄**：如“判定、裁决、核验、核定、校验、审计、机制对弈、可核、闭环、跑通、接口、底座、映射”等。方法部分可准确说明必要的核验程序，正文论证则优先写“如何选择材料、材料显示什么、支持何种解释、解释范围为何”。
4. **压缩构词制造分析感**：如“条款化、承诺化、宣示化、正式化不透明、嵌入式制衡”等未经登记的标签。能用一句普通学术汉语说清时，不用新造词；确有概念必要性则返回 `terminology_register.md` 和 contribution 门。

处理原则不是把词表机械清零，而是逐处判断该词是否比普通表达更准确、是否有学科通行依据、是否承担理论功能。最终仍保留的触发项必须在 §3.8 登记具体语境与保留理由；仅写“全文已检查”不能过门。表题和列名尤其容易残留“裁决物、相合程度、核验状态”等内部工作语，应把表格改成读者可直接理解的比较关系。普通正文默认不新增粗体强调；除非目标刊模板、标题层级、学科规范或用户明确要求，重点判断应靠位置、句法与论证承重呈现，不靠加粗替代结构。

### 第四遍：主张力度校准

逐项把强判断映射到 evidence_bank.md、research_design.json 的 Claim ID/推断上限或 `method_execution.py::downstream_eligibility` 授权的结果用途；不得从 `results_validation.md` 反推资格：

| 证据状态 | 通常允许的措辞 | 通常禁止的跃迁 |
|---|---|---|
| 可信因果识别 | 导致、影响、产生效应，并交代范围条件 | 从局部样本直接推成普遍规律 |
| 观察性关系 | 相关、伴随、预测、与某解释一致 | 证明、导致、决定 |
| 机制过程证据 | 支持某机制解释、显示某环节如何发生 | 把未观察环节写成既定事实 |
| 描述/类型学证据 | 呈现、识别、区分、概括 | 把分类差异写成因果效应 |
| 初步或有限证据 | 提示、可能、在某条件下 | 首次、普遍、必然、颠覆性 |

审查证明、导致、显著、普遍、首次、开创性等高风险词。“可能、似乎、在一定程度上”不能层层叠加；好的限定要说明不确定性来自样本、测量、识别、材料还是外推边界。立场标记与证据确定性匹配：对什么有把握、对什么保持开放，措辞要能区分。

### 增强遍（仅 distinguished）：洞见、思想、文气与声音

清晰度四遍完成后执行，一遍四个动作，全部登记进 §3.10 增强登记表：

1. **建立不可损失清单**。从正文、evidence bank、results validation 和 citation bank 抽取事实、数字、引文、反证、限制、范围条件和禁止措辞；增强后逐项核对正文仍在，结果记入忠实性清单表。
2. **提炼洞见**。洞见不是宣布对象重要，而是揭示认知增量：经验异象、理论张力、被遮蔽的假设、近邻概念差异、机制缺口或范围条件。把“研究 X”改造成“既有解释预期 X，为何在条件 Y 下出现 Z”；写清读者原来会怎样理解、本文证据迫使其修正什么。没有证据支持的“新洞见”不得写入正文——此时停止增强，返回上游阶段。
3. **压缩思想**。好概念减少解释成本，不是给熟悉现象换名。对照 `terminology_register.md`，先沿用中文学界通行术语和规范译名，再判断是否真的需要新概念；核心概念给出内涵、边界、近邻区分和可观察含义。用一个可工作的区分、机制或命题替代多个空泛贡献句；不得在增强遍临时发明术语，任何新词都返回 design，完成谱系、撞车和用户确认。
4. **调整文气与声音**。文气来自准确、收放和节制，句子节奏服从认识节奏：复杂推理可以用长句展开，关键判断可以收短，解释也可跨句完成；只检查依赖关系、焦点和责任是否清楚，不规定长中短句分工。平行结构用于真实比较，克制比喻用于解释已有关系；方法、模型、变量和结果报告保持透明精确。作者声音来自稳定的概念选择、问题视角和立场校准，不来自口癖：在 `style_profile.md` 登记有理论功能的概念对与判断尺度；提出研究动作和论证选择时允许适度作者在场，报告客观结果时不强行凸显自我。主动贴近经核验、承担同一论证功能的真实论文，学习动作、组织、句法骨架和引用节奏；允许成熟术语、常规搭配和共同体 lexical bundles 的自然复用，不为表面原创强换词。范文借用遵守 `commonplace-writing.md`，不复制独有隐喻、罕见表述或逐句拼接；经典语料不授权移植名家口吻。

分节要点：标题呈现可辩论判断或概念关系，不为醒目夸大贡献；摘要按“问题张力—证据进路—核心发现—贡献边界”压缩，文气来自压缩不来自形容词；引言不是全文压缩版，而是建立阅读动机，只承诺正文能兑现的增量；文献围绕本文要裁决的关系组织，先让对手以最强形式成立；理论与假设写成“什么主体在什么条件下通过什么机制导致什么结果以及为什么”，假设是推理的自然落点；方法说明关键选择为何使证据可信，不罗列劳动量；结果围绕研究问题而非“模型1、模型2、模型3”组织，先展示发现再解释它回答哪个问题，不因气势省略数值、方向、不确定性和负结果；讨论不复述结果、不漫无目的延伸、不越过证据，重点解释结果为何如此、修正什么认识、在哪些条件下成立；结论第一段先直接回答研究问题并说明增量，再用最短必要文字集中交代范围，未来研究必须来自一个真实未决问题，不能用“有待进一步研究”补偿尚未完成的结论；最后一句可以有余味，但必须由全文推出。

### 终遍：双读者复述

给未参与成稿且处于不同上下文的**两位**隔离读者只看正文，不给蓝图、作者审计表和预期答案。两位读者的分工来自"外行不觉得难，内行不认为浅"：**外行读者**来自分支品味卡登记的相邻分支（`top-journal-anatomy.md` §5A 的 `adjacent_branches`；无卡时取最近的邻近学科），只须复述研究对象、具体问题与"为什么要紧"，并指出正文里第一处让他坐直的位置（反常、张力或反转）；答不出对象与问题即回 build，答不出坐直位置须登记为趣味缺口而不能以"内容严谨"抵消。**内行读者**来自同一分支，须说出读完后自己此前不知道的那一件事；说不出即厚味缺口，回 build。两位读者的分支、隔离方式与 context 登记在 §3.9 首行。内行读者的复述次序固定为：研究对象与具体问题、实质答案、最强证据、推断边界；这些成立后，再复述作者相对前人的定位、五阶段认知路径、读者所得，以及第一次需要回读或感到受阻的位置。读者还要指出首次出现“已经知道作者拒绝什么，却仍不知道对象发生了什么或证据说明什么”的位置；没有这种位置也须明确说明。再让读者对叙事连续性、语言凝练度、读者可读性、行动主体可见性和展示—解释平衡给出定性反馈，必须指出稿内位置，不能只写“流畅/不流畅”。同一主线程即使隔离输入也只能标 single-agent review，不能冒充独立读者；若无法取得不同上下文，保留复核结果并降低 review assurance。复述与作者意图不一致或任一维度仍弱时先改正文，再重做测试。distinguished 模式下，audit 阶段只有在 independent assurance 成立时才称写作独立评审。

## 2A. 中文学术句法本体与套话词库

本节为第三遍“句子信息流与术语”和增强遍“文气与声音”补中文句法层的判准，并给出摘要、引言漏斗和文献综述的中文段落级示范。它不是禁词表，也不是“AI 味”检测器：每条规则的判准仍是 §1.1 的两层关系（信息层是否损失、引导层是否更清楚）、第二遍的“对象／行动—主张—证据—担保—边界”次序和第三遍的删减测试。机器（`scripts/academic_prose_check.py`）只标出本节 A 档里最稳定的几种套话，其余靠人读；人读命中的处置一律登记 §3.8，`Decision` 只用既有六种。本节全部示例为自造，涉及的地名、数字、文献立场（甲、乙、丙……）均为虚构，不得作为事实引用。

### 2A.1 中文句法十二条

每条按“规则—为什么伤论证—改前→改后—信息流关系”写。改后句只是示范句法动作，凡改后句出现的数字、行动者或机制，都以稿件已登记的证据为准；句法改写不得顺手加强推断（对照第四遍）。

**1. 长定语前置与“的”字堆叠。** 规则：名词前的修饰成分以读者一口气能记住为限（通常不超过两个层次）；超过就把限定拆成独立小句，按时间、主体、对象、属性的顺序分别交代。为什么伤论证：中文定语只能前置，读者必须把全部修饰语压在工作记忆里，等中心语出现才知道在说谁；主语与谓语被推远，论证动作迟到；多个“的”把时间、主体、对象、属性等不同层级的限定压成同一层，读者无法判断哪一层承重。

- 改前：基于2019年以来三个地级市热线工单数据所反映出来的跨部门事项在移交环节反复退回现象的成因，需要从事项移交权的配置来解释。
- 改后：2019年以来，三个地级市的热线工单显示，跨部门事项在移交环节反复退回。退回的成因在于事项移交权的配置。
- 信息流关系：落实“主语与核心谓语靠近”和“句首放旧信息”；拆句后每句只承担一个论证动作，第二句的主语“退回”正是第一句句末的新信息。

**2. “进行／加以／予以／作出／开展”泛动词外壳。** 规则：动作回到实义动词，“对 X 进行分析”写成“分析 X”；外壳后的名词若是登记术语（如“进行过程追踪”），保留术语但让主语可见。为什么伤论证：真正的动作被名词化，主语常随之消失，读者不知道谁做了什么；外壳还让作者回避动作强度——“作出回应”掩盖了决定是否真的改变。

- 改前：牵头部门对退回工单予以了重新分派，并对责任归属加以明确，协调效率的提升由此得以实现。
- 改后：牵头部门重新分派了退回工单，并明确了责任归属；协调效率由此提高。
- 信息流关系：落实“主要动作放在动词中，不埋进名词化外壳”。机器已标“进行／开展……研究／分析／探讨／考察”，其余外壳靠人读。

**3. 顿号并列滥用。** 规则：顿号只并列同一层级、同一语法功能的项；层级不同（原因与表现、条件与后果、变量与载体）时改为先总后分的分层结构，或拆成两句。为什么伤论证：并列暗示各项等值、互斥且穷尽，把原因、表现、条件、后果混在一起，读者无法知道哪些是变量、哪些是结果；它还遮蔽作者尚未完成的分类工作，把待论证的关系写成了清单。

- 改前：财政透明度受到领导重视程度、公开平台建设、上级考核压力、公众关注度、信息公开条例等因素的影响。
- 改后：财政透明度的差异来自两类条件：制度约束（信息公开条例的强制条款、上级考核指标）与地方动力（主要领导的重视、公众关注引发的问询）；公开平台是两类条件发挥作用的载体，不是独立原因。
- 信息流关系：落实“一个句子只承担一个论证动作”；并列项一旦分层，需要担保的关系（为何平台只是载体）就显露出来，必须由材料支持，不能靠分层本身制造。

**4. 四字格与对仗节律掩盖空泛。** 规则：四字格只在比普通表达更准确时保留；两两对仗的短语逐个追问“它指的可观察对象是什么”，答不出的删除或改写。为什么伤论证：节律带来“说完了”的错觉，读者被音节推着走，不会停下来追问证据；对仗迫使作者为凑形式添加并不存在的对称项，第二项常是第一项的空转。

- 改前：密折制度上通下达、内外兼修、赏罚分明、张弛有度，堪称清代集权治理的典范。
- 改后：密折制度让督抚可以越过通政司直接向皇帝陈奏，皇帝也可以不经内阁批复。这两项安排缩短了信息通道，也使批复不再留下部院记录；它强化了皇帝对督抚的直接控制，但没有改变六部处理日常政务的程序。
- 信息流关系：落实“句末放本句真正要强调的新判断”；对应增强遍的边界“不把排比或古雅词汇当作高水平文笔”。

**5. 欧化被动与“被”字滥用。** 规则：中文被动优先用意念被动（“工单退回了”）或“由／经／受”标出责任主体；只有受事必须成为焦点、且施事不明或无关时才用“被”。为什么伤论证：被动隐藏行动者，而行动者正是制度分析最需要看见的东西；“被认为、被视为”一类欧化归因还会漏掉归因者——谁认为？依据什么？

- 改前：事项移交权被下放到了牵头部门，退回工单被要求在24小时内被重新分派，这一做法被认为提高了效率。
- 改后：市级专班把事项移交权下放给牵头部门，并要求退回工单在24小时内重新分派；受访的三位部门负责人都把此后效率的提高归因于这一安排。
- 信息流关系：落实“行动主体对解释重要时用主动语态直接写出，过程或结果需要成为焦点时允许被动语态”；归因句必须带归因者，否则属于第二遍的缺失担保。

**6. 主语缺失与主语漂移。** 规则：一段之内追踪主语链，每句要么承接上句主语，要么明确换主语；不允许省略主语造成歧义，也不允许一句之内主语无告知地切换。为什么伤论证：中文允许省略主语，作者常在不知不觉中把“本文—制度—部门—数据”轮流当主语，读者无法判断谁在行动、谁在判断；主语漂移也是 §6“对象被框架取代”的句法入口。

- 改前：省级财政部门要求各市公开部门预算，公开率在两年内上升，但仍然没有说明预算调整的原因，这一点与既有研究的判断一致。
- 改后：省级财政部门要求各市公开部门预算后，各市的公开率在两年内上升；但各市公开的文本仍未说明预算调整的原因。既有研究关于公开率与说明质量脱节的判断，在这里再次得到印证。
- 信息流关系：主语链就是段落的信息流骨架，落实“句首放承接前文的旧信息”；改前句的“没有说明”主语不明（是省级部门、各市还是本文？），改后句把它交还给“各市公开的文本”。

**7. “通过……，……”悬垂结构。** 规则：“通过 X，Y”要求 Y 有主语，且该主语就是做 X 的人；否则改写为“谁通过 X 做了什么”或“X 之后，Y 如何变化”。为什么伤论证：悬垂结构让手段没有执行者、结果没有承受者，因果链两端都空；它也是把相关写成因果的常用通道——“通过平台接入，响应效率得到提升”省掉了谁接入、谁的效率、凭什么说是因果。

- 改前：通过下放事项移交权，跨部门响应时间明显缩短，协同机制得到优化。
- 改后：市级专班下放事项移交权后，牵头部门可以直接调度参与单位；三个部门的中位响应时间从31小时降至14小时。
- 信息流关系：落实主语可见与第四遍的主张力度校准——手段与结果之间的担保须写出，材料只支持先后关系时用“后／此后”，不用“通过……实现”。

**8. “不仅……而且……更……”三连递进与排比堆叠。** 规则：递进只在各项确有强度差且都有证据时使用；三项以上并列先逐项问“它是否独立承重”，否则降为一句判断加一个最强证据。为什么伤论证：三连递进制造“层层深入”的假象，第二、三项通常只是第一项的换说或未经支持的放大；排比把不同强度的主张拉平，最弱的一项拖累最强的一项。

- 改前：热线工单制度不仅改变了信息传递方式，而且重塑了部门间的责任关系，更从根本上推动了治理理念的转型。
- 改后：热线工单制度改变了部门间的责任关系：责任确认由多部门协商转为牵头部门判定。材料不支持关于治理理念转型的判断。
- 信息流关系：落实“一个句子只承担一个主要论证动作”和删减测试；删掉的两项若确有证据，各自另写一句并给担保，不回到递进句式。

**9. “化／性／度／力”堆叠成伪术语。** 规则：后缀构词只用于已登记术语或学界通行概念；临时构词能用一句普通学术汉语说清就不用；一句之内不超过一个未登记的“X 化／X 性”。为什么伤论证：后缀把过程、属性、程度一律名词化，读者无法追问“谁使它化、化到什么程度、依据什么判断”；连缀的“X 化 Y 性 Z 度”看似精确，每个都没有可观察指标。

- 改前：府际关系的制度化程度、规范化水平和协同性强度共同决定了政策执行的有效性与可持续性。
- 改后：省市两级之间是否有书面的事项分工、分工是否被上级考核引用、争议事项由谁裁定，这三项条件决定了政策能否在换届后继续执行。
- 信息流关系：落实第三遍的术语稳定与 §6“思想注水”反模式；改后句把每个后缀名词还原为可观察条件，确需新概念时返回 `terminology_register.md` 与 contribution 门。

**10. 段尾升华句与“总之／综上”机械收束。** 规则：段尾只做两件事——完成本段判断、把问题交给下一段；不在段尾把局部发现抬升为宏观意义；“综上所述”只用于确实综合了两项以上独立前提、且综合判断在前文尚未出现的位置。为什么伤论证：升华句把证据尚未支持的判断放在读者记忆最深的段尾位置；每段一个“总之”让读者以为每段都是独立结论，全文主线消失。

- 改前：三个案例中退回工单的减少都发生在移交权下放之后。总之，事项移交权的下放是推进国家治理体系和治理能力现代化的关键一环，具有深远意义。
- 改后：三个案例中退回工单的减少都发生在移交权下放之后。这一时间顺序支持移交权与退回率相关，但尚不能排除同期人员增配的作用；下一节比较人员规模相近的两个部门。
- 信息流关系：落实第二遍“段尾完成当前任务，并把读者带到下一任务，不突入未经支撑的新论点”；段尾的新信息应是下一段的旧信息。

**11. 每段等长与首句总起的模板化段落。** 规则：段落长度按论证功能分配；主题句可以是判断，也可以是对象或证据的呈现，不必每段都以“首先／其次／再次”或“X 是……的重要方面”起头。为什么伤论证：等长与总起模板让读者失去节奏线索，无法从篇幅和句式判断哪里是承重段；“首先其次”还暗示各项平行，掩盖推理的先后依赖。

- 改前：首先，财政透明度是现代财政制度的重要组成部分。其次，财政透明度受到多种因素影响。最后，财政透明度的提升需要多方协同。（三段各约150字，段首都是定义或口号。）
- 改后：一段交代对象与材料（短）；一段完整展开主发现及其担保（长）；一段处理替代解释（中）。承重段直接从对象进入：“2016年后，省内各地市的部门预算公开率趋同，但公开文本的说明深度分化。”
- 信息流关系：对应 §1.1 的“运动与节奏”和第一遍的反向提纲——篇幅按论证功能分配，不按作者的写作顺序分配。

**12. 数字、量词与概数的口语化。** 规则：承重句中的数字写清分子、分母、时间范围与比较基准；“不少、大量、很多、有些、相当一部分”改为可核对的数或比例；“约／近／超过”只用于确有精度限制处并说明来源。为什么伤论证：口语概数让读者无法判断证据强度，也让作者在“多数”与“部分”之间随意滑动；缺分母的数字会把样本描述误读为总体结论。

- 改前：不少地市在改革后大幅提高了公开率，有相当一部分部门实现了全覆盖。
- 改后：改革后两年内，样本中的21个地市有15个公开率上升10个百分点以上，其中6个地市的全部一级预算部门都公开了部门预算。
- 信息流关系：数字是第四遍主张力度校准的锚，也是忠实性清单（§3.11）的受保护原子；数字体例另按 `cn-journal-conventions.md` §9.1。

### 2A.2 中文 AI 味词库（三档）

“AI 味”在本协议中不指来源，而指高频、低信息表述的共现：读者读完仍说不出对象发生了什么、作者判断了什么、凭什么。判据沿用 `anti-defensive-writing.md` §2.1 的信息贡献测试：删掉该表达后，读者是否失去可核对的对象、判断、机制、证据或边界。三档的区别只在默认动作与检查范围。

**A 档：删掉几乎不损失信息。** 默认动作 `DELETE`。操作：整句或整短语直接删，重读前后句；若删除后句子失去主语或谓语，说明套话在替代真实内容，要补的是对象和判断，不是换一个套话。

| 类别 | 表达（示例，非穷尽） |
|---|---|
| 背景开场 | 在……不断深入推进的时代背景下；随着……的不断发展／深入；当前，……已成为……的重要议题；近年来，……日益受到学界和实务界的广泛关注；站在新的历史起点上；在……的大背景下 |
| 意义宣示 | 具有十分重要的理论与现实意义；对……具有重要的指导意义；是……的题中应有之义；是……的必然要求／内在要求；关系到……的成败；意义重大、影响深远 |
| 贡献借鉴 | 为……提供了有益借鉴／参考／启示；为……提供了新的思路和视角；对……进行了有益探索；丰富和拓展了……的研究；在一定程度上填补了……的空白；以期为……提供决策参考 |
| 治理流行语 | 赋能；抓手；底层逻辑；闭环；打通……的最后一公里；全方位、多层次、宽领域；系统性、整体性、协同性（并列三性）；深度融合；精准施策；多措并举；久久为功；行稳致远；高质量（无指标时）；顶层设计（泛指时） |
| 程度副词与外壳 | 不断、进一步、切实、有效、大力、深入（修饰研究动作时）；较为系统地；在一定程度上（不说明来源时）；深层次原因（不说是什么原因时） |

以上约四十项。判断单位是短语在句中的功能：“顶层设计”指具体的中央文件时是经验对象，不删；“闭环”在方法部分描述反馈回路且已定义时可保留，正文论证中作修辞用则删。

**B 档：看上下文的元话语。** 默认动作“先看后句”。操作：删掉元话语，看它后面接的是新信息（新对象、新判断、新证据、新边界）还是对前文的重复。接新信息则保留，或改为更明确的信号；接重复则连同后句一起删或并。

| 元话语 | 保留条件 | 删除或改写条件 |
|---|---|---|
| 值得注意的是 | 后接与前句预期相反的观察、反证或例外，且随后有处理 | 后接对前句的同义复述，或作者只是想强调 |
| 不可否认／诚然 | 后接有来源归属的反方立场，且紧接作者回应 | 无来源，或只是让步姿态；优先改写为“甲指出……” |
| 综上所述／总之 | 前文确有两项以上独立前提，本句作出的综合判断此前未出现 | 只重复上一段结论，或每段一个 |
| 换言之／也就是说 | 后句用可观察指标替换前句的抽象表述（实际在做 `DEFINE`） | 后句只是同义改写 |
| 某种程度上／在一定程度上 | 能改写为具体来源的不确定性（样本、测量、识别、外推） | 不能说明来源时删，不能靠叠加“可能、似乎”补救 |
| 事实上／实际上 | 后接与表面现象或既有判断相反的材料 | 无对比对象 |
| 需要指出的是／必须承认 | 后接改变当前主张的必要范围或方法限制 | 预演尚未出现的批评（按 `anti-defensive-writing.md` §4.1 处理） |
| 一般而言／通常 | 后文紧接“但本案例……”的例外 | 只是弱化语气 |

保留示例：“三市公开率在改革后趋同。值得注意的是，公开文本对预算调整原因的说明反而减少：改革前有两市在报表后附说明，改革后三市均只附报表。”这里的元话语标记了与预期相反的方向，后句给出可核对的比较；机械删掉标记并把后句压成“说明方式也随之调整”，丢失的是方向和证据，不是套话。

**C 档：结构性套路。** 默认动作“拆结构后重测”。操作：把结构标记（序数词、排比框架、升华句、问句串）拆掉，检查各项能否独立说出对象、判断、证据；若拆掉后各项内容互相可替换、顺序可随意调换，说明结构只是排版而非推理，回到第一遍反向提纲重组。常见形态：

- 三连排比与“不仅……而且……更……”递进（2A.1 第 8 条）；
- 段尾升华与每段一个“因此／总之／综上”（2A.1 第 10 条）；
- “首先、其次、最后”机械分段与等长段落（2A.1 第 11 条）；
- “一方面……另一方面……”没有真实对立，两面只是两个话题；
- “是什么—为什么—怎么办”问句串开场，随后并未逐一回答；
- “本文的边际贡献主要体现在以下三个方面”，三项互为换说；
- 结论以“三点启示”“若干建议”收束，建议与正文发现无对应。

**与机器的分工。** `academic_prose_check.py` 现有正则只稳定命中 A 档中的几种：`generic-background`（在……背景／形势／时代下）、`significance-cliche`、`generic-borrowing`、`generic-contribution`（丰富／拓展／深化了……研究）、`empty-gap`（鲜有研究、填补空白）、`nominalization-shell`（进行／开展……研究／分析）、`process-padding`（在……的过程中）、`vague-hedge`（在一定程度上、某种意义上），以及审计／工程语域里的“闭环、接口、底座、映射”。其余 A 档词（赋能、抓手、底层逻辑、随着……不断发展等）、全部 B 档和 C 档都不进机器：B 档必须看后句是否新信息，C 档是段落级结构，正则无法判断。机器命中只触发 §3.8 的上下文处置，不自动判错；人读以本节为词表，处置结果同样登记 §3.8。

### 2A.3 摘要中文示范

摘要按 §1.3 交付四要素：具体问题、材料／分析进路、实质发现、贡献边界；第三人称，不写“本文拟、旨在、分为”。示例数字为虚构。

**反例（套话加无具体发现）：**

> 在国家治理体系和治理能力现代化不断深入推进的时代背景下，政务热线作为回应群众诉求的重要抓手，其运行效能日益受到学界和实务界的广泛关注。本文以 X 市政务热线为例，运用案例研究方法，对热线工单处理中的跨部门协同问题进行了较为系统的分析，揭示了影响协同效率的深层次原因，并从制度设计、组织协调、技术赋能等方面提出了优化路径，以期为推动政务热线高质量发展、提升基层治理效能提供有益借鉴。

失败点：没有问题（只有“问题领域”）；材料只有“X 市”和“案例研究方法”，看不出比较对象和时间；“揭示了深层次原因”不说是什么原因；三方面“优化路径”是 C 档套路；A 档套话六处（时代背景、抓手、广泛关注、较为系统、高质量、有益借鉴）。同行读完无法判断论文发现了什么、是否值得读。

**正例（约 260 字，逐句标注要素）：**

> 同一政务热线平台上，为什么有的跨部门工单一次办结，有的反复退回？【问题】本文比较 X 市 2021—2023 年三个牵头部门的 4200 余件跨部门工单及其移交记录，并结合对部门负责人和话务中心的 12 次访谈追踪退回工单的处理过程。【材料／进路】退回集中发生在责任归属不明的事项上；市级专班把事项移交权交给牵头部门后，责任确认由多部门协商转为牵头部门判定，三个部门的退回率在半年内由 27% 降至 9%，中位响应时间由 31 小时降至 14 小时，同期人员规模未变，平台功能也无更新。【发现】这一比较说明热线效能的差异来自责任确认路径而非技术接入本身。【贡献】结论适用于具有相同事项移交安排的地级市热线；研究未构造反事实，不支持对全国平均效应的推断。【边界】

要素检查：问题句用现象内部的差异提问，而不是“研究 X 的效能”；材料句给出地点、时段、比较单位与数量；发现句先给模式（退回集中于何处）、再给变化（谁做了什么、指标如何变）、再排除同期替代解释；贡献句写认识增量而非意义宣示；边界句用正面范围加一项具体的设计限制，只出现一次。

### 2A.4 引言漏斗中文示范

引言只建立张力、公允定位已有研究、提出精确问题、交代进路并给出最低限度回答（§2 前置审查“章节答案密度”）。示例文献立场（甲、乙、丙）为虚构。

**反例（泛背景起手、罗列文献、以“填补空白”收束）：**

> 随着我国财政体制改革的不断深入，财政透明度已成为现代财政制度建设的重要内容，受到党和政府的高度重视。近年来，学界围绕财政透明度开展了大量研究。甲研究了财政透明度的测量问题；乙分析了财政透明度的影响因素；丙考察了财政透明度与政府绩效的关系；丁则从国际比较的视角进行了探讨。然而，既有研究鲜有从府际关系视角切入者，本文拟填补这一空白，以期为提升财政透明度提供有益参考。

失败点：第一段没有张力，只有“重要”；文献段只报告各家做了什么，不说明它们之间的分歧或与本文问题的关系，删掉作者名后只剩四个话题；“鲜有……填补空白”把对象稀缺当成真空白（§2 前置审查），也没有说出府际关系视角能解释什么既有解释解释不了的现象。

**正例（逐段标注 move）：**

> 【现象／张力】2016 年以后，某省财政部门要求所辖地市统一公开部门预算，各地市的公开率在两年内趋同到 90% 以上；但公开文本的说明深度却在分化：有的市在报表后附预算调整说明，有的市只公开报表。同一强制要求为什么产生不同的公开质量？
>
> 【既有解释及其不足】已有研究把财政透明度差异归因于地方财力、领导重视或公众关注（甲；乙）。这些解释能说明公开率为何上升，却难以说明公开率趋同之后说明深度为何分化——三类因素在样本中的分布与说明深度并不对应。另一支研究强调上级考核的作用（丙），但只测量考核是否存在，没有区分考核指标是否引用公开文本的具体内容。
>
> 【精确问题】本文的问题因而收窄为：省级考核指标是否引用公开文本的具体项目，如何影响地市公开文本的说明深度？
>
> 【答案预览】当省级考核只统计“是否公开”时，地市倾向于满足形式要求；当考核抽查具体项目的说明时，地市才补充调整说明。说明深度的分化来自考核指标的粒度，而非地方财力或领导重视。
>
> 【进路】本文比较该省 21 个地市 2016—2022 年的部门预算公开文本与省级考核指标文件，以两次考核口径调整为时间分界，核对每次调整前后各地市说明深度的变化。
>
> 【贡献边界】这一发现把财政透明度研究从“是否公开”推进到“公开什么”，并说明府际考核如何塑造公开质量；结论限于省内考核口径统一的地市，不推断跨省差异。

move 检查：张力来自材料内部的反差（趋同与分化并存），不是“重要”；既有解释先被公允转述并说明它能解释什么，再指出它解释不了本文现象的具体原因；精确问题由不足直接推出；答案预览只给最低限度判断，完整机制留给主体；进路交代比较单位与时间分界；贡献边界一句正面范围加一项不推断，不重复摘要。

### 2A.5 文献综述“罗列式 vs 对话式”段落对照

对话式综述把文献按立场组织，先让每一立场以来源会认可的形式成立并说明它能解释什么，再指出它留下的分析单位、条件或证据问题，最后写出本文从哪里进入。判准来自 `critical-reading-and-synthesis.md` §五：删掉作者姓名后，段落是否仍是一组有关系的判断而不是一串摘要。示例立场为虚构。

**第一组：实证议题（政务热线跨部门工单为何反复退回）**

罗列式：

> 甲研究了政务热线的制度设计，认为热线是回应型政府的重要载体。乙分析了热线工单的流转过程，发现部门间推诿是影响办结率的主要因素。丙运用问卷调查考察了市民对热线的满意度。丁从技术赋能的角度探讨了数字平台对热线效能的提升作用。戊则关注热线数据在城市治理中的应用。综上所述，既有研究从多个角度对政务热线进行了探讨，但仍有待深化。

对话式：

> 关于跨部门工单为何反复退回，既有研究给出两类解释。技术能力说（丁；戊）认为平台接入降低了信息传递成本，工单效率随平台功能升级而提高；这一解释与热线整体办结率的上升相符，却无法说明同一平台上不同牵头部门的退回率为何相差三倍。组织责任说（乙；甲的部分讨论）把退回归因于部门间的责任推诿，并已注意到责任归属不明的事项更易退回；但这支研究把“推诿”当作部门的稳定偏好，没有追问推诿在什么授权条件下减少。两类解释因而留下同一个问题：责任确认的路径由谁决定，以及这一路径改变时工单流转如何变化。本文以事项移交权的归属为比较变量，检验组织责任说未曾检验的授权条件。丙关于市民满意度的研究测量的是热线的外部评价，与本文的内部流转问题属于不同结果，不列为竞争解释。

对话式段落如何做到三件事：公允转述——每一立场先用它自己会接受的表述写出，并先说它能解释什么（整体办结率上升；责任不明事项易退回）；具体不足——指向分析单位（同平台部门差异）和未检验条件（授权条件），不是“有待深化”；本文位置——写明以什么变量、检验哪一支解释的哪个缺口。丙的研究因结果不同而被明确排除在竞争之外，对应 §3.1 的解释角色分类，不为显示周全强行并列。

**第二组：历史／理论议题（密折制度对清代皇权是集权强化还是信息纠偏）**

罗列式：

> 甲考察了密折制度的起源，认为它由康熙朝的奏折制度发展而来。乙整理了雍正朝密折的数量与地域分布。丙分析了密折在地方治理中的作用。丁讨论了密折与军机处的关系。戊从政治文化角度解释了密折制度的意义。本文在既有研究基础上，对密折制度进行进一步探讨。

对话式：

> 密折制度对清代皇权究竟意味着集权强化还是信息纠偏，既有研究存在真实分歧。集权说（甲；丁）以密折绕过通政司和内阁的通道特征为据，把它读作皇帝对督抚的直接控制工具；这一判断能解释密折为何集中于人事与地方军政，却难以说明雍正朝大量请安折与谢恩折的存在——若只为控制，何需如此高比例的无事之折。纠偏说（丙；戊）把密折视为皇帝校正常规奏报失真的补充信息源，强调其风闻性质与朱批中的核实要求；但这支研究主要依据朱批文本，较少追踪密折内容是否进入后续的部议或上谕，因而尚不能说明纠偏是否转化为制度行动。乙对密折数量与分布的整理为两派提供了共同材料，本身不作立场判断。分歧的症结在于：两派都把“集权”与“纠偏”当作互斥功能，而没有区分同一份密折在具奏、朱批、部议三个处理阶段各自承担的功能。本文以此为切入点，追踪一组密折的完整处理链，判断集权与纠偏在哪一阶段分离。

对话式段落如何做到三件事：公允转述——两派各自的证据基础（通道特征；朱批文本）和能解释的现象都先写出；具体不足——各指出一个对方证据难以容纳的经验事实（无事之折）或一个未追踪的环节（部议、上谕），不作总体贬抑；本文位置——把分歧重述为一个可判别的分析单位问题（处理阶段），再说明本文用什么材料判别。乙的材料性研究被如实定位为共同材料而非第三种立场，避免“三种竞争解释”的强行对称（§6“强行竞争”）。

### 3.14 总体结论

Overall Status: PASS

只有以下条件同时成立才写 PASS：

- 各表所有承重行以 PASS、REVISED、JUSTIFIED、通过、已修订、已改写或有据保留开头，没有 OPEN、FAIL、VERIFY、待修项；
- Title Revision Chain 三节点齐全并分别匹配问题承诺、执行后贡献校准和真实稿题；用户锁定题目没有被静默改写，final 无隐藏的实质改题，隔离读者能从标题复原问题、回答和范围；
- 已先完成外架构与章节角色审查：中心主张、引言、主体结构和结论可被快速定位，各节作用、控制性命题、关键术语与承接关系清楚；
- 题名规定的研究对象在摘要、引言、主体承重位置和结论持续可识别，作者分析框架始终是工具而未取代对象；
- 引言只给最低限度答案，主体承担完整定义、分析和证据，结论先完成实质回答；三者没有按同一次序整组复刻答案或以未来研究代替结论；
- 最强相关抗辩已处理；替代解释先按目标结果、作用阶段和经验预期分类，不把互补、阶段性或条件解释硬写成对称竞争；
- 每项实质边界都有一个完整说明位置，其他章节只保留必要限定；“无法确认/不能确定”式过程播报和重复局限已删除或转化为主张边界；
- 叙事包装图五阶段齐全并形成连续推进，而不是把传统章节改名为五个并列盒子；
- 对话与声音审计至少覆盖四个承重单元；承重命题的来源层级与主张匹配，来源声音、研究对象声音和作者判断边界清楚，隔离读者能复原谁说什么、作者如何回应及为何重要；
- 最强反方与预演审稿意见没有原样泄漏为正文答辩；确需显式反驳时有真实来源、同一问题与判别依据，边界段落在当前位置承担明确论证职能；
- 防御性单元已先按功能分类再处置；无必要免责声明和重复澄清已删除，必要范围、方法限制、证据限定、法律伦理边界与作者责任均有明确去向；高影响位置没有用 caveat 或自我削弱式贡献延迟实质判断；
- 至少一项真实实质修改已登记来源／证据复核和下游传播；若研究过程中确无主张变化，须以有据的局部处置说明，而不能用空表或“无”过闸；
- 外行读者能复述对象、问题与要紧处并指出坐直位置，内行读者能说出此前不知道的一件事；两位读者的分支与隔离方式已登记；
- 独立读者能先复述研究对象、具体问题、实质答案、最强证据和推断边界，再复述作者定位、认知路径与读者所得；首次出现作者拒绝事项压过对象／证据的位置已修复，或读者明确确认不存在；最大逻辑跳跃已修复或有据保留；
- 独立读者在承重单元中能恢复“发生什么—为什么—证据如何支持解释—改变什么认识”；不能恢复时已修复缺失的 warrant／证据功能，而不是只补过渡词；
- 最终稿不暴露评论顺序、隐性“质疑—让步—回复—限定”链、重复 Boundary ID 或局部后插补丁接缝；只看终稿的读者无法反推意见到来的顺序；
- 必要边界清楚但不过密，同一局限清单没有在多个章节审计式复刻；
- 正文中触发的风险表达都有上下文处置；任何保留项均有严格材料锚点、已登记 Claim、
  具体 claim delta、主张后唯一完整位置和去重记录，方法／证据／伦理／责任边界未被误删；
- 已对标题、摘要、正文、标题层级、图表文字、资料来源/注释和作者自写脚注完成异常措辞扫描；分析脚手架、审计腔与未经登记的压缩标签已改写或有据保留；
- 核心术语都能回查 `terminology_register.md`，通行译名、首次定义和中文学科谱系一致，正文无未登记变体；
- 普通正文未因修改过程新增粗体重点；任何保留的粗体均能回查目标刊模板、标题层级、学科规范或用户明确要求；
- 定性表达评价五维均有稿内证据、隔离读者反馈与处理决定，最终无 WEAK、NEEDS REVISION 或未解决项；
- distinguished 模式下：增强登记表至少 3 行实质动作、忠实性六类损失为 0、五维判决无 REGRESSED 且至少 4 维为 IMPROVED/MET。

## 4. 与审计阶段的分工

本协议的工件是作者侧自查；独立质量判断由 audit 阶段既有的三份隔离评审承担，不再单独组织文笔盲评。写作评审（Clarity/Writing Reviewer）只看最终正文，不看本工件或 `dialogic_argument_map.md`，先在承重单元复原“发生什么—为什么—证据如何支持—改变什么认识”，再独立复原研究对象、具体问题、实质答案、最强证据和推断边界。它还须复原谁在说什么、作者如何回应以及为何重要，并检查正面范围表达、证据的解释功能和修订清洁度；任何作者意图、框架名、隐性答辩链、评论顺序或补丁接缝压过对象—证据主线的位置都必须定位。distinguished 模式下它还对五维（洞见、思想、逻辑、文气、声音）逐维给出有证据的判断。Contribution Reviewer 另行判断前人立场是否公允、回应是否有增量、已激活反方是否成立以及真实 `Who Cares` / `So What` 是否具体；0 个反方或 1 条读者更新本身不构成缺陷。

三份 strict-v2 评审的 `Text Action` 仍使用 `DELETE|REPLACE|MOVE|ADD|NO_ACTION`；这是 review lifecycle 的问题修复路由，不是 Clarity Editor 的句子编辑账本，不得把 `BRIDGE|DEFINE` 混入 raw review 合同。三位评审均可 `Review Verdict: PASS` 且不写 finding；评审结论与本工件冲突时，先把合法 finding 归并为 Claim/Evidence/Structure Delta，必要时回到事实拥有阶段，重画受影响的 section blueprint 后整节重写，再重跑 `academic_prose_check.py`；不按意见顺序向正文逐条打补丁。

## 5. 学科与体裁适配

| 体裁 | 审查重点 | 增强遍加权 | 回炉条件 |
|---|---|---|---|
| 定量实证 | 主张力度、变量关系、因果词；结果段解释估计量回答哪个主张 | 问题洞见、结果含义、讨论声音；方法与结果报告只求透明 | 识别不足却增强因果措辞；按模型编号报数；数字或限制丢失 |
| 定性/案例 | 机制链、行动者意义、材料与概念之间的担保 | 洞见、机制逻辑、叙事节奏、人的面孔 | 机制环节不可见、材料只作故事或只作插图 |
| 理论/规范 | 前提、推理链、最强反方、概念边界 | 洞见、思想、逻辑、辨识度；理论角色功能清楚 | 前提不公开、最强反方未处理、概念无边界 |
| 描述/类型学 | 分类规则、比较逻辑 | 思想、概念压缩、展示—解释平衡 | 分类维度重叠、名称先于证据 |
| 文献综述 | 综合逻辑、纳入边界、文献间关系 | 综合判断、对话结构、作者立场 | 逐篇搬运摘要、综合命题无文献覆盖、文献成为无功能角色 |

文献综述的承重判断必须回溯到当前 `SYN-*`；`CR-*` 提供逐篇证据边界，`SYN-*` 提供来源关系、可比性、异质性解释和分析者判断。正文不展示这些内部编号，但若删除作者姓名后只剩一串彼此无关系的摘要，或无法说明来源分歧为何产生，就回到 research 的综合层，不能靠连接词润色补救。

目标刊范文决定段落长度、第一人称、标题形式和术语密度。本协议只规定读者可恢复的论证功能，不强迫不同学科采用同一表面风格。

## 6. 反模式与回炉路径

- **局部先行**：引言、结论、中心主张和章节角色尚未稳定，就先改同义词、加连接词、调 Word 样式或给重点句加粗 → 回到前置审查；恢复外架构后再向下修改。
- **对象被框架取代**：标题研究 A，正文逐渐只解释作者命名的 B 框架，摘要、主体和结论已说不清对 A 作出什么判断 → 回到前置审查和 research/contribution；恢复 A 的问题主语，把 B 降回分析工具。
- **二手声音代替对象声音**：关于原典、正式文件、档案、数据或原研究内容的承重判断只引二手转述，或把二手解释写成对象原意 → 回到来源—主张匹配；用最接近命题的原始来源承重，二手研究承担定位和解释，无法取得原始来源则明确降级。
- 先换同义词和连接词，后处理逻辑 → 回到第一遍。
- **引言抢写主体**：引言已按与核心分析相同的顺序完成概念界定、功能分解和证据判断，主体只能再次展开同一答案 → 回到 §3.0 和 §3.4；引言保留张力、问题、进路和最低限度答案，完整论证归主体。
- **强行竞争**：把解释不同阶段、不同结果或不同层次的观点并列成“三种竞争性解释”，却没有共同待解释结果和可区分预期 → 回到 §3.1，改标互补/阶段性/条件关系并移入相应机制环节；无独特功能者删除。
- **审稿答辩前台化**：把“最强反对意见—这一质疑成立—本文仅能说明”从内部论证图直接搬进正文，或插入只负责自我限缩的孤立段 → 回到第二遍与 §3.2；改写为已有成果、剩余问题、有限推进，把边界放进真正改变主张的位置。
- **作者说明压过对象**：摘要、引言、核心分析或结论先后说明“本文不做什么、如何界定自己、怎样回应质疑”，但删去这些句子后读者说不出对象发生了什么、材料显示什么或正文给出什么答案 → 回到 §1.2 和第二遍；恢复对象／行动、证据、判断与必要边界的论证关系，排列按局部功能决定，只保留不可替代的作者责任。
- **谨慎播报**：连续使用“只能说明、不能确定、无法确认、尚不足以”叙述研究过程，或在摘要、方法、分析、结论重复同一局限 → 回到 §3.2，只在承重位置完整说明不确定性的来源及其对主张的影响，其他位置缩短或删除。
- **否定转折惯性**：反复用“不是／并非／不在于……而是／而在于”定义概念、宣告贡献或组织段落，或用“本文不把／不试图／无意／并非旨在”说明作者意图 → 回到第三遍，改写为分析对象、直接判断和适用范围；只保留原文引语、文献题名及确有二分纠偏功能的句子，并在 §3.8 说明理由。
- **结论退成工作说明**：结论主要罗列本文贡献限于什么、材料不能推出什么和未来还可研究什么，实质回答反而缺席 → 回到增强遍分节审查；使研究判断、知识增量、必要范围和真实未决问题形成闭环，不机械限定句子次序。
- 以“短句越多、主动语态越多”代替清晰度判断；为避免重复而让核心术语漂移 → 第三遍。
- **形式大于内容**：机械套五阶段、把传统章节改名成戏剧术语、每节都造悬念，或用漂亮过渡掩盖没有证据的张力 → 返回第一遍或 research 的问题确认检查点；叙事包装只能组织真实认知增量。
- **伪凝练**：为缩短篇幅删掉条件、负结果、限定和担保；或把多个论证动作塞进一句“高密度”长句 → 第三、四遍。
- **主体抹除**：制度、组织或政策“自行实现/形成/推进”，读者看不见谁行动、谁受影响；反向地，在行动者无关时强塞第一人称或主动语态比例 → 第二、三遍。
- **展示与解释失衡**：案例、引文、数字或图表很多却不说明其意义；只有概念判断却不给读者看见证据 → 第二遍。
- 用“因此、然而、由此可见”掩盖缺失的前提；堆引文或数字却不写担保 → 第二遍。
- 把相关写成因果、有限案例写成普遍规律；把限定判断写成不容反驳的断言 → 第四遍。
- **伪洞见**：只有反常句式，没有反常证据 → 返回 research 的问题确认检查点。
- **思想注水**：换名不换解释；一段连造多个新名词；用“化、性、感、力、逻辑、机制、范式、赋能、耦合”等构词制造虚假新意 → 返回 design，按 `terminology-governance.md` 做精确/近义撞车检索、既有概念比较和术语数量收缩。
- **谱系失联**：有中文学界通行术语却自造同义词、随意另译外文概念、把政策口号直接当分析概念，或把古雅措辞误作学术传统 → 回到 `terminology_register.md`，补通行用法、原文、学科谱系和近邻区分。
- **文气过载**：排比、比喻、四字格、古雅词遮蔽证据；修辞比证据更醒目 → 撤销增强，恢复清晰版。
- **分析脚手架泄漏**：用“第几层、止步处、叠起来、落点、断点、链条、入口”等空间或流程隐喻代替具体学术关系；把写作时的临时框架名直接留在标题、段首或图表中 → 回到第三遍，逐处还原为研究限度、时间关系、证据差异、制度安排或因果环节。
- **审计/工程腔外泄**：把正文写成核验、核定、校验、审计、裁决、对弈、映射、闭环、跑通或接口说明；表头使用“判定、相合程度、核验状态”等内部工作语 → 改写为材料选择、比较对象、文献定位、解释依据与适用范围；确属方法程序的内容只在研究设计中准确保留。
- **内部获取日志外泄**：标题、正文、表格或图注出现“来源获取失败、抓取失败、下载报错、请求超时、工具不可用”等运行记录 → 日志留在工作区；正文只说明当前可观察的材料状态、替代材料为何可用或不可用，以及这一状态怎样改变具体主张。若获取失败导致必要证据缺失且无法合法替代，保持阻塞而不是把失败记录包装成论文发现。
- **缺失直接升级为必然**：把“没有、未出现、为零”直接接到“说明不能／必须／只能／足以”，却没有对照、担保或相邻解释处置 → 回到 §1.3；先报告观察分布，再补足可复核的推断桥，补不出就降低为描述性判断。
- **粗体代替承重**：在普通正文中把中心句、关键词或修改痕迹逐处加粗，让版式替代主题句、位置和论证关系 → 去掉新增粗体；只有目标刊模板、标题层级、学科规范或用户明确要求时保留。
- **名家拼贴**：出现范文稀有搭配、比喻或相邻句序 → 删除并从事实笔记闭卷重写。
- **定量文学化**：数字、标准误、方向或限制被删 → 立即判 FAIL。
- 为故事顺滑删除负结果、竞争解释或局限；为显示谨慎在每个章节完整重列同一组局限 → 第一、二遍。
- 只让作者本人填写读者测试；让工件成为事后勾选表而不回写正文 → 终遍重做。

## 7. 研究依据

本协议吸收以下可复用原则，不把来源中的英文表面规则机械移植到中文：

- Gopen, G. D., & Swan, J. A. (1990). [The Science of Scientific Writing](https://www.popecol.org/wp-content/uploads/2020/09/Gopen-Swan-1990.pdf)：读者预期、主题位置、重音位置、旧—新信息和主谓邻近。
- Doumont, J. [Effective Writing](https://www.nature.com/scitable/topicpage/effective-writing-13815989/), Nature Scitable：主句承载主意、动作回到动词、清楚准确简洁。
- Harvard College Writing Center. [Thesis](https://writingcenter.fas.harvard.edu/thesis); [Anatomy of a Body Paragraph](https://writingcenter.fas.harvard.edu/anatomy-body-paragraph)：可争论主张与主题句—证据—分析。
- University of Oxford. [Hedging](https://lifelong-learning.ox.ac.uk/hedging/)：主张力度与证据确定性匹配，同时避免过度限定。
- Hyland, K. (2005). [Stance and engagement](https://doi.org/10.1177/1461445605050365)：作者立场和读者互动是学术声音的组成部分。
- Alvesson, M., & Sandberg, J. (2011). [Generating Research Questions Through Problematization](https://journals.aom.org/doi/pdf/10.5465/amr.2009.0188)：通过质疑隐含假设生成更有影响力的问题。
- Sword, H. (2012). [Stylish Academic Writing](https://www.helensword.com/stylish-academic-writing)：跨学科语料显示清晰、具体与作者在场并不违背学术规范。
