# 研究空白的两轴诊断与回退协议

本协议把“七类研究空白”吸收为开放式诊断语言，但不把它们变成七个阶段、七列必填项、七项配额或关键词分数。它只回答一个工作流问题：**基于当前跨文献综合，哪一个具体命题仍不能得到有把握的回答，为什么不能，以及当前研究因此承担什么可检验责任？**

## 1. 来源定位：不是封闭的权威七分法

常见中文讲解中的“知识、概念、理论、实证、方法、群体、实践”是有用的教学归纳，但不是 Miles（2017）原文七类的准确转录。Miles 列出的是 evidence、knowledge、practical-knowledge conflict、methodological、empirical、theoretical 与 population；其中没有 conceptual gap。Miles 又是把 Jacobs（2011）讨论的研究问题类型与既有 gap 文献重新组织成 taxonomy，并不意味着 Jacobs 已提出同一套七类。

Müller-Bloch 与 Kranz 的官方会议记录为 ICIS 2015，论文目标是让定性综述中的 gap 识别更严谨、可复现，同时保留研究者的创造性判断。引用时使用[官方 AISeL 记录](https://aisel.aisnet.org/icis2015/proceedings/ResearchMethods/2/)，不要把 Miles 文中的 2014 简写当作无争议年份。Miles 原文可核对其[作者上传版本](https://www.researchgate.net/profile/D-Miles/publication/319244623_ARTICLE_Research_Methods_and_Strategies_Workshop_A_Taxonomy_of_Research_Gaps_Identifying_and_Defining_the_Seven_Research_Gaps/links/599d9781a6fdcc500350a2db/ARTICLE-Research-Methods-and-Strategies-Workshop-A-Taxonomy-of-Research-Gaps-Identifying-and-Defining-the-Seven-Research-Gaps.pdf)。

因此，本工作流不声称复刻某一原始 taxonomy，而是用“两轴诊断”保存七类提示的认识价值，并消除类别重叠、标签堆砌和方法先行。

## 2. 第一轴：空白落点

每个候选只登记一个 `Primary Locus`。其他位置可以作为条件或后果叙述，但不得叠成“六项创新”。“知识空白”是下面落点与阻断原因组合后的总体知识状态，不与其余类型并列。

| 规范值 | 它真正追问什么 | 成立所需的最低理由 | 不能单独成立的说法 |
|---|---|---|---|
| `concept-measurement` | 概念、分类或测量如何妨碍比较与判断 | 定义差异确实改变对象归类、测量、跨研究可比性或推断 | “定义很多”“我要提出新概念” |
| `theory-explanation` | 哪个异常、竞争解释、失效前提或范围条件仍未解决 | 至少有一个待解释结果和可区分的理论预期或异常 | “时代变了，旧理论过时”“构建新框架” |
| `evidence` | 当前证据为何不足以支持一个重要命题 | 明确证据精度、年代、质量、独立性、冲突或缺失及其后果 | “样本小”“再收一些数据” |
| `identification-method` | 既有观察或设计留下了什么测量、识别或解释盲点 | 旧工具造成明确偏误／不可观察项，新设计能改变可见证据或识别能力 | “用了新算法”“效率更高” |
| `scope-population` | 既有主张能否迁移到未覆盖群体、情境、时期或层级 | 说明既有结论是否越界外推，新范围能检验何种异质性、边界或知识公平责任 | “这个群体没人研究” |
| `action-practice` | 既有知识为何不能支持特定行动判断 | 明确行动主体、目标、约束、知识—行动冲突、证据桥与评价标准 | “有现实意义”“可服务政策” |

理论研究不强制制造实践转化；复制、复现、再分析与三角验证也不因“重复”二字失去贡献资格。它们是否值得做，取决于能否修复一个重要证据责任。

空白诊断还应指向可能的认识更新。对入围候选，比较最可能消解该主张的最近邻，指出承重假定、
范围或证据可信度是否需要改变。旧解释与替代解释若没有可区分预期，先保留为待解决责任；
不要把描述性差异改名为机制创新。字段与只读视图见 `topic-selection-protocol.md` §6。

## 3. 第二轴：为什么当前不能下结论

至少登记一个 `Obstruction`；多个原因可并列，但每个都须由同一 `SYN-*` 关系或其连接的来源支持。

| 规范值 | 含义 |
|---|---|
| `insufficient-or-imprecise` | 信息不足、精度不足或关键观察缺失，当前区间仍容纳性质不同的答案 |
| `biased-coverage` | 样本、来源、发表、保存、访问或知识生产偏向使可见证据系统性失衡 |
| `inconsistent-or-incomparable` | 结果表面冲突；经对象、时期、概念、测量、样本和设计核对后，仍需裁决真实冲突，或确认不可比本身阻断结论 |
| `misaligned-or-condition-changed` | 现有知识与当前问题、单位、行动条件或历史阶段错配，或承重条件已发生可证明的变化 |

“文献少”只是检索观察。它可能来自发表时滞、术语错配、精确题名未命中、相邻研究覆盖、访问／索引限制，或这个对象没有足够的理论张力。只有说明这些替代解释为何不足，才能把低命中升级为研究空白。

## 4. 生命周期：允许空白被改类或撤回

| 位置 | 允许状态 | 责任 |
|---|---|---|
| `intake` | `author-stated` / `candidate` | 只登记实践张力、未知与可推翻条件，不宣称真实 gap，不据此选方法 |
| `acquisition ⇄ research` | `candidate` → `corroborated` | 先完成 `CR-*` 与 `SYN-*`，再判断具体未知、阻断原因、反替代、研究责任与撤回条件 |
| 问题承诺 | 只允许 `corroborated` | 用户确认精确问题、工作标题与本诊断；确认前停止，不进 design 或正文 |
| `design` | `corroborated` | 把诊断转成条件式观察／识别／比较／行动责任；不得由标签自动选择方法 |
| `execution` | `corroborated` / `reclassified` / `withdrawn` | 证据可保留、收窄、改类或撤回原诊断；核心变化必须回 research |
| `audit` | 当前有效诊断 | 检查引言 gap、`SYN-*`、问题、执行结果与实际贡献是否仍是同一件事 |

`reclassified` 和 `withdrawn` 是合法认识结果，但会阻止 build；不得为维持题目或贡献而把它们改写成“仍填补空白”。

## 5. 现有字段内的最小合同

不增加候选表列。在现有 `Gap Reality Check`、`confirmed_motivation.md` 的 `Gap Diagnosis` 与 `research_design.json.knowledge_state.gap_authenticity` 中重复同一份核心诊断：

```text
Status=corroborated；
Primary Locus=theory-explanation；
Obstruction=inconsistent-or-incomparable；
Gap Claim=在相同制度压力下，现有理论仍不能区分资源约束何时改变项目选择机制；
Evidence Basis=SYN-GAP-1 综合了支持、负例与可比性判断；
Rival Explanations=已检查发表时滞、术语错配、相邻覆盖及仅因对象新而低命中；
Research Responsibility=比较同一结果并检验两种解释的区分性预期；
Withdrawal Condition=若差异完全由统计口径或不可比时期造成则撤回该空白
```

字段可以用英文或协议列出的中文别名，但值使用规范状态、落点和阻断原因最稳定。`Evidence Basis` 至少链接一个当前 `literature_analysis.json` 中真实存在的 `SYN-*`；Source ID、Query ID 与检索日期继续由综合单元、输入账本和 `Collision Trace` 承担，不在这个单元重复制造来源真相。

问题承诺与 design 之间必须保持 `Primary Locus`、`Obstruction`、`Gap Claim` 和 `SYN-*` 核心身份一致。设计可细化方法责任，但不能静默换 gap。

## 6. 硬门与语义评审的边界

机器只检查：

- 八个标签字段是否存在且不是占位符；
- 状态是否允许进入当前阶段；
- 只有一个主落点，阻断原因是否来自开放规范表；
- `Evidence Basis` 是否引用当前有效 `SYN-*`；
- 问题承诺与设计的核心诊断是否漂移。

机器不检查“这个 gap 是否足够重要”，也不因出现“理论、机制、概念、方法、创新”等词而判 PASS。Contribution Reviewer 结合正文、确认合同、`SYN-*`、执行结果与反方，判断：

1. 所谓 gap 是否只是作者措辞、低命中或标签堆砌；
2. gap、研究问题、实际回答与贡献是否同一；
3. 研究是否真正履行了登记的责任；
4. 负面结果是否已使 gap 收窄、改类或撤回；
5. 正文是否用“填补空白”代替具体认识增量。

任何语义审查失败都回到拥有事实的最早阶段，不靠改写标签过门。
