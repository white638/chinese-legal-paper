# 原典专著页码证据渠道手册（2026-06 核实）

所有渠道的共同点：**逐页影印或原版原式，页码与纸书一致**——这是能产 A 级
证据的资格线。流式排版（epub/微信读书/得到）一律不合格。

## 决策树

```
引用的是什么书？
├─ 马恩列斯毛邓等经典著作（人民出版社系） → ① 理论库
├─ 古籍整理本（点校本二十四史等中华书局系） → ④ 籍合网
├─ 一般中文专著（含汉译名著）
│    ├─ 有机构访问权限 → ② 读秀/超星
│    └─ 无权限 → ③ 全国图书馆参考咨询联盟（免费）
├─ 外文专著 → ⑤ Google Books → Internet Archive → HathiTrust
│             → ⑥ 馆藏出版社电子书平台
└─ 以上全部失败 → ⑦ 知网三角旁证（C 级，不解除 VERIFY）
     ├─ 同时把该条列入【VERIFY】清单
     └─ 或与用户商量降级为章节级引用 / 改用规范定位符
```

任何一步命中 → 截图存证 → 登记 A 级行 → 停止向下。

上面的树只覆盖图书类原典与专著。档案件（一史馆、台北故宫、二史馆）、实录与政书电子库
（籍合网、爱如生、书同文、汉籍电子文献）、地方志、近代报刊影像（全国报刊索引、《申报》）、
政府公报与人民日报图文库这几类材料的页面影像来源，见
`cnki-paper/references/source-channels-cn.md` 第 3.1–3.7 节；它们同样按"逐页影像＋页码或
档号／版次角标可见"作 A 级资格线，著录与定位符走 `primary-source-citation.md` 第 5 节。

## ① 中国共产党思想理论资源数据库（人民出版社"理论库"）

- **覆盖**：马恩列斯毛邓直至当代的全部经典著作与党的文献，1.5 万余册，
  原版原式，官方明确"可直接进行引用"。政治学/马理论论文的头号渠道。
- **入口**：多数高校图书馆数据库列表内（校园网/VPN 直入）；校外无权限时
  转 ②③。
- **操作**：库内全文检索引文片段 → 命中条目显示卷册与页码 → 打开页面影像
  截图。《马克思恩格斯文集》(2009)、《选集》(2012) 等标准引用版本全部在库。
- **登记**：Evidence Source 写条目 URL；Work 锁定到卷（如
  `马克思恩格斯文集(第5卷). 人民出版社, 2009`）。

## ② 读秀 / 超星知识搜索

- **覆盖**：650 万种中文图书题录、315 万种原文，16.7 亿页可全文检索。
- **入口**：高校图书馆订购（读秀学术搜索 / 超星发现）。
- **操作**："知识"频道检索引文片段 → 命中结果直接标注**所在页码** → 点开
  试读看该页影像 → 截图。试读页数受限时用"图书馆文献传递"按页码区间发
  邮箱（单次 ≤50 页），收到的页图同样可作 A 级证据。
- **坑**：检索词带标点会漏检，先去标点取 10-20 字实词片段；同书多版本时
  认准与引用条目一致的出版年/ISBN 再截图。

## ③ 全国图书馆参考咨询联盟（免费兜底）

- **覆盖**：与读秀同源（超星扫描库），230 万种电子书。
- **入口**：http://www.ucdrs.superlib.net/ ——**无机构身份也能检索试读**，
  注册邮箱即可文献传递（单次 ≤50 页，同书每周 ≤20%）。
- **操作**：图书频道按书名/ISBN 检索 → "图书馆文献传递"填页码区间 →
  邮箱收页图；部分书有在线试读可直接截图。
- **定位技巧**：本渠道全文检索弱于读秀。不知道页码时，先传目录页定位章节，
  再传该章节页码区间，在页图里逐页视觉确认引文。

## ④ 籍合网 · 中华经典古籍库（中华书局）

- **覆盖**：中华书局及多家古籍社正式出版的**整理本/点校本**古籍。
- **入口**：https://www.ancientbooks.cn/ （机构订购为主，个人可单库付费）。
- **关键能力**：文字与原书图像逐页对照，**页码与纸书一一对应**；选中文字
  可"引用"**自动生成含版本与页码的著录串**——直接复制进 Page Evidence 行。
- **登记**：Work 锁定点校本版次（如 `史记(点校本二十四史修订本). 中华书局, 2014`）。
- 先秦两汉文本的篇章定位可辅以 ctext.org（中国哲学书电子化计划，免费，
  带影印对照），但 ctext 本身不给点校本页码，只用于规范定位符核对。

## ⑤ 外文三件套：Google Books / Internet Archive / HathiTrust

按命中率顺序使用，三者互补：

| 渠道 | 用法 | 产证形态 |
|---|---|---|
| Google Books (books.google.com) | 书内全文检索；预览/摘录视图显示**真实页码**与版本信息（About this book 核对版次） | 命中页截图（含页码角标） |
| Internet Archive (archive.org) | 全文检索 + 受控借阅（免费账号，1 小时/14 天）；逐页扫描忠实纸书 | 借阅后翻到该页截图 |
| HathiTrust (hathitrust.org) | 即使受限视图也返回**页级命中列表**（"第 X 页含该词"）；公版书可看全文 | 命中页清单 + 可看时的页图 |

- 版本陷阱：Google Books 同书常索引多个版次，截图前必须核对出版年与
  引用条目一致；不一致时改在 IA/HathiTrust 找对应版次。
- 西方原典优先用规范定位符（见下表），页码作版次附注。

## ⑥ 馆藏出版社电子书平台

ProQuest Ebook Central、EBSCO eBooks、JSTOR（books）、Cambridge Core、
Oxford Academic、De Gruyter、SpringerLink 的出版社 PDF 与纸书页码一致：
下载到本地后直接走 `pdf_locate.py` 产 **B 级**证据（比截图更快）。
国内平台同理：Apabi（方正）原版式电子书可比照办理。

## ⑦ 知网三角旁证（C 级）

1. `cnki-advanced-search` 检索字段切**全文（FT）**，检索词用引文片段中
   最特异的 10-15 字（去标点）。
2. 在命中论文里找引用了同段文字且标注**同一版本同一页码**的脚注/参考文献。
3. 凑够 ≥2 篇**互相独立**（不同作者群、不同机构）→ 两篇知网 URL 写入
   Evidence Source → Tier `C`，Status 仍 `VERIFY`。
4. 只找到 1 篇或版本不一致：不登记 C 级，直接留【VERIFY】。

## 规范定位符对照表（版本无关，优先于页码）

| 原典 | 定位符 | 示例 |
|---|---|---|
| 柏拉图 | Stephanus 页码 | `Republic 514a` |
| 亚里士多德 | Bekker 码 | `Pol. 1253a2` |
| 康德 | 科学院版 AA 卷:页 | `AA 4:421` |
| 黑格尔 | 节号（§）+ 版本附注 | `《法哲学原理》§258` |
| 维特根斯坦 | 命题号/节号 | `TLP 5.6` / `PI §109` |
| 先秦典籍 | 篇章号 | `《论语·学而》` `《孟子·梁惠王上》` |
| 二十四史 | 卷 + 点校本页码 | `《史记》卷六十八, 中华书局点校本, 第2228页` |
| 马恩（中文） | 《文集》(2009) 卷+页 | `《马克思恩格斯文集》第5卷, 第610页`（理论库可核） |
| 圣经/古兰经 | 章:节 | `罗 13:1` |

Locator 列写定位符时，audit 脚本按文本匹配核对，不要求数字页码。

## 禁令与注意

- **禁止**：微信读书、得到、Kindle 流式版、盗版影印站作为页码来源。
- 截图必须含**页码角标或卷册信息**，只截正文无法证明页码。
- 渠道页面改版属常态：本手册核实于 2026-06；操作失效时以"逐页影印 +
  页码与纸书一致"为资格线自行甄别替代渠道，并更新本文件。
