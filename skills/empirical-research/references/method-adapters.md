# v4.0 方法适配器

## 使用方式

机器字段以 `method-adapter-registry.json` 为准。本文件解释为什么需要这些字段、何时不适用，以及哪些判断不能被固定阈值替代。每条路线在 `research_design.json.method_routes[]` 中获得稳定 Design ID；执行事实写入 `method_execution.json.runs[]`。

operation 是否分发隔离研究者由同一 registry 的 `researcher_dispatch_policy` 与设计风险共同编译；
任务、隔离、仲裁及严格输出合同见 `researcher-collaboration.md`，不得在方法段另建人工配额或名单。

所有路线先满足共同项：问题/主张映射、主辅角色、依赖、单位、材料边界、选择逻辑、权限、伦理、复现、证据独立性、报告计划、推断上限和禁止推断。

## 核心方法要求 ID

下列 ID 是期刊 overlay 可引用的核心科学要求。它们由唯一方法注册表、类型合同和执行
validator 解释；期刊 pack 只能要求在正文、附录或复现包中呈现对应记录，不能另选估计器、
设阈值或修复失败诊断。

| Requirement ID | 核心含义 |
|---|---|
| `CORE.CAUSAL.ESTIMAND_BINDING` | 因果路线以 `causal-design/v1` 登记 estimand、单位、反事实和识别假设；venue 不得改写目标量。 |
| `CORE.CAUSAL.ASSUMPTION_DIAGNOSTICS` | 识别假设绑定专属诊断工件；失败时收窄或撤回推断，不能用 limitation 段落补救。 |
| `CORE.PANEL.STAGGERED_DESIGN` | `causal-panel/v1` 登记处理批次、对照组、处理前窗口、时序与安慰剂诊断；估计实现须服务已登记 estimand，而不是由期刊指定一个通用 estimator。 |
| `CORE.INFERENCE.DEPENDENCE_ALIGNMENT` | 独立性单位、处理分配层级、网络/簇依赖与不确定性处理必须一致；对应字段和诊断由核心合同决定。 |
| `CORE.INFERENCE.MULTIPLICITY_PLAN` | 多结局、多臂或多重比较的 family、预定处置与探索性降级在核心设计中登记；venue 只能报告实际处置。 |
| `CORE.INFERENCE.SENSITIVITY_BINDING` | 敏感性分析针对已登记识别假设与失败模式，由核心合同选择并绑定工件；不存在跨设计统一 battery。 |
| `CORE.MEASUREMENT.CLASSIFICATION_DIAGNOSTICS` | 分类、聚类或潜类模型报告其登记的类别级诊断、误差与敏感性；AvePP 等指标没有跨项目通用硬阈值。 |
| `CORE.REPRO.STOCHASTIC_IDENTITY` | 随机步骤登记软件、版本、参数、种子或重复运行身份及输出工件；venue 只决定披露位置。 |
| `CORE.EXPERIMENT.REGISTERED_DESIGN` | `experiment` family 登记干预、比较、分配、实施/流失/干扰计划、预注册身份与执行诊断；venue 只报告登记事实和偏离。 |
| `CORE.QUAL.REGISTERED_SELECTION_EVIDENCE` | `case_study`、`process_tracing`、`congruence_analysis` 等 family 登记案例/材料选择、竞争解释、来源独立性和证据链；venue 不得另建选择规则或诊断测试。 |
| `CORE.MEASUREMENT.REGISTERED_VALIDATION` | 调查、内容分析、文本测量和计算路线的构念、编码/测量验证、误差、稳定性与允许解释由 core family/typed contract 登记；venue 不设统一阈值。 |
| `CORE.NETWORK.REGISTERED_BOUNDARY` | 网络路线的边界、边定义、依赖计划、缺失关系与诊断由核心 registry/contract 决定；venue 只呈现其 Artifact 和 disposition。 |

“报告核心 estimand/诊断”属于期刊呈现要求；“改用某估计器”“在某层聚类”“达到固定
指标才有效”属于核心方法决定，不能留在 venue pack。

## 实验

- 设计：干预、比较、分配机制、随机化可验证记录、结果时序、操纵检查、流失、不依从、干扰、预注册、欺骗/事后说明、内外部效度。
- 执行：分配审计、基线与流程、操纵/流失/不依从/干扰结果、结果与效度诊断。
- 硬错：把不可核验或非随机分配写成随机；伦理/权限缺失；设计后更换结果或分配而未登记。
- 评审：效度强弱和推广范围。实验标签本身不证明因果。

分配机制仍有原始日志可核验时，先暂停确认性随机化主张并审计不可预测性、覆盖、换组和干扰；只有审计证明机制并非随机或记录不可恢复时，才撤销相应标签。随机化单位须对应真实干扰网络与分析层级。多臂/多结局实验预定比较族与多重性控制；反复看结果时使用预定序贯边界、独立监测和盲态运行检查。分配效应、实际接受效应和更换结果后的探索性效应必须分开，不能用一个“实验效应”合并；未送达或未依从不自动退出 ITT 分母。

## 调查

`modes` 可包含 observation、interview、focus_group、questionnaire。设计记录总体、抽样/招募框、工具版本、预测试、调查员训练、应答、缺失、权重、测量误差和数据保护；执行记录真实模式、现场日志、应答/招募、缺失、权重、测量检查和保护动作。抽样框或版本缺失可硬检；代表性和样本充分性需结合目标总体评审。

## 案例导向剖面、案例研究与过程追踪

一般案例研究先用时间、空间、行动者/组织和事件或阶段界定案例，再记录案例总体、结果知情时点、选择、嵌入单元、证据链、来源独立性、时间线、理论复制与理论对话。结果导向选案或门卫控制进入时，另用角色覆盖矩阵和接触/拒访/不可达日志区分目标、可访问与实际材料范围；不能把负责人或胜者视角写成全体经验。反证计划应落到具体失败节点、受损群体、替代成功原因和不一致材料，受限证据按公开、受控复核、不得共享分级，不得为复核越过许可。虚构对照、同源伪独立和越权发布可阻断；案例价值、证据诊断力和可迁移范围由独立解释性研究运行评审并绑定证据。跨案例匹配只服务真实比较问题，不是单案例通用门槛。案例研究是总体设计，过程追踪可以成为其主要案例内分析路线，不应被机械降为辅助；只有明确了机制节点、同阶段竞争机制、预期痕迹、负面证据和范围条件后，才可声称执行了过程追踪。来源独立性相对于具体主张判断：同一材料可证明某说法出现或传播，却未必证明行动者采纳或决定改变。共同上游材料不能伪装成独立印证；案例数量不是通用质量阈值。

`case_study`、`process_tracing`、`qca`、`comparative` 和 `congruence_analysis` 共享
`case_design` 剖面，但仍保留各自适配器。设计以 CUN/CAS/SCP/CMP/WCA 身份连接案例总体、
案例、范围条件、跨案例比较和个案内分析。因果效应、机制、组态和理论评价分别登记；一般案例
研究不自动具有机制能力。跨案例与个案内分析并用时声明 `cross-case-first`、
`within-case-first` 或 `iterative`，并记录实际交接、材料角色分离和综合推断上限。

## 一致性分析

一致性分析以竞争理论的相对评价为目标：设计登记竞争理论、各自可区分预测、可观察含义、
来源独立性、范围条件和推断边界；执行登记预测—观察矩阵、理论拟合、异常观察、范围修订和
边界审计。预测若不能区分理论，属于评审风险；矩阵缺失属于未执行。理论与观察一致不能单独
证明平均效应或完整机制，机制主张须另由过程追踪路线及机制痕迹支持。

## QCA

设计记录集合类型、条件/结果、校准依据、真值表计划、矛盾组态、逻辑余项、解类型、稳健性和回到案例。执行冻结校准表、真值表、矛盾与余项处置、解、敏感性和案例解释。条件晚于结果时先修复答案对象：可以把结果改到真正晚于条件的时期，或把该条件移出因果配置并降为后果/解释材料；聚类标准误不能修复集合时序。不得将某一固定 consistency、frequency 或条件数变成通用门禁；阈值理由与敏感性进入评审。

## 文本路线

- 内容分析：语料、单位、版本/预处理、编码手册、信度适用性、验证和语境边界。
- 话语分析：语境、权力、研究者位置、竞争解读、反身性和解释边界；分别冻结分析单位与语境单位，以言语事件连接原文、译文、修订和转载版本；沉默主张须由文种模板、制度职责、前后版本或可比主体建立“本应出现”的期待基础；不强迫编码一致性。文本中的正当化框架、主体位置或可说性不是已经发生的组织实践或社会效果；后者需要独立实践材料、受众接受或组织传导与时间链。
- 文本即数据：语料、单位、版本/预处理、表示、训练/验证/测试隔离、模型验证、语境与解释边界。预测任务先冻结预测时点、独立标签来源与随访窗；实体与时间必须在同一嵌套切分中同时隔离，外层锁定未来测试并区分既见/未见实体。外部直接运输与重校准分开，标签/OCR/版本/群体/罕见文本误差由领域人员复核。

训练材料混入独立验证、语料版本缺失或结果工件变更属于硬错。固定信度或性能阈值只作方法特定评审。

## 社会网络

记录节点、关系、网络边界、方向/权重/时间、缺失关系、依赖结构、模型诊断、机制主张和再识别风险。执行需保留节点/边清单、名称与组织消歧、二模事件及投影权重、边界与缺失审计、依赖感知模型、诊断和隐私控制。多人事件投影用分数计数等方案避免关系膨胀；数据库扩容用稳定覆盖子样本、固定节点面板、同规模随机基准和断点复算诊断；零边区分真实无关系与未知收录。把节点或关系当作普通独立观测会触发评审；中心性和网络结构本身不能自动升级为创新带动或因果机制。

## 比较与类型学

记录案例内/案例间模式、可见案例总体、选案时点、可比性、相对事件时间与绝对年份、穆勒逻辑、负面案例、类型空间和集合论整合。改革阶段对齐不能遮蔽不同年份的共同冲击；必要时使用重叠年窗、同国跨期或第三案例作交叉比较。单一国家内部加入国家固定效应没有变异，也不能修复口径、时期或停业混杂。穆勒方法作为比较结构，不作为充分因果证明。类型学应公开维度、单元格、空格和归类规则。

## 历史研究

记录史料来源、传递链、一手/二手身份、史料批判、交叉印证、沉默证据、档案缺口、时代错置控制和口述史伦理。执行保留祖先文本—转载—汇编来源树、行动者—材料可见性矩阵、传递/批判/印证审计和缺口日志。同源抄录不能冒充独立材料；没有抽样框、选择概率和目标边际时，不给幸存档案套用现代无应答权重，而做保存机制与缺失情景分析。结论区分经核事实、来源内解释和仍待检验的机制；口述史遵循持续同意、保存和访问约定。

## 扎根理论

声明流派及其认识论后果，再选择与该流派相容的初始/理论抽样、持续比较、编码、备忘录、范畴发展、负面案例、饱和理由、反身性和文献介入时点；经典、Straussian、建构主义等路线不能被统一预设为同一种“共同建构”逻辑。执行记录每轮抽样/比较/编码/真实时点备忘录和范畴变化，回顾性重建不得倒签。门卫掌握排班、考核或晋升时，参与隐匿、独立招募和引语再识别控制先于理论收益。固定访谈人数或“连续若干次无新代码”不自动证明饱和；饱和质量由独立解释性研究运行评审并保留范畴级证据。

## 定量

`task_type` 必须是 descriptive、associational、predictive 或 causal：

- 共同：目标/estimand、变量/特征、时间结构、比较基础、假设、缺失、不确定性、验证和稳健性；
- 预测：训练/验证/测试、基准、校准和漂移；
- 因果：明确反事实、时序、识别假设与针对假设的诊断。

普通回归、显著相关或高预测性能不能自动解释为因果。固定 p 值、样本量或模型指标不作通用硬门。
处理在地区、学校或机构等聚类层级分配时，不确定性处理须匹配分配层级；簇数较少要采用适合少簇的修正并报告敏感性，不能只写“聚类标准误”。单位会迁移时分别定义当期暴露、基线归属等 estimand；政策后中介不能作为总效应的普通控制变量。
局部识别设计中的剔除带、甜甜圈样本、伪阈值或时间窗变化必须说明是否仍保留原比较和目标量；若关键阈值附近的信息被移除，该分析只能作为压力测试或新的估计对象，不能替代原效应。

## 计算社会科学

记录数字痕迹来源、平台条款、特征、数据切分、模拟规则、基准、漂移、可解释性、算法偏差、公平、隐私和环境。执行冻结数据快照、访问审计、特征日志、泄漏审计、模拟/基准/漂移/公平结果和环境锁。数字痕迹不等于目标总体；泄漏、无权使用或隐私事件可硬阻塞。

## 综述

`review_type` 为 embedded、narrative、scoping 或 systematic。共同记录搜索、截止日、数据库版本/漂移、筛选、阅读、质量评价、综合、矛盾证据和真实空白。把同一项目的注册、基线、阶段、终期、论文和报告连接成研究家族；追索灰色/零结果并联系作者或项目方补缺，未获结果进入选择性报告与确定性评定。单人筛选属于需复核的偏倚风险，不自动判废；统计合并只在估计对象、方向、随访窗和误差结构可比时成立，同研究多效应需处理依赖，研究数少时避免过度元回归。确定性逐结果综合设计偏倚、依赖、间接性、不精确与未发表结果，不按显著篇数投票。若无法补齐声明过的来源，降级为已覆盖来源的有边界综合，不把“未检索到”写成“没有研究”。systematic 接入 PRISMA；scoping 使用适用扩展；其他类型不强制 PRISMA。

## 概念、诠释与规范

- 概念/理论：定义规则、论证图、竞争概念、边界案例和反例；
- 诠释：材料、情境化转录、关系与沉默、解释规则、研究者位置、竞争解读和反身性；成员反馈必须由参与者自主完成并作为新材料，不由门卫代办；引语、概括、删改与撤回由参与者在无压力渠道选择；
- 规范：价值前提、事实前提、受影响主体、论证图、最强反对、反例和制度约束。

这些路线可以没有量化、因果识别或假设，但仍须有可追溯材料、论证步骤、替代意见和推断边界。

## 多路线整合

多路线必须从 sequential、convergent、nested、complementary、adjudicative 中选择一种，记录路线顺序、交接、材料独立性、冲突处理和综合上限。个体链接键丢失或同意不允许链接时，禁止用罕见特征猜配；现有研究通常只能在群体层作 complementary 联合展示，并恢复方向相反或沉默的结果。未来若要个体级 sequential 连接，必须重新取得同意、建立受控链接并预先定义后续抽样。两种方法并列出现不等于混合方法；同一上游材料变换成两种格式不等于独立三角验证。
