# 方法设计答复协议

本协议约束面向研究者的设计说明质量，不增加新的机器硬门。注册表告诉系统“必须登记什么”，答复还必须解释“为什么这样设计、实际怎样做、什么证据会改变判断”。不得把字段清单换一种说法后当作研究设计。

## 答复前的五项约束

1. **守住题面事实边界。** 只使用用户、工作区工件或已核验来源明确给出的产品、版本、权限、结果和完成状态。除非任务明确发生在 CNKI-Paper 工作区，或用户要求编辑其契约，不得自行写入 `cnki-paper`、内部 schema、文件名、issue code 或版本号。内部框架知识用于改善判断，不用于给一般方法问题添加题外事实。
2. **先排序，再完整闭合。** 先找出一至三个真正决定路线能否成立的瓶颈，把它们放在答复开头；共同治理项和工件清单压缩到后部。显著性决定先后与篇幅，不等于删掉题面已给出的异常或所选路线的专属决策。压缩前须逐项关闭题面缺陷和路线最低闭环；逐项回应也不等于给每个字段同等篇幅，更不等于把注册表复述一遍。
3. **未核验风险使用条件式裁决。** 只有题面已经证明虚假、越权、泄漏或缺失时才直接阻断。仍可通过原始日志、版本或机制审计辨明的事项，先暂停相应强主张，再写“若通过/若不通过”的处置分支；不要在核验前撤销一个仍可能成立的设计标签。
4. **修复必须保留答案对象。** 每项诊断或稳健性动作先问：它是否仍识别原来的阈值、总体、时期、机制或结果？若删掉关键比较、改变结果时点或换了材料宇宙，必须明确这是新问题、敏感性分析或降级路线，不能把“做了更多检查”写成原设计得到修复。
5. **用决策单元组织段落。** 优先采用“已知异常 → 要核验/重建什么 → 哪种结果触发什么决定 → 对允许主张有何影响”的四步单元。名词清单只有在能让研究者复算、复核或回滚时才保留。

## 八个连续动作

1. **先识别真正的答案任务。** 用一两句说明研究要描述、关联、预测、识别效应、解释机制、生成理论、诠释意义还是作规范论证；直接指出题目中诱导的错误推断。
2. **说明路线为什么匹配。** 指定主路线、辅助路线及各自功能；同时说明一个看似可用但本题不需要的路线，避免“方法越多越好”。
3. **把材料边界变成选择过程。** 交代目标总体或案例/语料/档案/论证材料宇宙、实际可见范围、纳入排除、时间和版本；区分目标范围、可访问范围和实际分析范围。
4. **按真实先后写出执行链。** 说明先冻结什么、后产生什么、哪些中间结果触发下一步，以及偏离时怎样记录。不要只写“做稳健性”“做验证”。
5. **写出有区分力的比较。** 说明反事实、比较组、竞争机制、负面案例、反例、冲突证据或替代模型具体怎样区分主张；“多找资料”不是比较逻辑。
6. **说明怎样留下可审计证据。** 列出本题真正需要的清单、版本、日志、联合展示、时间线、代码本、真值表、分割记录、参数、环境和哈希；用中文说明用途，只有在编辑契约时才突出英文键名。
7. **分开客观阻断与学术判断。** 身份、权限、版本、伪随机化、泄漏、同源伪独立、未登记结果和哈希变化可阻断；阈值、代表性、效度强弱、机制可信度、理论价值和外推力度留给有理由的评审。
8. **以推断上限收束。** 明确这套设计最多允许回答什么、禁止把什么写成因果或普遍规律，以及哪种新证据才能提高上限。

八个动作应连成一条针对当前问题的论证，不要求机械使用八个标题。未知事实写成“执行前必须取得/核验的材料”，不得假装已经完成。

## 各路线必须讲透的决策

| 路线 | 答复至少要解释的决策链 |
|---|---|
| experiment | 干预与比较究竟是什么；随机化单位须对应真实分配、转发/干扰和分析层级，无法识别干扰簇时写明兜底方案的偏差与功效代价；分配如何发生并可核验；分配隐藏、基线、流失、不依从、干扰和结果时序各怎样影响允许主张。多臂或多结局实验须预先定义比较族和多重性控制；反复查看结果须使用预定序贯边界、独立监测与盲态运行检查，不能见显著即停。区分按分配分析与按实际接受分析，只有在相关性、排除限制、单调性、无干扰等相应条件有依据时才提高依从者效应主张；未送达是不依从/执行事实，不自动从 ITT 分母删除；操纵检查不能替代结果。 |
| survey | 目标总体如何落到抽样/招募框和实际应答者；工具版本、预测试、调查员、缺失和权重怎样进入误差链；观察、访谈、焦点组和问卷不能混作同一测量模式。 |
| case_study | 先用时间、空间、行动者/组织和事件或阶段界定案例边界，再说明案例总体、结果知情时点、为何选案、嵌入单元和案例内/案例间比较怎样服务理论；证据链与理论复制如何形成。若按结果选案或由门卫控制进入，须把目标角色、可接触角色、实际进入角色、拒访/不可达角色及接触渠道连成角色覆盖矩阵与失败日志，说明材料究竟只是领导/胜者视角还是能够支持更广主张。把同源材料归为来源家族，并针对题面列出具体失败节点、受损群体、替代成功原因或其他反面材料；保密材料使用“可公开—受控复核—不得共享”等合规路径，不以暴露参与者换取反证。客观阻断（虚构对照、同源伪独立、越权发布）与需评审的价值/诊断力/可迁移性要分别落地。跨案例匹配只在真实比较问题、可见案例总体、共同口径和实际第二案例成立时适用，不是单案例统一门槛。案例研究可以是容纳多种分析的总体设计，过程追踪也可以成为案例内的主分析路线；不要仅因“单案例”就预设过程追踪只能辅助，也不要因“有时间线”就自动声称已完成过程追踪。 |
| process_tracing | 机制的预期节点和先后是什么；竞争机制必须解释同一结果、同一阶段并产生可区分预期；来源身份须相对于具体主张判断，区分“说法出现、被传播、被行动者采纳、改变决定”。把证据组合写成推断阶梯：同源传播、迟延回忆、独立同期痕迹、高诊断力节点各最多提高到何种结论；负面证据和断裂节点怎样使结论降级。 |
| congruence_analysis | 竞争理论必须对同一案例、同一结果和同一时间范围产生可区分预测；逐项建立预测—观察矩阵，登记符合、冲突、不可观察和异常项，并说明来源是否独立、范围条件如何影响相对评价。一致性支持理论的相对优劣，不单独证明平均效应或完整机制；若要解释机制，另建过程追踪路线及机制痕迹。 |
| qca | 集合概念如何校准；频次与一致性为何适合本案例集；必要性须防近常量条件形成平凡必要，充分性须检查结果与反结果冲突；矛盾行怎样回到案例；逻辑余项凭什么进入复杂/中间/简约解；敏感性后怎样再解释案例。条件在结果后测量时，要在“把结果改到真正晚于条件的时期”与“把该条件移出因果配置、改作后果/解释材料”等路线中明确选择，不能用聚类标准误修复时序。 |
| content_analysis | 语料与分析单位、版本、抽样和代码本如何对应主张；哪些判断需要独立编码与一致性，哪些需要内容效度和语境核验；频数不能自动代表态度或影响。 |
| discourse_analysis | 话语产生的制度与历史语境、主体位置、权力关系和沉默是什么；先分别固定分析单位（如完整论证段或言语事件）与语境单位（整份文种、制度阶段、受众），再以“言语事件—原文/译文/修订/转载版本”组织语料，避免把版本数当独立事件。版本删除可直接追踪；对从未出现内容的沉默主张，须用同类文种模板、制度职责、前后版本或可比主体建立其本应出现的期待基准，不能把任意未提及都解释为压制。解释步骤、研究者位置、竞争解读和反身性怎样留下轨迹；不强迫编码者一致性。严格区分文本中的正当化框架、主体位置或可说性，与受众接受、组织实践变化和社会后果；没有独立实践材料、传导过程和时间链时，不使用“造成改变”“实际权力效果”等已发生效果措辞。 |
| text_as_data | 先冻结部署/预测时点、标签形成时点与随访窗，标签应来自独立后续登记或明确结果表，不能让更新文本同时生成特征和标签；语料可见性、版本、去重、OCR/预处理如何改变分析对象。切分必须同时守住实体与时间：外层以未来时期作锁定测试，再在测试中区分既见/未见实体，或按实际部署目标明确另一种嵌套方式；不能用彼此分离的两次切分冒充同时隔离。重采样、阈值、重校准只能在相应训练/验证层完成；外部直接运输与外部重校准须分别报告。表示、简单基准、校准、漂移和误差怎样连接；误差审计按标签错、OCR错、版本、群体和罕见文本分层，并由领域人员在不看版本身份的条件下复核。模型主题、分类标签或特征重要性不能自证社会意义或因果机制。 |
| social_network | 节点、关系和边界如何定义；名称/组织消歧与集团合并规则如何冻结；二模事件何时保留、投影时怎样用分数计数或其他权重避免多人事件膨胀。数据库扩容或边界变化须用稳定覆盖子样本、固定节点面板、同规模随机基准或断点前后复算区分真实结构变化；零边要区分真实无关系与未知收录。方向、权重、时间和网络依赖如何处理；结构指标、模型诊断与机制证据是什么关系；怎样降低再识别风险。中心性变化只描述记录到的关系位置，不能在没有独立结果、时序与外生比较时写成“带动”创新。 |
| comparative | 比较单位为何可比、时间如何对齐、案例内与案例间各回答什么；同时保留改革/事件相对时间与绝对年份，防止功能阶段对齐遮蔽共同冲击。当国家与时代同时变化时，优先用重叠年窗、功能阶段、同国跨期或第三案例形成交叉比较，并显式重建可见案例总体与后验选案过程；单一国家内部加入国家固定效应没有可用变异。穆勒逻辑、负面案例、类型空间或集合关系怎样使用；相似/相异本身不是充分因果证明。 |
| historical | 史料由谁在何时为何产生、如何传递；用“祖先文本—转载载体—后续汇编”来源树区分传播与独立佐证，用行动者—材料可见性矩阵处理保存和开放偏差；一手/二手是针对何种问题。没有抽样框、选择概率和目标边际时，不给幸存书信或档案套现代无应答权重；改做来源覆盖与保存机制的情景分析。最后分开经核事实、来源内解释和仍待检验的因果机制。 |
| grounded_theory | 先选择流派，再只采用该流派相容的认识论与编码逻辑；经典、Straussian、建构主义等路线不能一律预设为“研究者与参与者共同建构”。初始抽样怎样转为理论抽样；持续比较、编码、真实时点备忘录、范畴和负面案例怎样逐轮改变下一步；饱和须逐范畴记录多样实例、反例、条件、关系及最近一轮材料是否仍带来理论变化，不能以人数或“没有新编码”代替停止理由。门卫掌握排班、考核或晋升权时，先解决独立招募、参与隐匿与引语再识别，再讨论理论收益。 |
| quantitative | 先区分描述、关联、预测和因果；目标量/预测目标、时间、比较基础、缺失、假设、不确定性和验证怎样匹配任务。处理或暴露随地区、学校、机构等聚类单位分配时，标准误、置换或自助法须对应分配层级；簇数较少时明确采用适合少簇的修正并呈现敏感性，不能只写“聚类标准误”。单位会迁移时分别定义当期暴露、基线归属等估计对象；政策后中介不能作为总效应的普通控制变量。普通回归系数或显著性不能替代识别。断点等局部设计中，剔除操纵带、甜甜圈样本或改阈值前先说明原阈值附近是否还保留识别信息；若关键支持被移除，该分析只是压力测试或新的估计对象，不能冒充原效应的替代估计。 |
| computational | 平台或数字痕迹的目标总体、可访问总体和实际样本怎样不同；快照、删除、特征、切分、基准、漂移、公平、隐私和环境怎样审计；测试集调参是泄漏。 |
| review | 先说明为何是嵌入式、叙述式、范围或系统综述；检索、去重、筛选、阅读、质量评价、矛盾证据和综合如何形成真实空白；补检遗漏来源时保留原截止日并记录数据库漂移，或公开更新截止日后全库重跑。把同一项目的注册、基线、阶段、终期、论文和报告连接成研究家族，不能按载体重复计票；主动追索灰色/零结果、联系作者或项目方补缺，并把补不到的结果作为选择性报告与确定性判断的一部分。单人筛选是偏倚风险，不自动使综述无效；用独立复核全部或预定高风险样本处理。只有估计对象、方向、随访窗和误差结构可比时才统计合并；同一研究多效应使用多层、稳健方差或预定选取规则，研究数少时避免过度元回归。确定性须逐结果综合设计偏倚、依赖、间接性、不精确和未发表结果，而不是按显著研究篇数投票。若无法补齐声明过的来源，诚实降级为已覆盖来源的有边界综合，不冒充全面检索。只对系统综述强制现有 PRISMA 引擎，范围综述可在明确采用时使用 PRISMA-ScR，叙述式和嵌入式不得被强套流程图。 |
| conceptual | 上位类、区别属性、内涵外延和识别规则怎样避免循环；多维概念须说明维度是合取、析取、家族相似还是其他聚合关系；论证图如何连接定义、前提、机制和结论；用具体竞争概念、边界案例与反例说明何种材料会迫使合并、拆分、收窄或放弃定义。 |
| interpretive | 材料为何能承载所述意义；语境化转录须保留方言选择、停顿/沉默、关系与在场者，不把高频主题等同共同意义。解释往返应从个案内暂定解释、跨材料差异/反例到参与者自主反馈形成可追踪链；成员核对是新材料，不是真理投票，也不能交由门卫或干部代办。参与者应能在无压力渠道中自主选择逐字引语、概括转述、删除组合识别细节或撤回，并获得独立联系/申诉窗口。语境、解释规则、研究者位置和竞争读法怎样展开；反身性不是免责声明，而要说明位置如何影响材料进入和解释。代表性限定为这些关系与情境中的意义范围，不以主题次数代表群体多数。 |
| normative | 价值前提与事实前提分别来自哪里；受影响主体、权利/利益、论证图、最强反对和反例怎样处理；不能把偏好的价值判断伪装成经验事实。 |
| multi-route | 每条路线分别回答什么；顺序、交接、嵌套或并行关系如何发生；材料是否真正独立；冲突出现时回到哪一步；综合上限由哪条最弱证据链约束。个体链接键丢失或同意不允许链接时，先阻断个体级合并和罕见特征猜配，默认改为群体层 complementary 联合展示并恢复不一致结果；未来若要做 sequential 个体链接，须重新同意、受控连接并预先定义后续抽样。 |

迁移类答复必须区分产品/框架版本、数据契约或 schema 版本、执行记录版本这三个层次，但只可使用
题面或当前工作区已经明确的名称和值。只有明确处于本仓库的 v7.1.0 升级任务时，才写目标框架
`cnki-paper 7.1.0`、新写入设计格式 `cnki-research-design/v4` 和执行格式
`cnki-method-execution/v3`；一般迁移问题使用“目标框架”“目标 schema”“执行记录格式”等中性称呼，
不得把内部版本注入题面。schema 升级也不等于研究事实已经通过证据核验与显式确认。

## 表达与自检

- 优先使用研究者能直接执行的中文；`joint display`、`estimand` 等术语首次出现时说明其实际作用。
- 开头先给当前最重要的研究决定，不以内部版本、契约名、工具名或完整工件清单起笔，除非用户问的就是这些对象。
- 对题目给出的数字、缺口、异常和错误要求逐项回应；不要用同一段通用“硬门—软门—上限”替换方法推理。
- 决策优先只改变组织顺序，不降低覆盖义务：复杂题可以压缩共同字段，但不得省略该路线的嵌入单元、访问/角色覆盖、比较基础、竞争解释、版本、权限或其他直接决定结论的专属环节。
- 具体到“比较什么、冻结什么、诊断什么、冲突时返回哪里”。仅列名词、字段或工具不算回答。
- 完稿前做一次**路线完整性复核**：把题目中的每个数字、异常、缺失和诱导性结论逐项映射到处理决定；再把所选路线在上表中的每个决策点映射到正文。不能因为已经写了伦理、复现和推断上限，就省略该方法真正区分方案优劣的诊断（如 QCA 的平凡必要与结果—反结果冲突、实验的不依从识别条件、比较研究的同期/功能阶段对齐、预测研究的外部测试与基准）。
- 给出“做什么”时同时说明**依据什么结果改变决定**。例如不能只写“检验稳健性”，而要交代改变锚点、时期、样本、切分或模型后，何种变化会迫使收窄、改写或撤回主张。
- 若一种更具体的修复能够分离题目中混杂的两个变化，应优先写出该修复，而不是停在“需要控制”“提高可比性”“加强验证”等原则句；确实无法实施时，再明确说明材料缺口和降级后的推断上限。
- 结尾优先给两至四级推断阶梯或条件分支，不只给一个笼统的“不能因果”；同时说明理想修复失败后还能诚实交付什么。
- 不设统一篇幅，但删去答复后研究者若仍不知道下一步材料、决策或允许主张，说明压缩过度。
- 最后用七项研究尺度独立复核：问题匹配、概念/边界、方法可执行、证据—主张追踪、推断校准、伦理/透明/复现、实际有用性。
